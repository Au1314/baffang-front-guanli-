# 实现审核记录详情功能方案

## 1. API层实现
- 在 `src/api/audit.js` 中添加 `getAuditRecordDetail` 方法，调用 `/audit/record/{id}` 接口
- 支持通过ID获取单个审核记录的详细信息

## 2. 视图层实现
- 在 `AuditRecordList.vue` 组件中添加详情弹窗组件
- 实现点击列表项或查看详情按钮时显示弹窗
- 弹窗中展示完整的审核记录信息，包括：
  - 基本信息（审核单号、标题、类型、状态、优先级等）
  - 申请人信息
  - 提交内容
  - 附件列表（支持预览和下载）
  - 审核日志（当前为空，预留展示位置）

## 3. 交互设计
- 点击列表行或查看详情按钮时显示详情弹窗
- 处理事件冒泡，确保点击操作按钮时不触发列表行点击
- 弹窗支持关闭和遮罩层点击关闭
- 附件支持点击预览或下载

## 4. 数据处理
- 实现详情数据的加载和缓存
- 实现附件列表的格式化处理
- 实现日期时间的格式化显示
- 处理数据加载状态和错误情况

## 5. UI设计
- 保持与现有页面一致的设计风格
- 使用 Element Plus 的 Dialog 组件实现弹窗
- 采用卡片式布局展示不同类别的信息
- 附件使用链接或图标展示，支持多种文件类型

## 6. 性能优化
- 实现详情数据的按需加载
- 避免重复请求相同ID的数据
- 优化弹窗的显示和隐藏动画

该方案将在现有全部审核记录列表功能基础上，添加详情查看功能，支持点击列表项或操作按钮查看完整审核记录，包括附件和审核日志，提升审核管理的完整性和易用性。
