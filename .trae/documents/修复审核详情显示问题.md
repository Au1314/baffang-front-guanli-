## 问题分析

根据代码和截图分析，审核单号、审核状态、认证状态没有正确显示的原因是：

1. 当点击列表行查看详情时，`handleViewDetail`函数会调用API `authApi.getPrivateStationAuthDetail(row.id)` 获取详情数据
2. 然后将API返回的`response`直接赋值给`currentAudit.value`，覆盖了列表行中原有的完整数据
3. 列表行数据包含了`auditNo`、`auditStatusName`、`authStatusName`等字段，但API返回的详情数据可能不包含这些字段

## 修复方案

**方案：直接使用列表行数据显示详情，无需重新调用API**

### 修改点：

1. **修改`handleViewDetail`函数**：删除API调用，直接使用传入的`row`数据
2. **保留详情弹窗的基础结构**：确保所有字段正确绑定

### 代码修改：

```javascript
// 查看详情
const handleViewDetail = async (row) => {
  try {
    detailLoading.value = true
    // 直接使用列表行数据，无需调用API
    currentAudit.value = row || {}
    showAuditDetail.value = true
  } catch (error) {
    console.error('获取审核详情失败:', error)
    ElMessage.error('获取审核详情失败')
  } finally {
    detailLoading.value = false
  }
}
```

## 预期效果

1. 审核单号、审核状态、认证状态等字段将正确显示
2. 详情弹窗加载速度更快（无需API请求）
3. 保持与列表数据的一致性
