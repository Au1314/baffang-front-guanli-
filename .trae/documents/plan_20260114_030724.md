## 修复评论列表数据处理错误

### 问题分析
- **错误原因**：fetchCommentList函数中数据处理逻辑错误
- **API响应结构**：API返回的完整结构包含code、msg、data三层
- **拦截器处理**：响应拦截器会直接返回res.data，所以authApi.getCommentList返回的已经是data部分
- **错误代码**：
  ```javascript
  commentList.value = response?.data?.list || []  // 错误：response已经是data
  commentTotal.value = response?.data?.total || 0 // 错误：response已经是data
  ```

### 修复方案
1. **修改数据处理逻辑**：直接从response中获取list和total，而不是从response.data中获取
2. **修复步骤**：
   - 定位到`src/views/ForumManage.vue`文件中的fetchCommentList函数
   - 修改数据赋值逻辑
   - 确保与其他列表功能（如帖子列表）的数据处理保持一致

### 预期效果
- 评论列表正常显示
- 评论总数正确显示
- 分页功能正常工作

### 代码修改示例
```javascript
// 修复前
commentList.value = response?.data?.list || []
commentTotal.value = response?.data?.total || 0

// 修复后
commentList.value = response?.list || []
commentTotal.value = response?.total || 0
```
