# 论坛管理模块实现计划

## 1. 功能分析
- 论坛管理模块包含：
  - 帖子与评论管理（增删改查）
  - 帖子置顶/精华设置
  - 用户举报帖子或评论审核
- 权限要求：论坛管理员（5）、普通管理员（1）和超级管理员（0）可用

## 2. 技术实现

### 2.1 管理员类型更新
- 添加论坛管理员（5）和未分配身份（10）到枚举中
- 更新类型描述映射
- 添加相关计算属性

### 2.2 权限管理
- 在`hasPermission`方法中添加论坛管理权限检查
- 确保只有论坛管理员、普通管理员和超级管理员可以访问

### 2.3 API 层
- 在 `auth.js` 中添加论坛管理相关 API 方法
- 包括帖子管理、评论管理、置顶精华设置和举报审核

### 2.4 路由配置
- 添加论坛管理页面路由 `/forum-manage`
- 设置正确的权限

### 2.5 页面组件
- 创建 `src/views/ForumManage.vue` 页面
- 实现帖子列表、帖子详情、评论管理、置顶精华设置和举报审核

### 2.6 菜单配置
- 在侧边栏添加论坛管理菜单项
- 仅对有权限的用户显示

## 3. 实现步骤

1. **更新管理员类型**：在 `adminStore.js` 中添加论坛管理员和未分配身份
2. **更新权限管理**：添加论坛管理权限检查
3. **添加 API 方法**：在 `auth.js` 中添加论坛管理相关 API
4. **配置路由**：添加论坛管理页面路由
5. **创建页面组件**：
   - 设计页面布局
   - 实现帖子列表和管理功能
   - 实现评论管理功能
   - 实现置顶精华设置
   - 实现举报审核功能
6. **添加菜单配置**：在侧边栏添加论坛管理菜单项
7. **测试和优化**：测试功能完整性和用户体验

## 4. 预期效果
- 论坛管理员、普通管理员和超级管理员可以看到论坛管理菜单
- 可以查看、编辑、删除帖子和评论
- 可以设置帖子置顶和精华
- 可以审核用户举报
- 完善的权限控制和用户体验
