# 修复头像上传API未被调用的问题

## 问题分析

根据用户提供的截图，头像上传API没有被调用，网络请求中只有profile接口的调用。经过分析代码，发现以下问题：

1. **@change事件参数处理错误**：
   - 当`auto-upload="false"`时，`@change`事件的参数结构是包含`file`和`fileList`的对象
   - 当前代码中`handleAvatarChange`方法直接使用`file.file`获取文件，但此时`file`已经是文件对象，导致`file.file`为`undefined`
   - 这会触发`if (!selectedFile) return`条件，函数直接返回，没有调用上传API

2. **before-upload事件可能不触发**：
   - 当`auto-upload="false"`时，`before-upload`事件可能不会被触发，因为没有自动上传
   - 这会导致图片格式和大小验证失效

3. **缺少手动触发上传的逻辑**：
   - 当前配置下，没有手动触发上传的逻辑

## 解决方案

修改头像上传流程，采用以下方案：

1. **修改 `handleAvatarChange` 方法**：
   - 正确处理`@change`事件的参数，获取选中的文件
   - 如果是文件列表，取第一个文件
   - 如果是单个文件，直接使用

2. **确保before-upload事件被触发**：
   - 在`handleAvatarChange`方法中手动调用`before-upload`的验证逻辑
   - 如果验证通过，再调用上传API
   - 如果验证失败，显示错误提示

3. **保持其他逻辑不变**：
   - `saveProfile`方法的实现是正确的
   - 头像上传前的验证逻辑保持不变

## 具体实现步骤

1. **修改 `handleAvatarChange` 方法**：
   ```javascript
   const handleAvatarChange = async (file) => {
     try {
       // 正确获取选中的文件
       let selectedFile
       if (file.file) {
         // 如果是包含file和fileList的对象（旧版Element Plus或某些配置下）
         selectedFile = file.file
       } else if (Array.isArray(file)) {
         // 如果是文件列表数组
         selectedFile = file[0]
       } else {
         // 如果直接是文件对象
         selectedFile = file
       }
       
       if (!selectedFile) return
       
       // 手动调用上传前验证
       const isValid = beforeAvatarUpload(selectedFile)
       if (!isValid) return
       
       // 调用头像上传API
       const uploadResponse = await authApi.uploadAvatar(selectedFile)
       console.log('头像上传API响应:', uploadResponse)
       
       // 保存上传后的头像URL
       editForm.avatar = uploadResponse.data
       ElMessage.success('头像上传成功')
     } catch (error) {
       console.error('头像上传失败:', error)
       console.error('错误详情:', error.response || error.message || error)
       ElMessage.error('头像上传失败：' + (error.message || '未知错误'))
     }
   }
   ```

2. **确保before-upload验证函数返回布尔值**：
   ```javascript
   const beforeAvatarUpload = (file) => {
     const isJPG = file.type === 'image/jpeg' || file.type === 'image/png'
     const isLt2M = file.size / 1024 / 1024 < 2
     
     if (!isJPG) {
       ElMessage.error('只能上传 JPG/PNG 格式的图片!')
       return false
     }
     if (!isLt2M) {
       ElMessage.error('图片大小不能超过 2MB!')
       return false
     }
     return true
   }
   ```

3. **保持其他配置不变**：
   - `el-upload`组件的配置保持不变
   - `saveProfile`方法保持不变

## 预期效果

- 用户选择图片后，会触发`@change`事件
- 函数会正确获取选中的文件
- 手动调用验证逻辑，验证图片格式和大小
- 验证通过后，调用`authApi.uploadAvatar`上传图片
- 上传成功后，将返回的URL保存到`editForm.avatar`
- 网络请求中会显示头像上传API的调用
