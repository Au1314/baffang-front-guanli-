# 优化快速分析功能请求超时处理

## 需求分析
用户要求将超时时间延长到90秒，解决API请求超时问题。

## 问题分析
1. 前端请求超时：`timeout of 30000ms exceeded`
2. 后端已收到请求但未在30秒内返回响应
3. 需要延长超时时间以适应后端处理时间

## 解决方案

### 1. 优化快速分析API的超时设置
在 `auth.js` 中的 `quickAnalysis` 方法中，为该API单独设置90秒超时时间，不影响其他API：

```javascript
// AI快速分析
quickAnalysis(question, config = {}) {
  return request.get('/ai/analysis/quick', { 
    params: { question }, 
    timeout: 90000, // 单独设置90秒超时
    ...config 
  })
}
```

### 2. 具体实现步骤

#### 步骤1：修改快速分析API的超时设置
在 `auth.js` 中为 `quickAnalysis` 方法单独设置90秒超时

#### 步骤2：测试优化效果
运行构建测试，确保代码质量

## 预期效果
1. 延长超时时间后，减少因后端处理时间长导致的超时错误
2. 为快速分析API提供更合适的超时设置
3. 不影响其他API的超时设置
4. 提高系统的可用性和健壮性

## 技术要点
* Axios API级别的超时设置
* 差异化的超时配置
* 优化的用户体验

## 优势
* 为快速分析这类耗时操作提供足够的处理时间
* 不影响其他API的正常运行
* 提高了系统的健壮性
* 减少了不必要的超时错误
