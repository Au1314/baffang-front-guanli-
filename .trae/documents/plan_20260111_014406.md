## 完善获取私人电桩认证详情功能方案

### 1. 优化思路

- **添加新的API方法**：在auth.js中添加获取私人电桩认证详情的新API方法
- **修改详情获取逻辑**：更新PrivateStationAudit.vue中的handleViewDetail方法，使用新API获取详情
- **完善详情弹窗**：显示新API返回的完整信息，包括审核信息、地理位置等
- **保持列表点击功能**：确保点击列表行可以查看详情

### 2. 具体实现

#### 2.1 在auth.js中添加API方法

**文件**：`src/api/auth.js`

```javascript
// 获取私人电桩认证详情
getPrivateStationAuthDetail(stationId) {
  return request.get(`/auth/station/detail/${stationId}`)
}
```

#### 2.2 修改PrivateStationAudit.vue中的详情获取逻辑

**文件**：`src/views/PrivateStationAudit.vue`

```javascript
// 查看详情
const handleViewDetail = async (row) => {
  try {
    detailLoading.value = true
    
    // 使用新API获取私人电桩认证详情
    const response = await authApi.getPrivateStationAuthDetail(row.id)
    
    currentAudit.value = response || {}
    showAuditDetail.value = true
  } catch (error) {
    console.error('获取审核详情失败:', error)
    ElMessage.error('获取审核详情失败')
  } finally {
    detailLoading.value = false
  }
}
```
