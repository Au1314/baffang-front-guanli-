# 评论详情功能实施方案

## 1. 需求分析
根据用户提供的API信息，需要实现评论详情功能。API使用GET方法，请求路径为`/forum/reply/{id}`，返回包含评论详情、父评论信息和子回复的完整数据结构。

## 2. 现有结构分析
- 论坛管理模块（ForumManage.vue）包含评论管理标签页
- 评论列表已经实现了基本的展示和删除功能
- authApi中已有getCommentList和deleteComment方法
- 需要添加评论详情API方法和UI功能

## 3. 实施方案

### 3.1 添加评论详情API方法
- 在authApi中添加getCommentDetail方法
- 实现GET请求，路径为/forum/reply/{id}
- 接收commentId作为参数

### 3.2 实现UI功能
- 在评论列表中添加详情按钮
- 添加评论详情对话框
- 实现评论详情展示，包括：
  - 基本信息（ID、内容、创建时间、点赞数等）
  - 用户信息（用户名、头像、电话等）
  - 父评论信息（如果有）
  - 子回复列表
- 添加加载状态和错误处理

## 4. 具体实现步骤

1. **添加评论详情API方法**
   - 修改 src/api/auth.js，添加getCommentDetail方法

2. **添加评论详情对话框**
   - 在ForumManage.vue中添加评论详情对话框
   - 添加相关的ref和响应式数据

3. **添加详情按钮**
   - 在评论列表中添加详情按钮
   - 实现handleViewCommentDetail方法

4. **实现评论详情展示**
   - 添加fetchCommentDetail方法
   - 展示评论基本信息
   - 展示用户信息
   - 展示父评论信息（如果有）
   - 展示子回复列表
   - 添加加载状态

5. **测试功能完整性**
   - 测试详情按钮点击事件
   - 测试评论详情API调用
   - 测试详情对话框展示
   - 测试嵌套评论展示

## 5. 预期效果
- 评论列表中每条评论都有详情按钮
- 点击详情按钮弹出详情对话框
- 对话框显示完整的评论信息
- 支持展示嵌套评论结构
- 显示加载状态和错误提示

## 6. 技术要点
- 使用Vue 3 Composition API
- 基于Element Plus组件库
- 遵循现有的代码风格和架构
- 确保功能完整性和稳定性
- 良好的用户体验设计

## 7. 代码结构
- `authApi.js`：添加getCommentDetail方法
- `ForumManage.vue`：
  - 添加详情按钮到评论列表
  - 添加评论详情对话框

## 8. 交互流程
1. 用户在评论列表中点击详情按钮
2. 显示加载状态

4. 展示评论详情对话框
5. 显示完整的评论信息，包括嵌套回复
6. 用户可关闭对话框返回列表
