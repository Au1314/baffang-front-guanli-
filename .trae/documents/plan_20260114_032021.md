## 修复人工客服数据处理错误

### 问题分析
- **错误原因**：人工客服相关函数的数据处理逻辑错误
- **API响应处理**：响应拦截器会直接返回res.data，所以authApi返回的已经是data部分
- **影响功能**：
  - 待处理对话列表
  - 我的对话列表
  - 对话消息列表
  - 对话记录详情

### 修复方案
1. **修改数据处理逻辑**：直接从response中获取数据，而不是从response.data中获取
2. **修复函数**：
   - `fetchMyConversations`：获取我的对话列表
   - `fetchPendingChatList`：获取待处理对话列表
   - `fetchChatMessages`：获取对话消息列表
   - `viewChatRecord`：查看对话记录详情

3. **修复步骤**：
   - 定位到`src/views/CustomerService.vue`文件
   - 修改上述四个函数的数据处理逻辑
   - 确保直接从response中获取数据

### 预期效果
- 待处理对话列表完整显示
- 我的对话列表完整显示
- 对话消息列表完整显示
- 对话记录详情完整显示

### 代码修改示例
```javascript
// 修复前
const data = response?.data || {}

// 修复后
const data = response || {}
```
