# 修复帖子和评论举报详情获取不到数据的问题

## 1. 问题分析

根据分析，问题出在 `ForumManage.vue` 中的 `handleViewReportDetail` 方法。具体原因如下：

1. **API响应结构**：API返回的响应结构是 `{ code: 200, data: {...}, msg: "OK" }`

2. **响应拦截器处理**：在 `src/api/index.js` 的响应拦截器中，当 `res.code === 200` 时，会直接返回 `res.data`（第51行），所以 `authApi.getReportDetail()` 方法返回的就是举报详情数据，而不是完整的响应对象

3. **组件中的处理差异**：
   - `PostReportAudit.vue` 中的 `handleViewDetail` 方法正确地直接使用 `response` 作为举报详情数据
   - `ForumManage.vue` 中的 `handleViewReportDetail` 方法错误地访问了 `response.data`，导致获取不到数据

## 2. 解决方案

修改 `ForumManage.vue` 中的 `handleViewReportDetail` 方法，将 `currentReport.value = response?.data || {}` 改为 `currentReport.value = response || {}`，直接使用响应拦截器返回的数据。
