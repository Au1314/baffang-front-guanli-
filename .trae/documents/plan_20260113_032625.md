## 迁移方案

### 目标

将平台管理中的数据统计部分移出来，单独放在统计模块下。

### 现有结构

当前数据统计功能位于`PlatformManage.vue`文件中的`statistics`标签页（第415-503行），包含：

1. 核心统计指标（用户总数、日活用户等）
2. 图表展示（私桩分布数据、交易数据）
3. 推送数据到大屏功能

### 迁移步骤

1. **创建统计模块相关文件**

   * 创建`Statistics.vue`主页面文件

   * 创建`StatisticsMetrics.vue`组件（核心统计指标）

   * 创建`StatisticsCharts.vue`组件（图表展示）

2. **迁移数据统计功能**

   * 将`PlatformManage.vue`中的数据统计相关代码复制到新文件中

   * 调整组件结构，确保功能完整

3. **更新路由配置**

   * 在`router/index.js`中添加统计模块路由

   * 设置合适的路由权限

4. **更新侧边栏菜单**

   * 检查`MainLayout.vue`或相关菜单配置文件

   * 添加统计模块菜单

5. **移除原有的数据统计标签页**

   * 从`PlatformManage.vue`中移除`statistics`标签页

6. **测试验证**

   * 确保统计模块正常访问

   * 确保数据统计功能正常工作

   * 确保权限控制正确

### 代码结构调整

1. **新的文件结构**

   ```
   src/
   ├── views/
   │   ├── Statistics.vue           # 统计模块主页面
   │   ├── StatisticsMetrics.vue     # 核心统计指标组件
   │   └── StatisticsCharts.vue      # 图表展示组件
   ├── router/
   │   └── index.js                  # 添加统计模块路由
   └── components/
       └── layout/
           └── MainLayout.vue        # 更新侧边栏菜单
   ```

2. **路由配置示例**

   ```javascript
   { 
     path: '/statistics',
     name: 'Statistics',
     component: () => import('@/views/Statistics.vue'),
     meta: {
       requiresAuth: true,
       title: '统计模块',
       hideLayout: false,
       permission: ['超级管理员', '普通管理员']
     }
   }
   ```

3. **组件拆分**

   * `Statistics.vue`：主页面，整合统计指标和图表

   * `StatisticsMetrics.vue`：负责展示核心统计指标

   * `StatisticsCharts.vue`：负责展示图表数据

### 预期效果

迁移完成后，数据统计功能将从平台管理中独立出来，形成一个专门的统计模块，便于后续扩展和维护。管理员可以通过侧边栏菜单直接访问统计模块，查看各项统计数据。

### 注意事项

1. 确保迁移后的数据统计功能与原功能保持一致
2. 注意权限控制，确保只有授权用户可以访问
3. 检查相关API调用，确保路径正确
4. 确保图表初始化和数据加载正常
5. 测试响应式设计，确保在不同屏幕尺寸下正常显示
6. 确保移除前后平台管理其他功能不会受到影响
