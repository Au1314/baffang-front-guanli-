# AI运营优化建议功能实现方案

## 1. 功能概述
在决策模块下新增AI运营优化建议页面，用于调用AI运营优化建议API，获取并展示运营优化建议和行动方案。

## 2. 实现步骤

### 2.1 创建新页面组件
- 创建文件：`src/views/AIROperationOptimization.vue`
- 参考现有`AIAnomalyDetection.vue`和`AIDecisionRequest.vue`的结构设计
- 包含表单提交和结果展示功能

### 2.2 添加API调用方法
- 在`src/api/auth.js`中添加新的API方法：
  ```javascript
  // AI运营优化建议
  getOperationOptimizationSuggest(data) {
    return request.post('/ai/decision/optimization/suggest', data, {
      timeout: 180000 // 3分钟超时
    })
  }
  ```

### 2.3 页面设计与实现

#### 2.3.1 表单设计
- 保持简洁的表单设计
- 包含业务类型、业务ID等可选参数
- 添加自动执行开关

#### 2.3.2 结果展示
- 基本信息展示：决策ID、编号、置信度、自动执行状态、处理时间
- AI分析结果：
  - 置信度和优先级
  - 优化建议列表（按优先级分组展示，包含分类、标题、描述、优先级）
  - 建议操作（表格展示，包含操作名称、描述、类型、可自动执行状态）
- 详细建议操作列表：独立表格展示
- 参数详情弹窗：用于查看操作参数

#### 2.3.3 数据处理
- 解析返回的`analysis`字段（Markdown格式的JSON）
- 格式化展示优化建议和操作
- 按优先级对建议进行分组
- 提供复制结果功能

### 2.4 路由配置
- 在`router/index.js`的决策模块子路由中添加AI运营优化建议页面路由
- 路径：`/decision/operation-optimization`
- 名称：`AIROperationOptimization`

### 2.5 导航菜单
- 在`Decision.vue`的水平菜单中添加AI运营优化建议菜单项
- 索引：`/decision/operation-optimization`
- 显示文本：`AI运营优化建议`

## 3. 技术要点

### 3.1 数据解析
- 使用正则表达式提取`analysis`字段中的JSON内容
- 安全处理JSON解析，防止解析错误

### 3.2 建议展示
- 按优先级分组展示优化建议
- 突出显示高优先级建议
- 使用卡片式布局提高可读性

### 3.3 交互设计
- 优化建议折叠/展开功能
- 操作参数详情弹窗
- 结果复制功能

## 4. 文件修改清单

   - `src/views/AIROperationOptimization.vue` - AI运营优化建议页面组件

   - `src/views/Decision.vue` - 添加AI运营优化建议导航菜单项
