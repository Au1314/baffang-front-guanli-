# 完善个人资料页面

**将个人资料改为个人中心页面**

## 一、需求分析

1. **页面功能**：

   * 显示管理员的基本信息，包括用户名、网名、头像、创建时间、最后登录时间等

   * 允许管理员修改个人信息，如网名、头像等

   * 允许管理员修改密码

   * 显示管理员类型和权限信息

   * 确保界面美观、易用

2. **技术栈**：

   * Vue 3 Composition API

   * Element Plus组件库

   * Pinia状态管理

   * Vue Router路由管理

   * Axios网络请求

3. **数据结构**：

   * 管理员表包含id、username、name、password、avatar、create\_time、update\_time、type、is\_deleted、last\_login\_time等字段

   * 页面需要展示其中的关键信息

   * 部分字段（如用户名、类型、创建时间等）应该是只读的

3. **添加路由配置**：

## 四、技术实现

1. **创建Profile.vue组件**：

   * 使用Element Plus的Card组件创建页面布局

   * 使用Form组件实现信息修改和密码修改表单

   * 使用Upload组件实现头像上传

   * 使用Input组件实现文本输入

   * 使用Button组件实现提交和取消按钮

2. **添加API接口**：

   ```javascript
   // 获取管理员信息
   getAdminInfo() {
     return request.get('/auth/info')
   },

   // 更新管理员信息
   updateAdminInfo(data) {
     return request.put('/auth/info', data)
   },

   // 修改密码
   changePassword(data) {
     return request.put('/auth/password', data)
   }
   ```

3. **添加路由配置**：

   ```javascript
   {
     path: '/profile',
     name: 'Profile',
     component: () => import('@/views/Profile.vue'),
     meta: {
       requiresAuth: true,
       title: '个人资料',
       hideLayout: false
     }
   }
   ```

4. **实现数据绑定和事件处理**：

   * 使用`useAdminStore`获取管理员信息

   * 实现表单验证规则

   * 实现`handleUpdateInfo`方法处理信息更新

   * 实现`handleChangePassword`方法处理密码修改

   * 实现`handleAvatarUpload`方法处理头像上传
