## 实现平台统计功能

### 需求分析
- 统计功能面向普通管理员和超级管理员开放
- 展示以下统计数据：
  1. 用户总数
  2. 用户日活
  3. 私桩认证量
  4. 车主认证量
  5. 私桩分布数据（图表展示）
  6. 交易数据（图表展示）
- 当前使用虚拟数据，后续对接真实接口

### 实现计划

1. **在PlatformManage.vue中添加统计标签页**
   - 使用Element Plus的统计卡片展示基础数据
   - 使用echarts展示图表数据
   - 包含两个图表：私桩分布饼图、交易趋势折线图

2. **添加虚拟统计数据**
   - 创建模拟数据展示用户总数、日活、认证量等
   - 模拟私桩分布数据用于饼图
   - 模拟交易数据用于折线图

3. **添加API接口**
   - 在auth.js中添加获取统计数据的方法
   - 添加获取私桩分布数据的方法
   - 添加获取交易数据的方法

4. **更新路由权限**
   - 统计功能对普通管理员和超级管理员开放

### 技术实现
- 使用Vue 3 Composition API
- 使用echarts进行数据可视化
- 使用Element Plus的el-card、el-row、el-col等组件布局
- 响应式设计，适配不同屏幕尺寸

### 预计修改的文件
- `src/views/PlatformManage.vue`：添加统计标签页
- `src/api/auth.js`：添加统计相关的API接口

### 预期效果
- 平台管理页面新增"数据统计"标签页
- 页面顶部展示4个关键指标卡片
- 页面中部展示两个数据图表
- 数据展示清晰、美观、易于理解
- 支持响应式布局
