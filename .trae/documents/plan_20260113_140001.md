# AI异常检测页面显示问题修复方案

## 1. 问题分析

### 1.1 页面未显示原因
- **路由配置缺失**：在`router/index.js`中没有为AI异常检测页面添加路由配置
- **导航菜单缺失**：在`Decision.vue`中没有为AI异常检测页面添加导航菜单项

### 1.2 API 403错误
- 控制台显示多个API请求返回403 Forbidden错误
- 这是系统级别的认证/权限问题，不是AI异常检测功能本身的问题
- 可能需要后端人员配合检查API配置和权限设置

## 2. 修复步骤

### 2.1 添加路由配置
- 在`router/index.js`的决策模块子路由中添加AI异常检测页面路由
- 路径：`/decision/anomaly-detection`
- 名称：`AIAnomalyDetection`
- 组件：`@/views/AIAnomalyDetection.vue`

### 2.2 添加导航菜单项
- 在`Decision.vue`的水平菜单中添加AI异常检测菜单项
- 索引：`/decision/anomaly-detection`
- 显示文本：`AI异常检测`

## 3. 修复文件清单

1. **修改文件**：
   - `src/router/index.js` - 添加AI异常检测页面路由
   - `src/views/Decision.vue` - 添加AI异常检测导航菜单项

## 4. 预期效果

- AI异常检测页面将在决策模块的导航菜单中显示
- 点击菜单项可正常访问AI异常检测页面
- 页面表单和功能正常显示
- API 403错误需要后端配合解决，但不影响页面显示

## 5. 修复优先级

- **高优先级**：添加路由配置和导航菜单项，确保页面可以正常访问
- **中优先级**：后续观察API请求情况，如有必要与后端团队配合解决403问题
