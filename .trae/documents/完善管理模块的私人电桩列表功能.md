# 创建独立的私人电桩管理页面方案

## 1. 需求分析
- 现有系统已实现获取单个私桩详情的API：`GET /api/v1/admin/private-station/{id}`
- 已提供获取私桩列表的API：`GET /api/v1/admin/private-station/page`
- 需要创建独立的私人电桩管理页面，支持查看、筛选和分页
- 实现私桩详情查看功能
- 遵循现有系统的设计风格和权限控制

## 2. API信息分析

### 2.1 获取私桩列表API
- **URL**: `GET /api/v1/admin/private-station/page`
- **参数**:
  - `pageNum`: 页码，默认1
  - `pageSize`: 每页条数，默认10
  - `name`: 私桩名称（模糊查询）
  - `status`: 状态（0:空闲/1:已预约/2:充电中/3:异常）
  - `authStatus`: 认证状态（0:未认证/1:审核中/2:已认证/3:认证失败）
  - `type`: 类型（0:普通/1:专业）
  - `openStatus`: 开放状态（0:关闭/1:开启）
  - `ownerId`: 所有者ID
- **响应格式**:
  ```json
  {
    "code": 200,
    "data": {
      "total": 5,
      "pages": 1,
      "pageNum": 1,
      "pageSize": 10,
      "list": [/* 私桩列表项 */]
    },
    "msg": "OK"
  }
  ```

### 2.2 获取私桩详情API
- **URL**: `GET /api/v1/admin/private-station/{id}`
- **响应格式**：包含私桩的详细信息，如名称、位置、价格、状态等

## 3. 实现方案

### 3.1 路由配置添加
- 在 `src/router/index.js` 中添加新的私人电桩管理路由
- 设置正确的权限控制，只有管理员可以访问

### 3.2 页面组件创建
- 创建新的页面组件 `src/views/PrivateStationManage.vue`
- 实现私桩列表展示、筛选和分页功能
- 实现私桩详情查看功能

### 3.3 API层扩展
- 在 `src/api/auth.js` 中添加获取私桩列表和详情的API函数

## 4. 具体实现步骤

### 4.1 路由配置添加
在 `src/router/index.js` 的 routes 数组中添加以下路由：
```javascript
{
  path: '/private-station-manage',
  name: 'PrivateStationManage',
  component: () => import('@/views/PrivateStationManage.vue'),
  meta: {
    requiresAuth: true,
    title: '私人电桩管理',
    hideLayout: false,
    permission: ['超级管理员', '普通管理员']
  }
}
```

### 4.2 API函数添加
在 `auth.js` 中添加以下API函数：
```javascript
// 私人电桩管理相关API
// 获取私桩列表
getPrivateStationList(params) {
  return request.get('/admin/private-station/page', { params })
},
// 获取私桩详情
getPrivateStationDetail(id) {
  return request.get(`/admin/private-station/${id}`)
}
```

<script setup>
import { ref, reactive, onMounted } from 'vue'
import { ElMessage } from 'element-plus'
import { authApi } from '@/api/auth'

// 私人电桩管理
const privateStationList = ref([])
const privateStationTotal = ref(0)
const privateStationPage = ref(1)
const privateStationPageSize = ref(20)
const privateStationLoading = ref(false)
const showPrivateStationDetail = ref(false)
const currentPrivateStation = ref(null)

const privateStationFilter = reactive({
  name: '',
  status: null,
  authStatus: null,
  type: null,
  openStatus: null
})

// 获取私桩列表
const fetchPrivateStationList = async () => {
  try {
    privateStationLoading.value = true
    const params = {
      pageNum: privateStationPage.value,
      pageSize: privateStationPageSize.value,
      name: privateStationFilter.name,
      status: privateStationFilter.status,
      authStatus: privateStationFilter.authStatus,
      type: privateStationFilter.type,
      openStatus: privateStationFilter.openStatus
    }
    
    const response = await authApi.getPrivateStationList(params)
    if (response.code === 200 && response.data) {
      privateStationList.value = response.data.list || []
      privateStationTotal.value = response.data.total || 0
    } else {
      ElMessage.error(response.msg || '获取私桩列表失败')
    }
  } catch (error) {
    console.error('获取私桩列表失败:', error)
    ElMessage.error('获取私桩列表失败')
  } finally {
    privateStationLoading.value = false
  }
}

// 重置筛选条件
const resetPrivateStationFilter = () => {
  privateStationFilter.name = ''
  privateStationFilter.status = null
  privateStationFilter.authStatus = null
  privateStationFilter.type = null
  privateStationFilter.openStatus = null
  fetchPrivateStationList()
}

// 分页大小变化
const handlePrivateStationSizeChange = (size) => {
  privateStationPageSize.value = size
  privateStationPage.value = 1
  fetchPrivateStationList()
}

// 页码变化
const handlePrivateStationPageChange = (page) => {
  privateStationPage.value = page
  fetchPrivateStationList()
}

// 查看私桩详情
const handleViewPrivateStationDetail = async (station) => {
  try {
    privateStationLoading.value = true
    const response = await authApi.getPrivateStationDetail(station.id)
    if (response.code === 200 && response.data) {
      currentPrivateStation.value = response.data
      showPrivateStationDetail.value = true
    } else {
      ElMessage.error(response.msg || '获取私桩详情失败')
    }
  } catch (error) {
    console.error('获取私桩详情失败:', error)
    ElMessage.error('获取私桩详情失败')
  } finally {
    privateStationLoading.value = false
  }
}

// 组件挂载时获取私桩列表
onMounted(() => {
  fetchPrivateStationList()
})
</script>
