# 修复AI风险评估API调用403错误

## 1. 问题分析

* AI风险评估API调用返回403 Forbidden错误

* 从Postman截图来看，API的正确调用方式是：
  - 请求方式：POST
  - 参数：businessType和businessId作为Query参数传递

* 当前代码中，参数是作为Body参数传递的，这可能是导致403错误的原因

## 2. 解决方案

### 2.1 修复方案

修改`riskAssessment`方法，将参数从Body参数改为Query参数传递。

### 2.2 实现步骤

1. **修改auth.js中的riskAssessment方法**

2. **测试修复结果**

## 3. 实现步骤

### 3.1 第一步：修改riskAssessment方法

在`src/api/auth.js`中修改`riskAssessment`方法，将参数改为Query参数传递：

```javascript
// AI风险评估
riskAssessment(params) {
  return request.post('ai/decision/risk/assess', {}, {
    params,
    timeout: 180000 // 3分钟超时
  })
}
```

### 3.2 第二步：测试修复结果

* 访问AI风险评估页面（/decision/risk-assessment）
* 输入业务类型和业务ID
* 点击"提交评估"按钮
* 验证API调用是否成功，返回200状态码
* 查看评估结果是否正常显示

## 4. 预期效果

* AI风险评估API调用返回200状态码
* 成功获取风险评估结果
* 页面正常显示评估结果
* 控制台不再出现403错误
