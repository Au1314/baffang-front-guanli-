# 实现统计模块智能体快速分析功能

## 需求分析
用户需要在统计模块中添加智能体快速分析功能，通过调用AI接口来分析用户问题并返回详细的分析报告。

## 现有代码结构
- 统计模块主页面：`views/Statistics.vue`
- 统计指标组件：`views/StatisticsMetrics.vue`
- 统计图表组件：`views/StatisticsCharts.vue`
- API请求封装：`api/auth.js`

## 实现方案

### 1. 添加AI分析API调用方法
在`api/auth.js`中添加快速分析API调用方法：
```javascript
// AI快速分析
export const quickAnalysis(question) {
  return request.get('/ai/analysis/quick', { params: { question } })
}
```

### 2. 创建智能分析组件
创建新组件`views/StatisticsAnalysis.vue`，包含：
- 问题输入框
- 分析请求按钮
- 分析结果展示区域
- 加载状态处理

### 3. 集成到统计主页面
在`views/Statistics.vue`中：
- 引入新组件
- 添加智能分析功能区域
- 设计合适的布局，与现有统计内容融合

### 4. 设计UI交互
- 使用Element Plus的输入框、按钮、卡片、加载状态等组件
- 分析结果使用富文本展示，支持Markdown格式
- 添加适当的动画和过渡效果

### 5. 实现核心功能
- 问题输入与提交
- API请求处理
- 加载状态管理
- 分析结果展示
- 错误处理

## 预期效果
用户进入统计页面后，可以在智能分析区域输入问题（如"用户总数"），点击分析按钮后，系统调用AI接口获取分析报告并展示在页面上。

## 技术栈
- Vue 3
- Element Plus
- Axios
- Markdown渲染（使用现有依赖或引入新库）
