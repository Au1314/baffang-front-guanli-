# 批量发送通知错误分析与解决方案

## 错误分析

从错误信息可以看出，批量发送通知时出现了API错误，返回错误码1000，提示"用户列表不能为空"。分析发现问题在于：

1. **参数名不匹配**：前端表单使用`userIds`，但后端API期望的是`userids`（全小写）
2. **数据结构问题**：前端处理用户ID的方式可能与后端API期望的不一致
3. **验证触发问题**：表单验证规则可能需要调整

## 解决方案

### 1. 修正参数名
- 确保前端发送的参数名与后端API期望的一致
- 检查auth.js中的API方法，确认正确的参数名

### 2. 优化用户ID处理逻辑
- 修改用户ID处理代码，确保生成的数组不为空
- 增强分隔符处理，支持多种分隔符（逗号、空格、分号等）

### 3. 改进表单验证
- 调整表单验证规则，确保只有在字段有值时才进行验证
- 添加字段级别的条件验证

### 4. 添加调试信息
- 在发送请求前添加调试日志，便于排查问题

## 实现步骤

1. **检查并修正auth.js中的API参数名**
2. 更新NoticeBatchSend.vue组件的用户ID处理逻辑
3. 优化表单验证规则，确保可选字段正确处理
4. 添加调试日志
5. 测试不同场景下的批量发送功能

## 预期效果

- 支持多种分隔符输入用户ID
- 确保用户ID数组不为空
- 正确处理可选字段验证
- 提供清晰的错误提示
- 成功发送批量通知
