# 完善私桩认证详情功能实现方案

## 1. 问题分析
- 现有实现直接使用列表行数据显示详情，未调用最新API获取完整数据
- 新API响应包含更丰富的审核信息，特别是`auditInfo`对象
- 需要更新详情页面以展示所有新数据字段

## 2. 实现方案

### 2.1 修改API调用逻辑
- 修改`handleViewDetail`方法，调用`getPrivateStationAuthDetail` API获取最新详情数据
- 确保API请求使用正确的路径参数`stationId`

### 2.2 更新详情弹窗布局

#### 2.2.1 电桩基本信息部分
- 保留现有字段：电桩ID、电桩名称、所有者ID、所有者姓名、所有者电话、地址、默认价格、定价类型、充电枪数量、是否公开、电桩状态、创建时间
- 添加新字段：更新时间、所有者邮箱、所有者头像、经纬度坐标、所有者认证车辆信息、所有者认证充电站点信息

#### 2.2.2 审核信息部分
- 扩展现有审核信息展示，增加`auditInfo`对象中的所有字段：
  - 审核状态、当前状态名称、优先级、优先级名称
  - 提交时间、完成时间、最终意见、拒绝原因
  - 审核日志列表：显示所有审核操作记录，包括操作人、操作时间、操作类型、状态变更、审核意见等

### 2.3 优化数据展示
- 使用Element Plus组件优化数据展示，如标签、时间格式化等
- 审核日志使用表格形式展示，清晰呈现状态流转
- 处理空值情况，确保页面显示友好

## 3. 具体修改点

### 3.1 修改`handleViewDetail`方法
```javascript
const handleViewDetail = async (row) => {
  try {
    detailLoading.value = true
    // 调用API获取最新详情数据
    const response = await authApi.getPrivateStationAuthDetail(row.id)
    currentAudit.value = response.data || {}
    showAuditDetail.value = true
  } catch (error) {
    console.error('获取审核详情失败:', error)
    ElMessage.error('获取审核详情失败')
  } finally {
    detailLoading.value = false
  }
}
```

### 3.2 更新详情弹窗模板
- 扩展`<el-descriptions>`组件，添加新的字段展示
- 在审核信息部分添加审核日志表格

### 3.3 调整审核条件判断
- 更新审核按钮的显示条件，适应新的`auditInfo.currentStatus`字段

## 4. 预期效果
- 详情页面显示完整的私桩认证信息，包括所有新API返回的字段
- 审核日志清晰展示审核流程和状态变更
- 页面布局合理，数据展示友好
- API调用正常，数据获取及时准确
