# 待接入对话列表API集成方案

## 1. 添加API接口定义
在 `src/api/auth.js` 中添加获取待接入对话列表的API方法：
```javascript
// 获取待接入对话列表
getPendingChatList(params) {
  return request.get('/customer-service/pending', { params })
}
```

## 2. 更新WebSocket服务
在 `CustomerServiceWS.js` 中，确保 `CONVERSATIONS` 事件处理器能正确处理新的会话数据结构。

## 3. 修改fetchPendingChatList函数
将 `CustomerService.vue` 中的 `fetchPendingChatList` 函数从使用WebSocket改为使用API调用：
```javascript
const fetchPendingChatList = async () => {
  try {
    chatListLoading.value = true
    const response = await authApi.getPendingChatList({
      pageNum: 1,
      pageSize: 10,
      keyword: chatFilter.keyword
    })
    pendingChatList.value = response.data.list || []
  } catch (error) {
    console.error('获取待接入对话失败:', error)
    ElMessage.error('获取待接入对话失败')
  } finally {
    chatListLoading.value = false
  }
}
```

## 4. 更新UI显示
修改会话列表项，显示更多用户信息：
- 显示用户姓名和头像
- 显示等待时间
- 显示用户手机号（脱敏处理）
- 优化会话项布局

## 5. 协同WebSocket和API
- API用于初始化加载会话列表
- WebSocket用于实时更新会话状态和接收新会话通知
- 确保两者的数据结构兼容

## 6. 添加分页支持
为待接入对话列表添加分页功能，支持pageNum和pageSize参数

## 7. 优化用户体验
- 添加会话排序（按等待时间）
- 为长时间等待的会话添加视觉提示
- 优化空状态显示

## 8. 测试和验证
- 测试API调用是否正常
