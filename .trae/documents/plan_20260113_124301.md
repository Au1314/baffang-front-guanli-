## 修复方案

1. **检查 API 返回数据结构**：确认 API 返回的决策详情数据是否在 `response.data.data` 中，而非 `response.data`
2. **修复 `fetchDecisionDetail` 方法**：调整数据赋值逻辑，确保 `decisionDetail` 正确获取数据
3. **添加数据初始化**：确保 `decisionDetail` 初始状态有合理的默认值
4. **检查 `showDecisionDetail` 方法**：确认该方法正确调用了 `fetchDecisionDetail`
5. **确保弹窗显示时机正确**：在 `decisionDetail` 赋值完成后再显示弹窗
