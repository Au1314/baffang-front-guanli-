# 论坛管理帖子列表查询功能更新方案

## 功能需求
根据提供的新API响应结构，更新论坛管理模块下的帖子列表查询功能，确保正确解析新的响应格式。

## 新API响应结构
```json
{
  "code": 200,
  "data": {
    "total": 10,
    "pages": 1,
    "pageNum": 1,
    "pageSize": 10,
    "list": [
      // 帖子列表
    ]
  },
  "msg": "OK"
}
```

## 实现方案

### 1. 更新帖子列表查询功能
- 修改 `fetchPostList` 函数，从 `response.data.list` 获取帖子列表，从 `response.data.total` 获取总数
- 确保分页逻辑正常工作

### 2. 检查并更新评论列表查询功能
- 检查 `fetchCommentList` 函数的实现
- 如果需要，更新为从 `response.data.list` 和 `response.data.total` 获取数据

### 3. 检查并更新举报列表查询功能
- 检查 `fetchPostReportList` 和 `fetchCommentReportList` 函数
- 如果需要，更新为从 `response.data.list` 和 `response.data.total` 获取数据

### 4. 测试功能
- 确保所有列表查询功能正常工作
- 验证分页、筛选等功能不受影响

## 预期效果
- 帖子列表、评论列表和举报列表都能正确解析新的API响应
- 所有列表查询功能正常工作
- 分页、筛选等功能保持不变

## 实现步骤
1. 修改 `fetchPostList` 函数，更新帖子列表获取逻辑
