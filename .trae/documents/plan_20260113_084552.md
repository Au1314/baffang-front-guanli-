# 实现所有客服统计功能计划

## 1. 添加API调用
- 在`src/api/auth.js`中添加获取所有客服统计API调用方法
- API路径：`/customer-service/stats/admins`
- 请求方法：GET
- 返回数据：客服统计列表

## 2. 创建所有客服统计页面
- 在`src/views/`目录下创建`StatisticsAllCustomerService.vue`组件
- 展示所有客服的统计数据，包括：adminId、adminName、今日接待量、今日完成量、进行中量、消息量、平均响应时间
- 使用表格形式展示，支持排序和筛选
- 添加数据加载状态和错误处理

## 3. 添加路由配置
- 在`src/router/index.js`中添加所有客服统计页面路由
- 路径：`/statistics/all-customer-service`
- 权限：超级管理员、普通管理员

## 4. 更新统计模块主页面
- 在`src/views/Statistics.vue`中添加所有客服统计入口按钮
- 按钮位置：在现有操作栏中添加

## 5. 数据转换处理
- 对API返回的`avgResponseTime`（平均响应时间）进行格式转换
- 将秒转换为更友好的格式（如：分:秒）
- 使用计算属性实现实时数据转换

## 6. 功能增强
- 添加表格排序功能，可按各项指标排序
- 添加表格筛选功能，可按管理员名称搜索
- 添加数据总览信息（如：总客服数、平均数据等）
- 支持导出数据功能（可选）

## 7. 测试功能
- 确保页面能正常访问
- 确保数据能正确加载和展示
- 确保路由权限控制正常
- 确保数据转换处理正确

## 技术栈
- Vue 3 + Element Plus
- 响应式数据处理
- 组件化开发
- 路由管理
- Element Plus Table组件
- 计算属性

## 预期效果
- 管理员可以查看所有客服的统计数据
- 数据展示清晰直观，支持排序和筛选
- 页面风格与现有统计模块保持一致
- 平均响应时间显示友好的分:秒格式

## 代码结构
- 遵循现有项目的代码风格和组件结构
- 利用现有的API调用模式
- 组件化设计，便于维护和扩展
