# 恢复待处理状态的手动执行按钮显示

## 1. 问题分析

* 用户要求改为待处理状态也显示手动执行按钮

* 当前实现中，待处理状态（status=0）的决策不显示手动执行按钮

* 需要调整手动执行按钮的显示条件，重新添加待处理状态

## 2. 解决方案

### 2.1 修复方案

修改手动执行按钮的显示条件，重新添加待处理状态（status=0），允许在待处理状态的决策上执行手动执行操作。

### 2.2 实现步骤

1. **修改操作列，调整手动执行按钮的显示条件**

2. **测试修复结果**

## 3. 实现步骤

### 3.1 第一步：修改手动执行按钮的显示条件

在`src/views/DecisionList.vue`中修改手动执行按钮的显示条件，重新添加status=0：

```html
<el-button v-if="!scope.row.autoExecute && [0, 1, 3, 6].includes(scope.row.status)" type="warning" size="small" @click.stop="executeDecision(scope.row)">手动执行</el-button>
```

### 3.2 第二步：测试修复结果

* 访问决策列表页面

* 验证待处理状态的决策是否显示手动执行按钮

* 验证已处理状态的决策是否正常显示手动执行按钮

* 测试手动执行功能是否正常工作

## 4. 预期效果

* 待处理状态（status=0）的决策显示手动执行按钮

* 已处理状态（status=1、3、6）的决策正常显示手动执行按钮

* 手动执行功能正常工作
