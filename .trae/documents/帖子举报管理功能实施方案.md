# 帖子举报管理功能实施方案

## 1. 需求分析
根据用户反馈，帖子举报列表功能应该放在论坛管理模块，而不是审核管理模块。论坛管理模块已经有一个"举报管理"标签页，但需要优化以支持专门的帖子举报功能。

## 2. 现有结构分析
- 论坛管理模块（ForumManage.vue）包含三个标签页：帖子管理、评论管理、举报管理
- 现有举报管理使用通用举报列表API（/forum/report/list）
- 我们需要添加专门的帖子举报列表API支持（/forum/report/post/list）

## 3. 实施方案

### 3.1 调整路由配置
- 删除之前在审核管理模块中添加的帖子举报路由

### 3.2 优化论坛管理模块的举报管理标签页
- 增强举报筛选功能，添加举报类型筛选
- 支持帖子举报和其他类型举报的区分显示
- 使用帖子举报专用API获取帖子举报列表

### 3.3 完善API调用
- 保留已添加的getPostReportList API方法
- 确保举报审核功能正常工作

### 3.4 优化举报详情展示
- 确保帖子举报详情完整展示
- 优化举报审核流程

## 4. 具体实现步骤

1. **删除审核管理模块中的帖子举报路由**
   - 修改 src/router/index.js，删除post-report路由配置
   - 修改 src/views/Audit.vue，删除左侧菜单中的帖子举报菜单项
   - 修改 src/views/Audit.vue，删除currentTitle中的帖子举报标题映射

2. **优化论坛管理模块的举报管理标签页**
   - 修改 src/views/ForumManage.vue，增强举报筛选功能
   - 添加举报类型筛选条件
   - 根据筛选条件调用不同的API（通用举报列表或帖子举报列表）

3. **完善举报列表展示**
   - 优化举报列表字段，确保帖子举报相关字段正确显示
   - 增强举报详情展示，显示帖子举报特有的字段

4. **测试功能完整性**
   - 测试帖子举报列表查询功能
   - 测试举报筛选功能
   - 测试举报详情查看功能
   - 测试举报审核功能

## 5. 预期效果
- 帖子举报功能整合到论坛管理模块中
- 支持帖子举报的筛选、查看和审核
- 与现有论坛管理功能无缝集成
- 提供良好的用户体验

## 6. 技术要点
- 使用Vue 3 Composition API
- 基于Element Plus组件库
- 遵循现有的代码风格和架构
- 确保功能完整性和稳定性
