# 添加投诉和故障审核优先级设置功能

## 1. 实现目标
在已有的投诉和故障审核功能基础上，添加完整的优先级设置选项，允许审核人员在审核时设置或修改优先级。

## 2. 实现范围
- `src/views/ChargingComplaintAudit.vue` - 充电桩投诉审核
- `src/views/ChargingFaultAudit.vue` - 充电桩故障审核

## 3. 技术方案

### 3.1 优先级设置设计
- 在审核对话框中添加优先级选择下拉框
- 优先级选项：低（0）、普通（1）、高（2）、紧急（3）
- 支持清空选择（可选字段）
- 保持现有审核流程不变

### 3.2 表单数据结构调整
- 在`auditForm`中添加`priority`字段
- 初始值为空
- 提交时转换为数字类型

### 3.3 API调用调整
- 利用已有的API参数结构，`priority`字段已包含在API调用中
- 为空时自动转换为`null`

## 4. 具体实现步骤

### 4.1 修改 `ChargingComplaintAudit.vue`
1. **更新审核表单数据**：在`auditForm`中添加`priority`字段
2. **修改审核对话框模板**：添加完整优先级选择组件
3. **保持API调用不变**：已有代码已支持优先级参数

### 4.2 修改 `ChargingFaultAudit.vue`
1. **更新审核表单数据**：在`auditForm`中添加`priority`字段
2. **修改审核对话框模板**：添加完整优先级选择组件
3. **保持API调用不变**：已有代码已支持优先级参数

## 5. 实现细节

### 5.1 优先级选择组件

```vue
<el-form-item label="优先级">
  <el-select v-model="auditForm.priority" placeholder="请选择优先级" clearable>
    <el-option label="低" value="0"></el-option>
    <el-option label="普通" value="1"></el-option>
    <el-option label="高" value="2"></el-option>
    <el-option label="紧急" value="3"></el-option>
  </el-select>
</el-form-item>
```

### 5.2 表单数据更新

```javascript
// 审核表单数据
const auditForm = reactive({
  action: '',
  opinion: '',
  priority: '' // 添加优先级字段
})
```

### 5.3 API调用处理
- 提交审核时自动转换为数字类型：`priority: parseInt(auditForm.priority) || null`
- 已有代码中API调用部分已包含此处理

## 6. 预期效果
- 审核对话框中新增优先级选择下拉框，包含四个级别
- 支持选择低、普通、高、紧急优先级，也可清空不设置
- 审核提交时正确传递优先级参数
- 不影响现有审核功能流程

## 7. 测试要点
- 优先级选择是否正常显示所有四个级别
- 选择不同优先级后是否正确提交到API
- 不选择优先级时是否正常提交
- 审核成功后优先级是否更新

## 8. 注意事项
- 优先级为可选字段，不影响必填项验证
- 确保与现有API参数格式兼容
- 保持UI风格一致性
