# 实现故障/投诉统计功能方案

## 1. 功能需求
根据API返回的故障/投诉统计数据，实现一个故障/投诉统计页面，展示以下信息：
- 投诉统计（投诉总数、待处理投诉、处理中投诉、已通过投诉、已拒绝投诉）
- 故障统计（故障总数、待处理故障、处理中故障、已通过故障、已拒绝故障）
- 紧急情况统计（紧急总数）
- 今日统计（今日故障/投诉总数）

## 2. 实现步骤

### 2.1 API调用实现
在`src/api/auth.js`中添加获取故障/投诉统计信息的方法：
```javascript
// 获取故障/投诉统计信息
getComplaintStatistics() {
  return request.get('/complaint/statistics')
}
```

### 2.2 组件创建
创建`src/views/StatisticsComplaint.vue`组件，包含以下功能：
- 数据加载和刷新功能
- 投诉统计展示（使用卡片布局）
- 故障统计展示（使用卡片布局）
- 紧急情况和今日统计展示
- 加载状态和错误处理

### 2.3 路由配置
在`src/router/index.js`中添加故障/投诉统计路由：
```javascript
{
  path: '/statistics/complaint',
  name: 'StatisticsComplaint',
  component: () => import('@/views/StatisticsComplaint.vue'),
  meta: {
    requiresAuth: true,
    title: '故障/投诉统计',
    hideLayout: false,
    permission: ['超级管理员', '普通管理员', '审核员', '客服']
  }
}
```

### 2.4 入口按钮添加
在`src/views/Statistics.vue`的action-bar中添加故障/投诉统计入口按钮：
```html
<el-button type="primary" plain @click="$router.push('/statistics/complaint')">故障/投诉统计</el-button>
```

## 3. 数据转换处理
根据API返回的数据结构，组件将直接使用返回的数据，无需额外转换，因为字段名和展示需求匹配：
- 投诉统计：`complaintTotal`, `complaintPending`, `complaintProcessing`, `complaintPassed`, `complaintRejected`
- 故障统计：`faultTotal`, `faultPending`, `faultProcessing`, `faultPassed`, `faultRejected`
- 紧急情况：`urgentCount`
- 今日统计：`todayCount`

## 4. 技术栈
- Vue 3 + Element Plus
- Axios用于API调用
- Vue Router用于路由管理
- 响应式设计，适配不同屏幕尺寸

## 5. 预期效果
- 故障/投诉统计页面展示清晰的投诉和故障统计数据
- 支持数据刷新功能
- 包含加载状态和错误处理
- 界面美观，交互友好
