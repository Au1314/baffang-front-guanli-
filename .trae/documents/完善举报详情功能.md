# 完善举报详情功能实现方案

## 1. 问题分析
- 当前已存在 `PostReportAudit.vue` 组件，包含举报列表和详情对话框
- `authApi` 中已实现 `getReportDetail` 方法，但需确认路径是否与后端API匹配
- 详情对话框需完善以显示所有返回字段
- 附件列表需优化处理返回数据
- 需确保帖子举报和评论举报都能使用同一详情功能

## 2. 实现方案

### 2.1 调整API路径
- 检查 `authApi.js` 中 `getReportDetail` 方法的路径
- 确保路径与后端API `/forum/report/{id}` 匹配

### 2.2 完善详情对话框
- 在 `PostReportAudit.vue` 中添加缺失的字段显示：
  - 举报人用户名、电话
  - 被举报人ID、头像
  - 审核完成时间
  - 业务ID
- 确保所有字段根据API返回数据动态显示

### 2.3 优化附件处理
- 添加附件链接清理逻辑，处理返回数据中的空格和引号
- 实现附件列表的格式化显示
- 添加文件类型识别和图标显示（可选）

### 2.4 完善数据处理
- 确保 `handleViewDetail` 方法正确处理API返回数据
- 添加错误处理和加载状态管理
- 确保组件能够同时处理帖子举报和评论举报数据

### 2.5 验证功能完整性
- 测试点击详情按钮能否正确显示弹窗
- 验证所有字段是否正确显示
- 测试附件链接是否可正常访问
- 确保帖子举报和评论举报都能正常显示详情

## 3. 预期效果
- 点击举报列表中的详情按钮，弹出详情对话框
- 对话框显示完整的举报信息，包括举报人、被举报人、举报内容、被举报内容等
- 附件列表正确显示所有附件链接
- 支持帖子举报和评论举报详情查看
- 界面美观，交互流畅

## 4. 技术要点
- 使用Vue 3 + Element Plus实现
- 遵循现有的代码风格和架构
- 确保API调用和数据处理的健壮性
- 优化用户体验，添加适当的加载状态和错误提示
