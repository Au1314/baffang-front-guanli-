## 注册页面头像上传功能实现计划

### 1. 图标导入修改
- 添加所需图标：PictureFilled、Delete、Upload

### 2. 表单数据修改
- 在 registerForm 中添加 avatar 字段
- 添加 avatarFileList 用于文件列表管理
- 添加 imageUrl 用于头像预览

### 3. 头像上传组件添加
- 在昵称和用户名之间添加头像上传区域
- 使用 Element Plus 的 el-upload 组件
- 支持单张图片上传
- 限制文件类型为 JPG/PNG/GIF
- 限制文件大小为 2MB

### 4. 头像处理逻辑
- 实现 handleAvatarChange 函数处理文件选择
- 实现 beforeAvatarUpload 函数验证文件
- 实现 removeAvatar 函数删除头像
- 实现 readFileAsDataURL 函数预览图片

### 5. 注册API修改
- 修改 registerData 包含 avatar 字段
- 确保字段名称与后端接口一致（后端使用 name 作为昵称字段）

### 6. 样式添加
- 添加头像上传区域样式
- 添加预览图样式
- 添加删除按钮样式
- 添加提示文字样式

### 7. 字段名称修正
- 后端接口使用 name 作为昵称字段，确保注册时使用正确的字段名

### 8. 邀请码字段修正
- 后端接口使用 invitecode（小写），确保注册时使用正确的字段名
