# 获取通知详情功能实现方案

## 功能需求

在现有通知列表功能基础上，添加获取通知详情功能，要求：
1. 点击通知列表项可显示详情
2. 使用弹出框显示通知详情
3. 注意处理冒泡事件
4. 操作列添加查看详情按钮

## 实现方案

### 1. API服务层

在 `auth.js` 中添加获取通知详情的API方法：

```javascript
// 获取通知详情
getNoticeDetail(noticeId) {
  return request.get(`/notice/${noticeId}`)
}
```

### 2. 详情弹窗组件

在 `NoticeList.vue` 中添加Element Plus的 `el-dialog` 组件，用于显示通知详情：

```vue
<!-- 通知详情弹窗 -->
<el-dialog
  v-model="detailVisible"
  title="通知详情"
  width="600px"
  @close="handleDetailClose"
>
  <div v-if="detailLoading" class="detail-loading">
    <el-skeleton :rows="6" animated />
  </div>
  <div v-else class="notice-detail">
    <div class="detail-item">
      <label>通知标题：</label>
      <span>{{ noticeDetail.title }}</span>
    </div>
    <div class="detail-item">
      <label>通知类型：</label>
      <el-tag :type="getTypeTagType(noticeDetail.type)">{{ noticeDetail.typeName }}</el-tag>
    </div>
    <div class="detail-item">
      <label>接收用户：</label>
      <span>{{ noticeDetail.userName }}</span>
    </div>
    <div class="detail-item">
      <label>是否已读：</label>
      <el-tag :type="noticeDetail.isRead === 1 ? 'success' : 'warning'">
        {{ noticeDetail.isRead === 1 ? '已读' : '未读' }}
      </el-tag>
    </div>
    <div class="detail-item">
      <label>创建时间：</label>
      <span>{{ noticeDetail.createTime }}</span>
    </div>
    <div class="detail-item">
      <label>阅读时间：</label>
      <span>{{ noticeDetail.readTime || '未读' }}</span>
    </div>
    <div class="detail-item content">
      <label>通知内容：</label>
      <div class="content-text">{{ noticeDetail.content }}</div>
    </div>
  </div>
</el-dialog>
```

### 3. 交互逻辑

#### 3.1 数据定义

在 `script setup` 中添加以下响应式数据：

```javascript
// 详情弹窗可见性
const detailVisible = ref(false)
// 详情加载状态
const detailLoading = ref(false)
// 通知详情数据
const noticeDetail = ref({})
```

#### 3.2 方法实现

添加以下方法：

```javascript
// 获取通知详情
const getNoticeDetail = async (noticeId) => {
  detailLoading.value = true
  try {
    const response = await authApi.getNoticeDetail(noticeId)
    noticeDetail.value = response
    detailVisible.value = true
    // 如果通知未读，标记为已读
    if (noticeDetail.value.isRead === 0) {
      await handleMarkAsRead(noticeDetail.value)
    }
  } catch (error) {
    ElMessage.error('获取通知详情失败')
    console.error('获取通知详情失败:', error)
  } finally {
    detailLoading.value = false
  }
}

// 处理列表行点击
const handleRowClick = (row) => {
  getNoticeDetail(row.id)
}

// 处理详情弹窗关闭
const handleDetailClose = () => {
  noticeDetail.value = {}
}

// 添加查看详情按钮点击事件
const handleViewDetail = (row) => {
  getNoticeDetail(row.id)
}
```

#### 3.3 事件绑定

1. 为表格添加行点击事件，使用 `.stop` 修饰符防止冒泡：

```vue
<el-table
  :data="noticeList"
  stripe
  border
  style="width: 100%"
  v-loading="loading"
  @selection-change="handleSelectionChange"
  @row-click.stop="handleRowClick"
>
```

2. 在操作列添加查看详情按钮：

```vue
<el-button
  type="primary"
  size="small"
  @click.stop="handleViewDetail(scope.row)"
>
  <el-icon><View /></el-icon>
  查看详情
</el-button>
```

## 预期效果

1. 点击通知列表项，弹出通知详情窗口
2. 操作列添加了"查看详情"按钮，点击也可弹出详情窗口
3. 弹窗显示通知的完整信息，包括标题、类型、接收用户、状态、时间和内容
4. 弹窗加载时显示骨架屏
5. 点击未读通知查看详情时，自动标记为已读
6. 点击弹窗外部或关闭按钮可关闭弹窗

## 技术要点

1. 使用Element Plus的Dialog组件实现弹窗
2. 使用Skeleton组件实现加载状态
3. 使用@row-click.stop防止事件冒泡
4. 实现了点击列表项和按钮两种查看详情方式
5. 查看未读通知时自动标记为已读
6. 详情内容使用了合适的样式和布局
