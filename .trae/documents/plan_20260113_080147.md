# 模块数据分析功能实施方案

## 一、功能概述
根据用户需求，需要在统计模块下添加模块数据分析功能，调用API `/ai/analysis/module` 获取指定模块的数据分析结果并展示。

## 二、技术方案

### 1. API 调用添加
在 `src/api/auth.js` 文件中添加模块数据分析API调用：
```javascript
// 模块数据分析
moduleAnalysis(data) {
  return request.post('/ai/analysis/module', data, {
    timeout: 180000 // 3分钟超时
  })
}
```

### 2. 视图组件创建
创建新的视图组件 `src/views/StatisticsModuleAnalysis.vue`，用于：
- **添加返回按钮**：方便用户返回统计模块首页
- 提供模块选择下拉框（包含platform、stationDistribution、vehicleAudit、complaint、auditRecord、forum、emergency、customerService）
- 提供问题输入框
- 控制是否包含原始数据
- 展示AI分析结果
- 处理rawData为null的情况
- 支持数据刷新

### 3. 路由配置
在 `src/router/index.js` 中添加新路由：
```javascript
{
  path: '/statistics/module-analysis',
  name: 'StatisticsModuleAnalysis',
  component: () => import('@/views/StatisticsModuleAnalysis.vue'),
  meta: {
    requiresAuth: true,
    title: '模块数据分析',
    hideLayout: false,
    permission: ['超级管理员', '普通管理员']
  }
}
```

### 4. 入口按钮添加
在 `src/views/Statistics.vue` 中添加模块数据分析入口按钮：
```vue
<el-button type="warning" @click="$router.push('/statistics/module-analysis')">模块数据分析</el-button>
```

## 三、数据处理
根据返回的响应结构，处理以下情况：
1. 当 `rawData` 为 null 时，显示数据缺失提示
2. 当 `rawData` 有数据时，根据不同模块展示相应数据
3. 格式化 `analysis` 字段的Markdown内容
4. 显示分析时间和处理耗时

## 四、UI 设计
- 使用 Element Plus 组件库构建响应式布局
- 采用卡片式设计展示不同模块数据
- **页面头部包含返回按钮**：与综合数据分析页面保持一致的用户体验
- 添加表单区域用于输入分析参数
- 支持加载状态和错误提示
- 清晰展示AI分析结论和优化建议

## 五、实现步骤
1. 添加API调用
2. 创建视图组件（包含返回按钮）
3. 配置路由
4. 添加入口按钮
5. 实现数据展示和UI设计
6. 测试功能完整性

## 六、预期效果
- 提供完整的模块数据分析功能
- 支持多种模块的数据分析
- 处理各种数据返回情况
- 提供良好的用户交互体验
- 与现有统计模块无缝集成
- 统一的返回按钮设计，提升用户体验
