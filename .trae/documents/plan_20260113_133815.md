## 实现方案：添加AI审核建议功能

### 1. 功能概述
在决策模块下添加一个新页面，实现AI审核建议功能，允许用户输入审核ID，获取AI生成的审核建议和分析结果。

### 2. 技术实现步骤

#### 步骤1：添加API方法
在 `src/api/auth.js` 中添加获取AI审核建议的API方法：
- 方法名：`getAIAuditSuggest`
- 请求URL：`/api/v1/admin/ai/decision/audit/suggest/{auditId}`
- 请求方式：POST
- 超时设置：3分钟（适应AI分析的长时间处理）

#### 步骤2：创建新页面组件
创建 `src/views/AIAuditSuggest.vue` 组件，包含以下功能：
- 审核ID输入表单（带验证）
- 提交按钮和加载状态
- 结果展示区域，包括：
  - 基本信息（决策ID、编号、置信度等）
  - AI分析结果（解析JSON格式的建议）
  - 详细分析文本
  - 建议操作列表
- 参数详情弹窗

#### 步骤3：更新路由配置
在 `src/router/index.js` 的决策模块路由下添加新路由：
- 路径：`/decision/audit-suggest`
- 名称：`AIAuditSuggest`
- 组件：`AIAuditSuggest.vue`
- 标题：AI审核建议

#### 步骤4：更新导航菜单
在 `src/views/Decision.vue` 的水平菜单中添加新菜单项：
- 索引：`/decision/audit-suggest`
- 文本：AI审核建议

### 3. 组件实现细节

#### 核心功能
1. **表单验证**：审核ID必填，且为数字
2. **API调用**：提交审核ID获取AI审核建议
3. **响应处理**：
   - 解析AI分析结果中的JSON部分（提取```json```包裹的内容）
   - 处理响应数据，转换为组件可用的格式
   - 显示AI建议、置信度、优先级等
4. **结果展示**：
   - 使用Element Plus的Descriptions、Table、Tag等组件展示数据
   - 高亮显示关键信息（如异常检测结果、优先级）
   - 支持查看操作参数详情
5. **用户体验**：
   - 添加加载状态
   - 错误提示
   - 结果复制功能

#### 数据处理
- 解析AI分析结果中的JSON内容
- 格式化参数显示
- 映射优先级和类型到可读文本

### 4. 预期效果

1. **页面访问**：通过决策模块菜单进入AI审核建议页面
2. **功能使用**：
   - 输入审核ID，点击提交
   - 等待AI分析完成（显示加载状态）
   - 查看AI生成的审核建议和详细分析
   - 查看建议的操作列表
   - 查看操作参数详情
3. **响应展示**：
   - 基本信息清晰展示
   - AI分析结果结构化显示
   - 建议操作直观呈现
   - 支持结果复制

### 5. 技术栈
- Vue 3 + Composition API
- Element Plus组件库
- Axios API请求
- JSON数据处理

### 6. 实现计划

1. 添加API方法到 `auth.js`
2. 创建 `AIAuditSuggest.vue` 组件
3. 更新路由配置
4. 更新导航菜单
5. 测试功能完整性

### 7. 代码结构

```
├── src/
│   ├── api/
│   │   └── auth.js          # 添加API方法
│   ├── router/
│   │   └── index.js         # 更新路由配置
│   ├── views/
│   │   ├── Decision.vue     # 更新导航菜单
│   │   └── AIAuditSuggest.vue  # 新增组件
```

这个实现方案将完整地添加AI审核建议功能，与现有决策模块无缝集成，提供良好的用户体验和清晰的结果展示。
