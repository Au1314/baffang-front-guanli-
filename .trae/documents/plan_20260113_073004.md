# 添加快速分析页面返回按钮

## 需求分析
用户需要在快速分析页面添加一个返回按钮，点击后返回到统计模块的初始页面。

## 实现方案

### 1. 添加返回按钮组件
在 `QuickAnalysis.vue` 页面中添加返回按钮，使用 Element Plus 的 Button 组件，包含：
- 返回图标（ArrowLeft）
- 按钮文本（返回统计）
- 合适的样式和位置

### 2. 实现返回功能
使用 Vue Router 的 `$router.push` 方法，点击按钮后跳转到统计模块的初始页面 `/statistics`。

### 3. 设计布局
将返回按钮添加到页面顶部的合适位置，建议放在页面标题附近，保持与现有页面风格一致。

### 4. 具体实现

#### 步骤1：修改 `QuickAnalysis.vue` 模板
在卡片头部或页面顶部添加返回按钮：

```vue
<template #header>
  <div class="card-header">
    <el-button 
      type="default" 
      @click="$router.push('/statistics')"
      :icon="ArrowLeft"
      size="small"
    >
      返回统计
    </el-button>
    <span>快速分析</span>
    <el-tooltip content="输入问题获取AI分析报告" placement="top">
      <el-icon class="header-icon"><QuestionFilled /></el-icon>
    </el-tooltip>
  </div>
</template>
```

#### 步骤2：引入必要的图标
```javascript
import { ArrowLeft, Search, QuestionFilled, InfoFilled, Document, Close, RefreshRight } from '@element-plus/icons-vue'
```

#### 步骤3：调整样式
确保返回按钮与页面标题对齐，保持良好的视觉效果。

## 预期效果
在快速分析页面顶部显示一个返回按钮，点击后跳转到统计模块的初始页面，方便用户在两个页面之间切换。

## 技术要点
- Vue Router 的导航功能
- Element Plus 按钮组件
- 图标使用和样式调整
- 页面布局优化

## 优势
- 提升用户体验，方便页面间切换
- 保持与现有系统风格一致
- 实现简单，代码量少
- 不影响其他功能模块
