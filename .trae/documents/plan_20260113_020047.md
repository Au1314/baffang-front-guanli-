# 修复发送系统公告无响应问题

## 1. 问题分析

根据错误信息 `SyntaxError: The requested module '/node_modules/.vite/deps/@element-plus_icons-vue.js?v=16ddfazd' does not provide an export named 'Send'`，问题出在 `NoticeBroadcast.vue` 组件中导入了不存在的 `Send` 图标。

## 2. 解决方案

将不存在的 `Send` 图标替换为 Element Plus Icons 中存在的图标，比如 `Document` 或其他适合表示发送/提交操作的图标。

## 3. 修复步骤

### 3.1 修改图标导入

在 `src/views/NoticeBroadcast.vue` 中，将 `Send` 图标替换为 `Document` 图标：

```javascript
// 修改前
import { Send, Refresh } from '@element-plus/icons-vue'

// 修改后
import { Document, Refresh } from '@element-plus/icons-vue'
```

### 3.2 修改图标使用

在模板中，将 `Send` 图标替换为 `Document` 图标：

```vue
// 修改前
<el-button type="primary" @click="handleSubmit" :loading="loading">
  <el-icon><Send /></el-icon>
  发送公告
</el-button>

// 修改后
<el-button type="primary" @click="handleSubmit" :loading="loading">
  <el-icon><Document /></el-icon>
  发送公告
</el-button>
```

## 4. 预期效果

- 修复后，发送系统公告页面将能够正常加载
- 点击"发送公告"按钮时，表单将被提交
- 系统将调用 `/notice/broadcast` API 发送系统公告
- 发送成功或失败都会显示相应的消息提示

## 5. 其他可能的替代图标

如果 `Document` 图标不符合需求，还可以考虑使用以下图标：
- `Paperclip` - 适合附件或发送操作
- `ArrowRight` - 适合提交或发送操作
- `Check` - 适合确认或提交操作

## 6. 修复文件

- 仅需修改 `src/views/NoticeBroadcast.vue` 文件
