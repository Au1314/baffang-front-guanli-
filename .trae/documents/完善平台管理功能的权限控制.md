## 完善平台管理功能的权限控制

### 需求分析
- 普通管理员可以使用的功能：新增成员、设置成员角色（审核员/客服/紧急响应人员）、剥夺成员身份（权限比自己低的）、平台参数配置、查看平台日志
- 普通管理员不能设置其他管理员
- 权限等级：超级管理员＞管理员＞客服/紧急响应人员/审核员＞未分配成员

### 实现计划

1. **完善 PlatformManage.vue 组件**
   - 在成员管理标签页中，根据当前用户类型控制功能按钮的显示
   - 普通管理员隐藏"设置为管理员"按钮
   - 超级管理员显示所有按钮

2. **增强权限检查逻辑**
   - 在组件中引入 adminStore，获取当前用户类型
   - 根据用户类型决定显示哪些功能按钮
   - 为每个功能按钮添加权限检查

3. **改进成员管理功能**
   - 确保普通管理员只能管理权限比自己低的成员
   - 在界面上体现权限差异

4. **测试验证**
   - 确保超级管理员可以使用所有功能
   - 确保普通管理员只能使用允许的功能
   - 验证权限控制逻辑的正确性

### 技术实现
- 使用 Vue 3 Composition API
- 利用 Pinia store 获取用户权限信息
- 基于 Element Plus 的条件渲染功能
- 实现细粒度的权限控制

### 预计修改的文件
- `src/views/PlatformManage.vue`：添加权限控制逻辑，控制按钮显示

### 预期效果
- 普通管理员登录后只能看到允许的功能按钮
- 超级管理员登录后可以看到所有功能按钮
- 权限控制逻辑清晰，易于维护和扩展
