# 重写登录功能计划

## 问题分析
根据用户提供的最新登录API响应格式，登录成功后返回的data对象中已经包含了完整的adminInfo字段，不需要再调用getUserInfo方法获取用户信息。当前代码中存在冗余的getUserInfo调用，需要简化登录流程。

## 修改内容

### 1. 修改Login.vue组件
- **文件路径**：`src/views/Login.vue`
- **修改点**：第110行的handleLogin方法
- **修改内容**：
  - 移除调用getUserInfo的逻辑，因为响应中已经包含完整的adminInfo
  - 简化登录流程，直接存储登录信息并跳转
  - 确保登录成功后能正确跳转到首页

### 2. 检查adminStore.js的login方法
- **文件路径**：`src/store/adminStore.js`
- **检查点**：第157行的login方法
- **修改内容**：
  - 确保能正确处理最新的adminInfo格式，特别是包含name字段
  - 检查是否需要调整adminInfo的存储逻辑

### 3. 验证响应拦截器
- **文件路径**：`src/api/index.js`
- **检查点**：第32行的响应拦截器
- **修改内容**：
  - 确保正确处理最新的API响应格式
  - 确认返回res.data，包含adminInfo、expiresIn、token、tokenType

### 4. 验证路由跳转
- **文件路径**：`src/router/index.js`
- **检查点**：路由守卫逻辑
- **修改内容**：
  - 确保登录成功后能正确跳转到首页
  - 检查权限验证逻辑是否正确

## 测试要点
1. 登录功能正常工作
2. 登录成功后能正确存储adminInfo
3. 登录成功后能正确跳转到首页
4. 页面能正确显示用户信息
5. 刷新页面后保持登录状态

## 预期效果
登录功能重写后，能够正确处理最新的API响应格式，直接使用响应中的adminInfo，不需要再调用getUserInfo方法，简化了登录流程，确保登录后能跳转到正确页面。
