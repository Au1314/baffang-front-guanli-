# 批量发送通知功能实现方案

## 功能需求
基于现有通知管理系统，添加批量发送通知功能，允许管理员向多个用户发送相同内容的通知。

## 实现步骤

### 1. API配置更新
在 `src/api/auth.js` 中添加批量发送通知的API方法：
- 添加 `batchSendNotice` 方法，调用 `/notice/batch-send` 接口

### 2. 创建批量发送通知组件
创建 `src/views/NoticeBatchSend.vue` 组件，包含：
- 用户ID输入框（支持输入多个用户ID，逗号分隔）
- 通知标题输入框
- 通知内容输入框
- 通知类型选择器
- 关联ID和关联类型输入项（可选）
- 发送和重置按钮
- 表单验证逻辑

### 3. 更新路由配置
在 `src/router/index.js` 中添加批量发送通知的子路由：
```javascript
{
  path: 'batch-send',
  name: 'NoticeBatchSend',
  component: () => import('@/views/NoticeBatchSend.vue'),
  meta: {
    title: '批量发送通知'
  }
}
```

### 4. 更新导航菜单
在 `src/views/Notice.vue` 的导航菜单中添加批量发送通知的菜单项：
```html
<el-menu-item index="/notice/batch-send">
  <template #title>
    <span>批量发送通知</span>
  </template>
</el-menu-item>
```

## 技术实现细节

### 表单设计
- 用户ID输入框：支持逗号分隔的多个用户ID，提交前转换为数组
- 通知类型：与现有通知类型保持一致（0-6）
- 关联类型：与现有关联类型保持一致（0-5）
- 表单验证：确保必填项（用户ID、标题、内容、类型）已填写

### API调用
- 使用POST请求，Content-Type为application/json
- 请求参数：
  - userids：数组类型，包含所有目标用户ID
  - title：通知标题
  - content：通知内容
  - type：通知类型
  - relatedid：关联ID（可选）
  - relatedtype：关联类型（可选）

### 交互设计
- 发送成功后显示成功提示，并重置表单
- 发送失败时显示错误提示
- 加载状态显示，防止重复提交

## 预期效果
- 管理员可以通过新的菜单项进入批量发送通知页面
- 支持一次向多个用户发送相同内容的通知
- 表单验证确保数据格式正确
- 与现有通知系统无缝集成
