# 完善私桩分布数据统计功能方案

## 1. 功能需求
修改私桩分布数据统计组件，确保即使数据库中没有某类电流类型数据，也能显示该类型的分布卡片，计数为0。

## 2. 实现方案

### 2.1 定义完整电流类型列表
在组件中定义所有可能的电流类型，确保无论数据库中是否存在该类型数据，都能在页面上显示。

### 2.2 创建计算属性处理数据
创建计算属性，将API返回的电流类型数据与完整电流类型列表合并，确保所有类型都能显示：
- 对于API返回中存在的类型，使用实际计数
- 对于API返回中不存在的类型，计数显示为0

### 2.3 应用到模板中
将模板中直接使用API返回数据的地方替换为使用处理后的计算属性数据。

## 3. 技术实现

### 3.1 修改组件脚本
在组件的脚本部分添加：
```javascript
// 定义完整的电流类型列表
const allCurrentTypes = [
  { currentType: 0, currentTypeName: '直流电' },
  { currentType: 1, currentTypeName: '交流电' }
]

// 处理后的电流类型分布数据
const processedCurrentTypeDistribution = computed(() => {
  if (!privateStationStats.value) return []
  
  const apiData = privateStationStats.value.currentTypeDistribution || []
  const apiDataMap = new Map(apiData.map(item => [item.currentType, item]))
  
  // 合并所有类型，确保每个类型都显示
  return allCurrentTypes.map(type => {
    const apiItem = apiDataMap.get(type.currentType)
    return {
      ...type,
      count: apiItem ? apiItem.count : 0
    }
  })
})
```

### 3.2 修改模板
将模板中电流类型分布部分的数据源替换为处理后的计算属性：
```html
<div v-for="item in processedCurrentTypeDistribution" :key="item.currentType" class="distribution-item">
  <el-card shadow="hover" class="distribution-card">
    <div class="distribution-item-header">
      <span class="distribution-name">{{ item.currentTypeName }}</span>
    </div>
    <div class="distribution-item-value">{{ item.count }}</div>
  </el-card>
</div>
```

## 4. 预期效果
- 无论数据库中是否存在直流电或交流电数据，页面都会显示这两种类型的分布卡片
- 对于数据库中不存在的类型，计数显示为0
- 保持原有功能不变，只是增强了数据显示的完整性

## 5. 扩展考虑
可以将此方案扩展到其他分布类型，如状态分布、类型分布等，确保所有分布类型都能完整显示。
