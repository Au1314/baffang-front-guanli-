# 在决策列表实现手动执行决策功能

## 1. 功能需求

* 在决策列表中添加手动执行决策功能

* 当自动执行字段显示为"否"时，在操作列显示"手动执行"按钮

* 点击按钮后执行决策，并显示操作结果

## 2. 技术方案

### 2.1 文件结构

* 修改现有文件：
  * `src/views/DecisionList.vue` - 添加手动执行决策功能

### 2.2 功能设计

#### 2.2.1 手动执行决策按钮

* 在决策列表的操作列添加"手动执行"按钮

* 显示条件：
  * `autoExecute` 为 `false`
  * 决策状态允许执行（如待处理、已采纳、部分采纳、执行失败等）

* 点击按钮打开确认弹窗

#### 2.2.2 确认弹窗

* 弹窗标题："确认执行决策"

* 弹窗内容：提示用户确认执行该决策，包含决策ID和决策编号

* 操作按钮：确认、取消

#### 2.2.3 执行逻辑

* 调用现有API方法 `executeDecision(decisionId)`

* 处理成功或失败的情况

* 显示操作反馈

* 刷新列表数据

### 2.3 样式设计

* 采用Element Plus组件库

* 保持与现有决策列表页面一致的样式

* 使用确认弹窗确保用户操作的准确性

## 3. 实现步骤

### 3.1 第一步：修改操作列，添加手动执行按钮

在`src/views/DecisionList.vue`的操作列中添加手动执行按钮：

```html
<el-table-column label="操作" width="240">
  <template #default="scope">
    <el-button type="primary" size="small" @click.stop="showDecisionDetail(scope.row.id)">详情</el-button>
    <el-button v-if="scope.row.status === 0" type="success" size="small" @click.stop="openHandleDialog(scope.row)">处理</el-button>
    <el-button v-if="!scope.row.autoExecute && [0, 1, 3, 6].includes(scope.row.status)" type="warning" size="small" @click.stop="executeDecision(scope.row)">手动执行</el-button>
  </template>
</el-table-column>
```

### 3.2 第二步：添加执行决策的方法

在`src/views/DecisionList.vue`中添加`executeDecision`方法：

```javascript
// 手动执行决策
const executeDecision = async (row) => {
  try {
    // 显示确认弹窗
    await ElMessageBox.confirm(
      `<div>确定要执行该决策吗？</div><div style="margin-top: 10px;">决策ID：${row.id}</div><div>决策编号：${row.decisionNo}</div>`,
      '确认执行决策',
      {
        confirmButtonText: '确认',
        cancelButtonText: '取消',
        type: 'warning',
        dangerouslyUseHTMLString: true
      }
    )
    
    // 调用API
    const response = await authApi.executeDecision(row.id)
    
    ElMessage.success(response || '执行已触发')
    
    // 刷新列表和统计数据
    fetchDecisionList()
    fetchDecisionStatistics()
  } catch (error) {
    console.error('执行决策失败:', error)
    if (error !== 'cancel') {
      ElMessage.error('执行决策失败，请重试')
    }
  }
}
```

### 3.3 第三步：添加必要的依赖

确保已导入`ElMessageBox`组件：

```javascript
import { ElMessage, ElMessageBox } from 'element-plus'
```

## 4. 预期效果

* 决策列表中，当自动执行显示为"否"且状态允许执行时，显示"手动执行"按钮

* 点击按钮弹出确认弹窗

* 确认后调用API执行决策

* 执行成功后显示成功提示，并刷新列表

* 执行失败后显示失败提示

* 处理异步API调用

* 提供清晰的操作反馈
