# 修复决策模块页面空白问题

## 1. 问题分析
从代码分析来看，决策模块页面显示空白的原因是：
- DecisionList.vue组件中调用了`showDecisionDetail`函数
- 但这个函数是定义在Decision.vue组件中的，而不是在DecisionList.vue组件中
- 这会导致当组件加载或用户交互时，调用不存在的函数，从而导致组件崩溃

## 2. 解决方案
在DecisionList.vue组件中添加`showDecisionDetail`函数，或者将该函数通过props传递给子组件。由于当前项目结构使用了Vue 3的组合式API和路由视图，最直接的解决方案是在DecisionList.vue组件中添加`showDecisionDetail`函数，并修改其实现逻辑。

## 3. 实现步骤

### 3.1 修改DecisionList.vue组件
1. 添加`showDecisionDetail`函数，实现显示决策详情的功能
2. 修改该函数的实现，直接在当前组件中处理，而不是依赖父组件的函数
3. 确保该函数能够正确调用API获取决策详情并显示

### 3.2 具体代码修改
在DecisionList.vue组件的script部分添加以下代码：
```javascript
// 详情弹窗可见性
const detailDialogVisible = ref(false)

// 决策详情数据
const decisionDetail = ref({})

// 显示决策详情
const showDecisionDetail = (rowOrId) => {
  const id = typeof rowOrId === 'number' ? rowOrId : rowOrId.id
  fetchDecisionDetail(id)
}

// 获取决策详情
const fetchDecisionDetail = async (id) => {
  try {
    const response = await authApi.getDecisionDetail(id)
    decisionDetail.value = response
    detailDialogVisible.value = true
  } catch (error) {
    console.error('获取决策详情失败:', error)
    ElMessage.error('获取决策详情失败')
  }
}
```

### 3.4 添加辅助函数
在DecisionList.vue组件的script部分添加`formatJson`函数：
```javascript
// 格式化JSON数据的辅助函数
const formatJson = (data) => {
  if (!data) return '无'
  try {
    return JSON.stringify(data, null, 2)
  } catch (error) {
    return data
  }
}
```
