# 修复选择私桩认证后没有反应的问题

## 1. 问题分析
选择私桩认证后没有反应的原因是：
- 在Audit.vue组件中，当用户选择审核类型时，没有自动触发获取审核列表的请求
- 只有在组件挂载时、提交审核后或手动点击"查询"按钮时，才会调用fetchAuditList方法
- 因此，用户选择私桩认证后，需要手动点击"查询"按钮才能看到结果

## 2. 解决方案
添加对auditFilter.auditType变化的监听，当选择审核类型时自动触发fetchAuditList方法，同时对其他筛选条件也添加类似的监听，提升用户体验。

## 3. 实现步骤

### 3.1 导入watch API
在script setup中导入Vue的watch API，用于监听响应式数据的变化。

### 3.2 添加监听逻辑
- 监听auditFilter.auditType变化，自动触发fetchAuditList
- 可选：监听其他筛选条件变化，如status、priority、authStatus等，自动触发fetchAuditList

### 3.3 优化用户体验
- 确保在选择审核类型后，立即显示加载状态
- 确保数据正确更新

## 4. 预期效果

- 选择私桩认证后，自动触发获取审核列表的请求
- 显示加载状态
- 加载完成后显示相应的审核列表
- 提升用户体验，无需手动点击"查询"按钮

## 5. 文件修改

- `src/views/Audit.vue`：添加watch监听，自动触发fetchAuditList
