# 实现评论举报列表获取功能

## 一、需求分析
1. 已知获取评论举报列表的API为 `GET /forum/report/reply/list`
2. 该API支持的请求参数包括：pageNum、pageSize、status、priority、keyword、startTime、endTime
3. 响应数据包含评论举报的详细信息，如举报单号、举报标题、举报人、被举报人、优先级、状态等
4. 目前论坛管理下的举报管理只显示帖子举报，需要完善以支持评论举报

## 二、实现方案

### 1. 添加评论举报列表API方法
- 在 `src/api/auth.js` 中添加 `getCommentReportList` 方法，用于调用评论举报列表API

### 2. 修改论坛管理页面的举报管理逻辑
- 在 `src/views/ForumManage.vue` 中修改举报管理部分，使其支持获取和显示评论举报列表
- 添加举报类型筛选选项，允许管理员选择查看帖子举报还是评论举报
- 修改 `fetchReportList` 方法，根据举报类型调用不同的API
- 确保响应数据能够正确显示，包括评论举报的特殊字段

## 三、具体实现步骤

### 步骤1：添加API方法
在 `src/api/auth.js` 中添加以下代码：
```javascript
// 评论举报列表查询
getCommentReportList(params) {
  return request.get('/forum/report/reply/list', { params })
}
```

### 步骤2：修改举报管理的筛选条件
在 `src/views/ForumManage.vue` 的举报筛选部分添加举报类型选择器：
```vue
<el-select
  v-model="reportFilter.auditType"
  placeholder="举报类型"
  style="width: 120px; margin-right: 10px"
  clearable
>
  <el-option label="全部" :value="null" />
  <el-option label="帖子举报" :value="1" />
  <el-option label="评论举报" :value="4" />
</el-select>
```

### 步骤3：修改获取举报列表的方法
修改 `fetchReportList` 方法，根据举报类型调用不同的API：
```javascript
const fetchReportList = async () => {
  try {
    reportLoading.value = true
    const params = {
      pageNum: reportPage.value,
      pageSize: reportPageSize.value,
      keyword: reportFilter.keyword,
      status: reportFilter.status,
      priority: reportFilter.priority,
      startTime: reportFilter.startTime,
      endTime: reportFilter.endTime
    }
    console.log('请求举报列表参数:', params)
    let response;
    // 根据举报类型调用不同的API
    if (reportFilter.auditType === 4) {
      // 评论举报
      response = await authApi.getCommentReportList(params)
    } else {
      // 帖子举报（默认）
      response = await authApi.getPostReportList(params)
    }
    console.log('举报列表响应:', response)
    reportList.value = response?.data?.list || []
    reportTotal.value = response?.data?.total || 0
  } catch (error) {
    console.error('获取举报列表失败:', error)
    if (error.response) {
      ElMessage.error(`获取举报列表失败：${error.response.data?.msg || '服务器错误'}`)
    } else {
      ElMessage.error(`获取举报列表失败：${error.message}`)
    }
  } finally {
    reportLoading.value = false
  }
}
```

### 步骤4：修改重置筛选条件方法
在 `resetReportFilter` 方法中添加重置举报类型的逻辑：
```javascript
const resetReportFilter = () => {
  reportFilter.keyword = ''
  reportFilter.status = null
  reportFilter.auditType = null
  reportFilter.priority = null
  reportFilter.startTime = null
  reportFilter.endTime = null
  reportPage.value = 1
  fetchReportList()
}
```

### 步骤5：确保响应数据正确处理
由于评论举报的响应数据结构与帖子举报基本一致，只是 `auditType` 为 4，表示评论举报，因此现有的列表显示逻辑不需要大的修改。但需要确保 `fetchReportList` 方法中正确获取 `response.data.list` 和 `response.data.total`，因为从提供的响应示例来看，数据是嵌套在 `data` 字段中的。

## 四、预期效果
1. 论坛管理下的举报管理页面将支持选择查看帖子举报或评论举报
2. 管理员可以使用现有的筛选条件（关键词、状态、优先级、时间范围）来筛选评论举报
3. 评论举报列表将正确显示所有字段，包括举报单号、举报标题、举报人、被举报人、优先级、状态等
4. 支持分页、详情查看和审核操作

## 五、注意事项
1. 确保API请求参数与后端要求一致
2. 确保响应数据正确解析，特别是 `data.list` 和 `data.total` 字段
3. 确保举报类型筛选选项能够正确切换帖子举报和评论举报列表
4. 确保现有功能不受影响，特别是帖子举报的获取和显示
