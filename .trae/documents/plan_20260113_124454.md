## 问题分析

经过仔细分析，我找到了决策详情显示问题的根本原因：

1. **API响应结构**：API返回的数据结构为 `{ code: 200, msg: "OK", data: { id: 2, ... } }`

2. **响应拦截器处理**：在 `src/api/index.js` 中，响应拦截器会处理所有API响应：
   - 对于 `code === 200` 的成功响应，大多数接口会直接返回 `res.data`（API返回的实际数据）
   - 只有特定接口（登出和响应紧急呼叫）才会返回完整的 `res` 对象

3. **代码逻辑错误**：在 `fetchDecisionDetail` 方法中：
   ```javascript
   const response = await authApi.getDecisionDetail(id)
   decisionDetail.value = response.data
   ```
   - 由于 `authApi.getDecisionDetail` 调用的响应已被拦截器处理，`response` 已经是 API 返回的实际数据（即 `res.data`）
   - 所以 `response.data` 实际上是 `undefined`，导致 `decisionDetail.value` 被赋值为 `undefined`
   - 当详情弹窗尝试访问 `decisionDetail.id` 时，就会报错：`Cannot read properties of undefined (reading 'id')`

## 修复方案

修改 `fetchDecisionDetail` 方法，直接将响应赋值给 `decisionDetail.value`，而不是访问 `response.data`。

## 具体步骤

1. 打开 `src/views/Decision.vue` 文件
2. 找到 `fetchDecisionDetail` 方法
3. 将 `decisionDetail.value = response.data` 修改为 `decisionDetail.value = response`
4. 测试修复后是否能正常显示决策详情
