# 完善AI风险评估结果的转化处理与显示

## 1. 问题分析

* API返回的响应中，`analysis`字段是一个包含JSON代码块的字符串，需要解析其中的JSON部分
* 目前的代码直接将response赋值给assessmentResult，没有解析analysis字段，导致无法正确显示风险等级、置信度等信息
* 需要修改代码，正确解析analysis字段，并确保所有数据都能正确显示

## 2. 解决方案

### 2.1 修复方案

修改handleSubmit函数，添加analysis字段的解析逻辑，将JSON代码块解析为对象，然后将解析后的数据赋值给assessmentResult。

### 2.2 实现步骤

1. **修改handleSubmit函数，添加analysis字段解析**

2. **测试修复结果**

## 3. 实现步骤

### 3.1 第一步：修改handleSubmit函数

在`src/views/AIRiskAssessment.vue`中修改handleSubmit函数，添加analysis字段解析逻辑：

```javascript
// 提交评估
const handleSubmit = async () => {
  // 表单验证
  if (!queryParams.value.businessType) {
    ElMessage.warning('请选择业务类型')
    return
  }
  if (!queryParams.value.businessId) {
    ElMessage.warning('请输入业务ID')
    return
  }
  
  try {
    loading.value = true
    assessmentResult.value = null
    
    // 调用API获取风险评估结果
    const response = await authApi.riskAssessment({
      businessType: queryParams.value.businessType,
      businessId: queryParams.value.businessId
    })
    
    // 解析analysis字段中的JSON字符串
    const result = { ...response }
    if (result.analysis) {
      try {
        // 提取```json和```之间的内容
        const jsonMatch = result.analysis.match(/```json\n([\s\S]*?)\n```/)
        if (jsonMatch && jsonMatch[1]) {
          result.analysis = JSON.parse(jsonMatch[1])
        }
      } catch (error) {
        console.error('解析analysis字段失败:', error)
        result.analysis = {}
      }
    }
    
    assessmentResult.value = result
    ElMessage.success('风险评估完成')
  } catch (error) {
    console.error('风险评估失败:', error)
    ElMessage.error('风险评估失败，请重试')
  } finally {
    loading.value = false
  }
}
```

### 3.2 第二步：测试修复结果
