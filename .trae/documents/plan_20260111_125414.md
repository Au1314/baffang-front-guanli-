# 批量删除评论功能实施方案

## 1. 需求分析
根据用户提供的API信息，需要实现批量删除评论功能。API使用DELETE方法，请求路径为`/forum/reply/batch`，请求体为包含ids数组的JSON对象，响应为成功或失败状态。

## 2. 现有结构分析
- 论坛管理模块（ForumManage.vue）包含评论管理标签页
- 评论列表已经实现了基本的展示和删除功能
- authApi中已有getCommentList和deleteComment方法
- 评论列表使用el-table组件实现
- 需要添加批量删除API方法和UI功能

## 3. 实施方案

### 3.1 添加批量删除API方法
- 在authApi中添加batchDeleteComment方法
- 实现DELETE请求，路径为/forum/reply/batch
- 接收ids数组作为参数

### 3.2 实现UI功能
- 在评论列表中添加多选框列
- 添加批量删除按钮
- 实现评论选择功能
- 添加确认对话框
- 实现批量删除逻辑
- 显示操作结果提示

## 4. 具体实现步骤

1. **添加批量删除API方法**
   - 修改 src/api/auth.js，添加batchDeleteComment方法

2. **实现评论列表多选功能**
   - 修改 src/views/ForumManage.vue，在评论列表中添加多选框列
   - 添加selectedComments ref用于跟踪选中的评论
   - 实现selection-change事件处理

3. **添加批量删除按钮**
   - 在评论列表上方添加批量删除按钮
   - 根据选中状态启用/禁用按钮

4. **实现批量删除逻辑**
   - 添加batchDeleteComments方法
   - 显示确认对话框
   - 调用batchDeleteComment API
   - 处理响应，显示结果提示
   - 刷新评论列表

5. **测试功能完整性**
   - 测试多选功能
   - 测试批量删除功能
   - 测试确认对话框
   - 测试结果提示

## 5. 预期效果
- 评论列表支持多选
- 可通过批量删除按钮一次性删除多个评论
- 操作前显示确认对话框
- 操作后显示成功或失败提示
- 列表自动刷新

## 6. 技术要点
- 使用Vue 3 Composition API
- 基于Element Plus组件库
- 遵循现有的代码风格和架构
- 确保功能完整性和稳定性
- 良好的用户反馈机制

## 7. 代码结构
- `authApi.js`：添加batchDeleteComment方法
- `ForumManage.vue`：
  - 添加多选框列和选择事件处理
  - 添加selectedComments状态管理
  - 添加批量删除按钮
  - 添加batchDeleteComments方法
  - 实现完整的批量删除流程

## 8. 交互流程
1. 用户在评论列表中勾选多个评论
2. 批量删除按钮显示选中数量并启用
3. 用户点击批量删除按钮
4. 弹出确认对话框，显示待删除数量
5. 用户确认后，发送批量删除请求
6. 显示操作结果提示
7. 自动刷新评论列表
