# 完善修改管理员个人信息功能方案

## 需求分析
根据API文档，需要实现以下功能：
1. 使用 `PUT /profile` 接口修改管理员个人信息，支持修改昵称和头像
2. 使用 `POST /profile/avatar` 接口上传头像，支持将图片文件上传到服务器并获取URL
3. 两者都是可选的修改项

## 上传头像API详情
- **请求方式**：POST
- **请求地址**：/profile/avatar
- **请求头**：
  - Content-Type: multipart/form-data
  - Authorization: Bearer token
- **请求体**：form-data格式，包含file字段，值为图片文件
- **响应格式**：JSON
  ```json
  {
    "code": 200,
    "data": "http://localhost:8080/files/admin/avatar/avatar_2_64f343da091f42879e78306dd38209fe.png",
    "msg": "OK"
  }
  ```

## 实现方案

### 1. 修改API调用
- 在 `auth.js` 中新增 `uploadAvatar` 方法，使用 `POST /profile/avatar` 接口
- 新增 `updateProfile` 方法，使用 `PUT /profile` 接口
- 移除或保留原有的 `updateAdminInfo` 方法（建议保留作为兼容）

### 2. 实现头像上传功能
- 修改 `Profile.vue` 中的头像上传组件配置
- 实现 `handleAvatarSuccess` 方法，调用 `authApi.uploadAvatar` 上传图片
- 获取上传后的图片URL并保存到表单中

### 3. 修改保存逻辑
- 在 `Profile.vue` 中修改 `saveProfile` 函数，调用新的 `updateProfile` 方法
- 只传递 `name` 和 `avatar` 参数，不传递 `id`

### 4. 优化用户体验
- 确保头像上传前有格式和大小验证
- 添加上传过程中的加载状态
- 处理上传和保存过程中的错误
- 添加适当的成功反馈

## 具体实现步骤

1. **修改 `auth.js`**：

   - 参数为 `name` 和 `avatar`，均为可选

2. **修改 `Profile.vue`**：

   - 修改 `saveProfile` 函数，调用 `authApi.updateProfile`
   - 只传递 `name` 和 `avatar` 参数

3. **优化头像上传流程**：
   - 保留原有的 `beforeAvatarUpload` 验证逻辑
   - 添加上传过程中的加载状态
   - 处理上传错误

4. **测试功能**：
   - 测试昵称修改功能

   - 测试各种边界情况

- 浏览器兼容性：确保 `FormData` 和 `multipart/form-data` 在目标浏览器中兼容
