# 完善私人电桩认证审核功能方案

## 1. API层实现

* 在 `src/api/auth.js` 中添加 `auditPrivateStation` 方法，调用 `/auth/station/review` 接口

* 参数：

  * `stationId`（必填，integer）- 电桩ID

  * `authStatus`（必填，integer）- 认证状态：0-未认证，1-审核中，2-已认证，3-认证失败

  * `opinion`（必填，string）- 审核意见

  * `rejectReason`（必填，string）- 拒绝原因

  * `remark`（可选，string）- 备注

  * j拒绝原因只有拒绝时才是必填的，

* 方法类型：POST

## 2. 组件层修改

* 修改 `PrivateStationAudit.vue` 中的审核相关逻辑

  * 更新 `submitAudit` 方法，调用新的API

  * 调整请求参数格式，确保与API要求一致

  * 根据认证状态说明，调整审核结果映射关系：

    * 通过 → authStatus: 2

    * 拒绝 → authStatus: 3

    * 要求补充材料 → authStatus: 0 或 1（根据业务需求）

  * 确保表单验证逻辑正确，特别是必填项验证

## 3. 表单优化
