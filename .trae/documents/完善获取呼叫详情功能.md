# 实现方案

## 1. 需求分析
- 点击待处理紧急呼叫列表项时，通过API获取完整的呼叫详情
- 确保详情面板显示最新的API返回数据
- 处理事件冒泡，避免不必要的事件触发

## 2. 实现步骤

### 2.1 修改 `selectEmergency` 函数
- 位置：`Emergency.vue` 中的 `selectEmergency` 函数
- 功能：调用 `getEmergencyCallDetail` API 获取完整呼叫详情
- 实现：
  ```javascript
  const selectEmergency = async (emergency) => {
    try {
      // 设置选中状态
      selectedEmergencyId.value = emergency.id;
      // 调用API获取完整详情
      const detailResponse = await authApi.getEmergencyCallDetail(emergency.id);
      selectedEmergency.value = detailResponse.data;
      // 刷新处理日志
      fetchHandlingLogs(emergency.id);
    } catch (error) {
      console.error('获取呼叫详情失败:', error);
      ElMessage.error('获取呼叫详情失败');
    }
  };
  ```

### 2.2 确保API方法可用
- 已确认 `getEmergencyCallDetail` 方法在 `auth.js` 中定义，路径为 `/emergency/call/{callId}`
- 无需额外添加API方法

### 2.3 优化详情面板显示
- 确保详情面板使用 `selectedEmergency` 中的最新数据
- 已有的详情面板代码（第142-210行）已经使用 `selectedEmergency`，无需修改

### 2.4 处理事件冒泡
- 列表项的点击事件已经正确绑定，无需额外处理冒泡
- 若后续添加子元素点击事件，可使用 `.stop` 修饰符阻止冒泡
