# 修复登录功能错误计划

## 问题分析
根据用户提供的API响应格式，API返回的data对象中没有adminInfo字段，而是直接包含token、tokenType和expiresIn字段。这与之前预期的格式不符，导致adminStore.login方法验证失败。

## 修改内容

### 1. 修改adminStore.js的login方法
- **文件路径**：`src/store/adminStore.js`
- **修改点**：第157行的login方法
- **修改内容**：
  - 移除对adminInfo字段的强制验证
  - 调整参数验证逻辑，允许adminInfo为可选字段
  - 添加登录成功后获取用户信息的逻辑

### 2. 添加获取用户信息的方法
- **文件路径**：`src/store/adminStore.js`
- **修改点**：添加getUserInfo方法
- **修改内容**：
  - 调用authApi.getAdminInfo获取用户信息
  - 更新adminInfo状态
  - 存储到localStorage

### 3. 修改Login.vue组件
- **文件路径**：`src/views/Login.vue`
- **修改点**：第110行的handleLogin方法
- **修改内容**：
  - 登录成功后调用getUserInfo方法获取用户信息
  - 调整登录流程，确保先存储token，再获取用户信息

### 4. 验证authApi.getAdminInfo方法
- **文件路径**：`src/api/auth.js`
- **检查点**：确保getAdminInfo方法正确定义

## 测试要点
1. 登录功能正常工作
2. 登录成功后能获取用户信息
3. 正确存储token和用户信息
4. 页面能正确显示用户信息
5. 刷新页面后保持登录状态

## 预期效果
登录功能修复后，能够正确处理API响应，即使没有adminInfo字段，也能先存储token，然后调用获取用户信息的API，完成登录流程。
