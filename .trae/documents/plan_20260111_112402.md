# 完善评论列表查询功能方案

## 1. 问题分析

当前评论列表查询功能存在以下问题：

- **API请求参数不匹配**：
  - 当前使用`page`参数，后端要求`pageNum`
  - 当前使用`status`和`postId`筛选，后端支持`username`筛选
  - 缺少对后端支持的其他筛选条件的实现

- **数据结构不匹配**：
  - 当前使用`author`字段，后端返回`userName`
  - 当前显示`status`字段，后端API未返回
  - 缺少对`likeCount`、`parentId`、`replyToUserId`等字段的展示

- **评论列表展示不完整**：
  - 缺少点赞数、回复关系、帖子标题等重要信息
  - 回复关系展示不直观

- **筛选条件不完善**：
  - 缺少按用户名筛选功能
  - 缺少按帖子标题筛选功能

## 2. 解决方案

### 2.1 更新API请求参数

- 将`page`改为`pageNum`，与后端API保持一致
- 调整筛选参数，支持按用户名筛选
- 移除不支持的`status`筛选条件

### 2.2 完善数据绑定

- 更新数据字段映射，使用`userName`替代`author`
- 添加对`likeCount`、`parentId`、`replyToUserId`等字段的处理
- 移除对`status`字段的依赖

### 2.3 优化评论列表展示

- 添加点赞数字段
- 显示帖子标题
- 直观展示回复关系
- 区分主评论和回复评论

### 2.4 完善筛选功能

- 添加用户名筛选
- 优化关键词筛选，支持按评论内容搜索

## 3. 具体实现步骤

1. **修改fetchCommentList函数**：更新API请求参数和数据处理
2. **更新commentFilter对象**：调整筛选条件
3. **优化评论筛选区域**：添加用户名筛选
4. **更新表格列定义**：展示完整的评论信息
5. **优化评论关系展示**：直观区分主评论和回复
6. **调整样式**：确保列表展示美观易用

## 4. 预期效果

- 评论列表查询功能与后端API完全匹配
- 支持通过关键词、用户名进行筛选
- 评论列表展示完整的评论信息，包括点赞数、回复关系、帖子标题等
- 直观区分主评论和回复评论
- 分页功能正常工作
