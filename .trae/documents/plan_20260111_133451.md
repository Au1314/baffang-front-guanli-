# 实现获取举报详情功能的方案

## 一、需求分析
1. 已知获取举报详情的API为 `GET /forum/report/{id}`，返回包含详细举报信息的响应
2. 响应包含举报基本信息、附件列表、审核日志等字段
3. 需在现有举报列表功能基础上，完善举报详情获取和展示功能
4. 涉及 `PostReportAudit.vue` 和 `ForumManage.vue` 两个组件

## 二、实现方案

### 1. 添加举报详情API方法
- 在 `src/api/auth.js` 中添加 `getReportDetail` 方法，用于调用举报详情API

### 2. 修改 `PostReportAudit.vue` 组件
- 更新 `handleViewDetail` 方法，使用新的API获取举报详情
- 修正响应数据处理，从 `response.data` 中获取详细信息
- 扩展详情对话框，展示响应中的新增字段：
  - 附件列表（以链接形式展示，支持点击查看/下载）
  - 审核日志（以列表形式展示审核历史）
  - 其他新增字段（如申请人电话、用户名等）

### 3. 修改 `ForumManage.vue` 组件
- 更新 `handleViewReportDetail` 方法，使用新的API获取举报详情
- 扩展详情对话框，展示响应中的新增字段：
  - 附件列表
  - 审核日志
  - 其他新增字段

## 三、具体实现步骤

### 步骤1：添加API方法
在 `src/api/auth.js` 中添加以下代码：
```javascript
// 举报详情查询
getReportDetail(reportId) {
  return request.get(`/forum/report/${reportId}`)
}
```

### 步骤2：修改 `PostReportAudit.vue` 的详情获取方法
修改 `handleViewDetail` 方法，使用新的API并正确处理响应：
```javascript
const handleViewDetail = async (row) => {
  detailLoading.value = true
  try {
    const response = await authApi.getReportDetail(row.id)
    currentReport.value = response.data || {}
    showDetailDialog.value = true
  } catch (error) {
    console.error('获取举报详情失败:', error)
    ElMessage.error('获取举报详情失败')
  } finally {
    detailLoading.value = false
  }
}
```

### 步骤3：扩展 `PostReportAudit.vue` 的详情对话框
更新详情对话框，添加附件列表和审核日志的展示：
```vue

  <div class="attachment-list">
    <el-link
      v-for="(attachment, index) in currentReport.attachmentList"
      :key="index"
      :href="attachment.trim()"
```

## 四、预期效果
1. 点击举报列表中的"详情"按钮时，将调用新的API获取完整的举报详情
2. 详情对话框将展示完整的举报信息，包括附件列表和审核日志
3. 附件列表中的文件将以链接形式展示，点击可下载或查看
4. 审核日志将以时间线形式展示，清晰呈现审核历史
5. 支持显示响应中的所有新增字段

## 五、注意事项
1. 确保API请求参数正确，特别是reportId
2. 正确处理API响应，从response.data中获取实际数据
3. 确保附件链接可点击，支持在新标签页打开
4. 审核日志的时间线展示要清晰、易读
5. 确保组件加载状态正确，避免用户体验问题
6. 确保错误处理完善，对API请求失败情况进行适当提示
