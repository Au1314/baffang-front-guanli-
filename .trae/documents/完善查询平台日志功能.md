# 完善查询平台日志功能实现方案

## 1. 方案概述
根据系统日志表结构、API请求参数和响应格式，完善PlatformManage.vue中的日志查看功能，实现真实的日志查询、筛选和分页功能。

## 2. 实现步骤

### 2.1 更新API接口定义
- 修改auth.js中的日志API路径，将现有的`/platform/logs`更新为用户提供的`/system/log/list`
- 确保API方法支持所有请求参数：page、size、module、startTime、endTime、status、action、adminId、userId

### 2.2 完善日志筛选条件
在PlatformManage.vue的日志查看标签页中扩展筛选条件：
- 保留现有关键字搜索功能
- 扩展日期范围选择器
- 添加模块名筛选（模糊搜索）
- 添加操作名筛选（模糊搜索）
- 添加状态筛选（成功/失败）
- 添加管理员ID筛选
- 添加用户ID筛选

### 2.3 修改日志表格列定义
将现有的表格列更新为与API响应匹配的字段：
- id: 日志ID
- adminId: 操作管理员ID
- adminName: 操作管理员名称
- userId: 操作用户ID
- module: 操作模块
- action: 操作行为
- method: 请求方法
- url: 请求URL
- ip: 操作IP
- status: 操作状态（1-成功，0-失败）
- executionTime: 执行时长
- createTime: 创建时间

### 2.4 实现API调用和数据处理
- 在日志查看相关方法中，调用真实的API获取日志数据
- 实现加载状态管理
- 处理API响应，将数据转换为表格所需格式
- 实现错误处理

### 2.5 完善分页功能
- 添加完整的分页控件，支持页码切换和每页条数调整
- 实现分页相关的事件处理

### 2.6 实现筛选和查询功能
- 实现筛选条件的重置功能
- 实现按回车键触发查询
- 实现查询按钮点击事件

## 3. 技术要点

### 3.1 数据结构匹配
确保前端数据模型与后端API响应格式完全匹配，特别是状态字段的转换（数字状态码转换为中文描述）

### 3.2 性能优化
- 实现防抖或节流，避免频繁请求
- 合理设置分页大小，避免一次性加载过多数据

### 3.3 用户体验
- 添加加载状态提示
- 完善筛选条件的交互体验
- 优化表格展示，确保数据清晰易读

## 4. 预期效果

- 日志列表显示真实的系统日志数据
- 支持多条件组合筛选
- 支持分页浏览
- 提供良好的用户交互体验
- 响应迅速，加载状态明确

## 5. 文件修改

- `src/api/auth.js`：更新日志API路径和参数
- `src/views/PlatformManage.vue`：完善日志查看标签页的UI和功能实现
