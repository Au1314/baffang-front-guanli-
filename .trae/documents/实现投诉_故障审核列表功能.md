# 实现投诉/故障审核详情功能方案

## 1. 需求分析
- 实现获取投诉/故障审核详情的API接口
- 接口路径：`GET /complaint/detail/{id}`
- 请求参数：path参数id，代表审核表对应id
- 返回数据：包含详细的投诉/故障信息，包括申请人信息、内容、附件、状态等
- 需要在现有列表组件基础上添加详情查看功能

## 2. 实现方案

### 2.1 API接口定义
在`src/api/auth.js`文件中添加获取投诉/故障审核详情的API方法。

### 2.2 代码实现步骤

在`src/api/auth.js`文件中添加以下代码：
```javascript
// 获取投诉/故障审核详情
getComplaintDetail(id) {
  return request.get(`/complaint/detail/${id}`)
}
```

3. **完善查看详情方法**：
```javascript
// 查看详情
const handleViewDetail = async (row) => {
  detailLoading.value = true
  try {
    const response = await authApi.getComplaintDetail(row.id)
    currentComplaint.value = response || {}
    showDetailDialog.value = true
  } catch (error) {
    console.error('获取投诉详情失败:', error)
    ElMessage.error('获取投诉详情失败')
  } finally {
    detailLoading.value = false
  }
}
```
