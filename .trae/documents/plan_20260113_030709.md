## 现状分析

当前批量删除通知功能已经实现，但使用的是循环调用单个删除API的方式，效率较低。新的批量删除API提供了更高效的实现方式。

## 改进方案

1. **在auth.js中添加批量删除通知API方法**
   - 添加`batchDeleteNotice`方法，使用DELETE请求，路径为`/notice/batch-delete`
   - 请求体包含ids数组，格式为`{"ids": [13, 14, 15]}`
   - 预期响应为`{"code": 200, "data": 3, "msg": "OK"}`，其中data是删除的数量

2. **修改NoticeList.vue中的批量删除逻辑**
   - 将`handleBatchDelete`函数中的循环调用单个删除API改为调用新的批量删除API
   - 优化用户反馈，显示删除成功的数量
   - 保持其他逻辑不变，包括确认提示、加载状态和列表刷新

## 预期效果

改进后，批量删除通知功能将更加高效，一次请求即可删除多条通知，提高系统性能和用户体验。

## 改进步骤

1. 在`auth.js`文件中添加`batchDeleteNotice`方法
2. 修改`NoticeList.vue`文件中的`handleBatchDelete`函数
3. 保存文件并测试

## 代码修改示例

### 1. 在auth.js中添加方法
```javascript
// 批量删除通知
batchDeleteNotice(ids) {
  return request.delete('/notice/batch-delete', { data: { ids } })
}
```

### 2. 修改NoticeList.vue中的handleBatchDelete函数
```javascript
const handleBatchDelete = async () => {
  if (selectedIds.value.length === 0) {
    ElMessage.warning('请选择要删除的通知')
    return
  }
  
  try {
    await ElMessageBox.confirm(
      `确定要删除选中的 ${selectedIds.value.length} 个通知吗？`,
      '确认批量删除',
      {
        confirmButtonText: '确定',
        cancelButtonText: '取消',
        type: 'error'
      }
    )
    
    // 使用批量删除API
    const response = await authApi.batchDeleteNotice(selectedIds.value)
    ElMessage.success(`成功删除 ${response.data} 个通知`)
    
    // 刷新列表
    getNoticeList()
    
    // 清空选择
    selectedIds.value = []
  } catch (error) {
    if (error.type !== 'cancel') {
      ElMessage.error('批量删除失败')
      console.error('批量删除通知失败:', error)
    }
  }
}
```
