# 完善论坛管理模块帖子列表查询功能

## 1. 问题分析

当前论坛管理模块中的帖子列表查询功能存在以下问题：
- API请求参数与后端API不一致（当前使用`page`，后端要求`pageNum`）
- 缺少`userId`筛选功能
- 缺少时间范围（`startTime`和`endTime`）筛选功能
- 帖子列表展示字段可能不完整

## 2. 解决方案

### 2.1 更新API请求参数映射

修改`ForumManage.vue`中的`fetchPostList`函数，将请求参数从`page`改为`pageNum`，确保与后端API一致。

### 2.2 完善筛选条件

在`ForumManage.vue`的帖子筛选区域添加以下筛选条件：
- `userId`输入框（用于根据作者ID筛选）
- 时间范围选择器（使用`el-date-picker`实现`startTime`和`endTime`筛选）

### 2.3 优化帖子列表展示

更新帖子列表的表格列，确保展示API返回的所有重要字段：
- 标题（包含置顶和精华标记）
- 作者信息（用户名、用户ID）
- 内容摘要
- 统计信息（点赞数、评论数、收藏数）
- 状态标记（是否置顶、是否精华）
- 创建时间和更新时间

### 2.4 更新数据绑定和处理

确保前端数据模型与后端返回数据结构匹配，特别是：
- 处理`isTop`和`isEssence`字段的展示
- 格式化时间字段
- 处理用户头像显示

## 3. 具体实现步骤

1. **修改API请求参数**：更新`fetchPostList`函数中的参数映射
2. **添加筛选控件**：在筛选区域添加`userId`输入框和时间范围选择器
3. **更新表格列定义**：添加和调整表格列，展示完整的帖子信息
4. **优化样式和交互**：确保筛选区域和表格展示美观易用
5. **测试功能完整性**：验证所有筛选条件和分页功能正常工作

## 4. 预期效果

- 帖子列表查询功能与后端API完全匹配
- 支持通过关键词、作者ID、状态、是否置顶、是否精华、时间范围进行筛选
- 帖子列表展示完整的帖子信息
- 分页功能正常工作
- 界面美观易用，符合管理系统的使用习惯

## 5. 文件修改

- `src/views/ForumManage.vue`：主要修改文件，完善帖子列表查询功能

## 6. 技术要点

- 使用Element Plus的表单控件和表格组件
- 处理日期时间格式化
- 实现多条件组合筛选
- 确保API请求参数与后端一致

通过以上修改，论坛管理模块的帖子列表查询功能将完全符合后端API的要求，提供更全面的筛选和展示功能，方便管理员进行论坛帖子管理。
