# API请求403错误修复方案

## 1. 问题分析

### 1.1 根本原因
- **API代理配置错误**：在`vite.config.js`中，代理配置缺少`rewrite`规则
- **请求路径重复**：当前配置会导致请求路径重复，形成`http://localhost:8080/api/api/v1/admin/...`的错误路径
- **403错误**：由于请求路径错误，后端服务器无法识别请求资源，返回403 Forbidden

### 1.2 证据
- **Postman截图**：正确API路径应为`http://localhost:8080/api/v1/admin/ai/decision/list`
- **Vite配置**：当前配置将`/api`请求转发到`http://localhost:8080`，但没有重写路径
- **实际请求**：前端实际发送的请求为`http://localhost:6101/api/v1/admin/ai/decision/list`，经过代理后变为`http://localhost:8080/api/api/v1/admin/ai/decision/list`

## 2. 修复步骤

### 2.1 修改Vite代理配置
- 在`vite.config.js`的代理配置中添加`rewrite`规则
- 将`/api`前缀替换为空字符串，确保请求路径正确

### 2.2 修复后的请求流程
- 前端发送请求：`http://localhost:6101/api/v1/admin/ai/decision/list`
- 代理转发请求：`http://localhost:8080/v1/admin/ai/decision/list`（去掉重复的`/api`）
- 后端正确响应请求，返回200 OK

## 3. 修复文件清单

1. **修改文件**：
   - `src/vite.config.js` - 修复API代理配置，添加rewrite规则

## 4. 预期效果

- API请求路径正确，不再出现重复前缀
- 后端服务器能正确识别请求资源
- 403 Forbidden错误消失，API请求返回正常响应
- 决策列表和统计数据能正常加载
- AI异常检测功能能正常使用
