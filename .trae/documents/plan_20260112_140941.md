# 修复头像预览和立即更新不生效的问题

## 问题分析

根据用户描述，点击更换头像后，预览没有显示正确头像，上传头像后也没有立即更新头像，反而是刷新页面后，才显示出更换后头像。经过分析代码，发现以下问题：

1. **缺少本地预览功能**：
   - 当用户选择头像后，没有立即显示本地预览
   - 只有在上传成功后，才会更新 `editForm.avatar`
   - 这会导致用户在上传过程中看不到头像预览，体验不好

2. **主页面头像没有立即更新**：
   - 上传成功后，只更新了 `editForm.avatar`，用于编辑对话框中的预览
   - 主页面的头像绑定的是 `userInfo.value.avatar`，只有在点击"保存"按钮后才会更新
   - 这会导致上传成功后，主页面的头像没有立即更新

3. **缺少即时反馈**：
   - 用户选择头像后，没有即时的视觉反馈
   - 上传过程中，没有加载状态提示

## 解决方案

修改头像上传流程，实现以下功能：

1. **添加本地预览功能**：
   - 当用户选择头像后，立即生成本地预览 URL
   - 更新 `editForm.avatar`，显示本地预览
   - 然后再调用上传 API
   - 上传成功后，更新 `editForm.avatar` 为服务器返回的 URL

2. **主页面头像立即更新**：
   - 上传成功后，同时更新 `userInfo.value.avatar`
   - 这样主页面的头像会立即更新，不需要等待保存
   - 保持 `saveProfile` 方法中的更新逻辑不变，确保数据一致性

3. **添加上传加载状态**：
   - 添加上传过程中的加载状态提示
   - 提升用户体验

## 具体实现步骤

1. **添加上传加载状态**：
   ```javascript
   // 在组件中添加上传加载状态
   const uploadLoading = ref(false)
   ```

2. **修改 `handleAvatarChange` 方法**：
   ```javascript
   const handleAvatarChange = async (file) => {
     try {
       // 获取选中的文件
       // ... 省略获取文件的代码 ...
       
       if (!selectedFile) return
       
       // 手动调用上传前验证
       const isValid = beforeAvatarUpload(selectedFile)
       if (!isValid) return
       
       // 显示本地预览
       const localUrl = URL.createObjectURL(selectedFile)
       editForm.avatar = localUrl
       
       // 显示上传加载状态
       uploadLoading.value = true
       
       // 调用头像上传API
       const uploadResponse = await authApi.uploadAvatar(selectedFile)
       console.log('头像上传API响应:', uploadResponse)
       
       // 保存上传后的头像URL
       editForm.avatar = uploadResponse.data
       // 同时更新主页面的头像
       userInfo.value.avatar = uploadResponse.data
       
       // 释放本地URL
       URL.revokeObjectURL(localUrl)
       
       ElMessage.success('头像上传成功')
     } catch (error) {
       console.error('头像上传失败:', error)
       ElMessage.error('头像上传失败：' + (error.message || '未知错误'))
     } finally {
       // 隐藏上传加载状态
       uploadLoading.value = false
     }
   }
   ```

3. **修改 `el-upload` 组件，添加加载状态**：
   ```vue
   <el-avatar :size="100" :src="editForm.avatar">
     <el-icon v-if="uploadLoading"><Loading /></el-icon>
     <el-icon v-else><UserFilled /></el-icon>
   </el-avatar>
   ```

4. **确保导入 `Loading` 图标**：
   ```javascript
   import { UserFilled, Upload, Loading } from '@element-plus/icons-vue'
   ```

5. **保持 `saveProfile` 方法不变**：
   ```javascript
   // 保存资料
   const saveProfile = async () => {
     try {
       await editFormRef.value.validate()
       saveLoading.value = true
       
       // 调用更新API
       await authApi.updateProfile({
         name: editForm.name,
         avatar: editForm.avatar
       })
       
       // 更新本地数据
       userInfo.value.name = editForm.name
       userInfo.value.avatar = editForm.avatar
       
       ElMessage.success('保存成功')
       dialogVisible.value = false
     } catch (error) {
       // ... 省略错误处理代码 ...
     } finally {
       saveLoading.value = false
     }
   }
   ```

## 风险评估

- 本地预览 URL 需要及时释放，避免内存泄漏
- 上传失败时，需要处理本地预览 URL 的清理
- 需要确保 `userInfo.value.avatar` 和 `editForm.avatar` 保持一致
