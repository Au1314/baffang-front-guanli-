## 实现批量删除功能的具体方案

### 1. API层修改

**文件**：`src/api/auth.js`
**修改内容**：在`authApi`对象中添加批量删除用户的方法

```javascript
// 批量删除用户
deleteUsersBatch(ids) {
  return request.delete('/user/batch', { data: { ids } })
}
```

### 2. 组件层修改

**文件**：`src/views/system/UserManage.vue`

#### 2.1 添加多选功能

**修改位置**：用户列表表格组件
**修改内容**：添加`selection-change`事件和多选列

```vue
<el-table
  :data="userList"
  stripe
  border
  style="width: 100%"
  v-loading="loading"
  @row-click="handleRowClick"
  :row-class-name="'user-row'"
  @selection-change="handleSelectionChange"
>
  <!-- 添加多选列 -->
  <el-table-column type="selection" width="55" />
  <!-- 其他列保持不变 -->
</el-table>
```

#### 2.2 添加批量删除按钮

**修改位置**：表格上方的操作栏
**修改内容**：添加批量删除按钮，根据选择状态动态禁用

```vue
<div class="operation-bar" style="margin-bottom: 16px;">
  <el-button 
    type="danger" 
    @click="handleBatchDelete" 
    :disabled="selectedIds.length === 0"
  >
    <el-icon><Delete /></el-icon>
    批量删除
  </el-button>
</div>
```

#### 2.3 添加响应式数据和方法

**修改位置**：`<script setup>`部分
**修改内容**：

```javascript
// 1. 添加响应式数据
const selectedIds = ref([])

// 2. 添加选择变化处理方法
const handleSelectionChange = (selection) => {
  selectedIds.value = selection.map(item => item.id)
}

// 3. 添加批量删除方法
const handleBatchDelete = async () => {
  if (selectedIds.value.length === 0) {
    ElMessage.warning('请选择要删除的用户')
    return
  }
  
  try {
    // 显示确认对话框
    await ElMessageBox.confirm(
      `确定要删除选中的 ${selectedIds.value.length} 个用户吗？`,
      '确认删除',
      {
        confirmButtonText: '确定',
        cancelButtonText: '取消',
        type: 'warning'
      }
    )
    
    // 调用API批量删除
    await authApi.deleteUsersBatch(selectedIds.value)
    
    // 清空选择
    selectedIds.value = []
    
    // 重新获取用户列表
    getUserList()
    
    ElMessage.success('批量删除成功')
  } catch (error) {
    if (error.type !== 'cancel') {
      ElMessage.error('批量删除失败')
      console.error('批量删除失败:', error)
    }
  }
}
```

### 3. 功能说明

1. **多选功能**：在表格左侧添加多选列，支持单选和全选
2. **批量删除按钮**：位于表格上方，选择用户后启用
3. **确认机制**：点击批量删除按钮后，弹出确认对话框，显示要删除的用户数量
4. **操作反馈**：删除成功或失败后显示相应的提示信息
5. **数据更新**：删除成功后自动刷新用户列表，并清空选择

### 4. 技术要点

1. 使用Element Plus的`el-table`组件的多选功能
2. 通过`selection-change`事件获取选中的用户ID
3. 调用新增的`deleteUsersBatch` API方法
4. 使用`ElMessageBox.confirm`实现确认机制
5. 使用`ElMessage`显示操作结果

### 5. 预期效果

* 用户可以在列表中选择多个用户

* 点击批量删除按钮后，确认并执行删除操作

* 删除成功后，列表自动刷新，显示最新数据

* 所有操作都有明确的反馈提示
