# 解决获取当前位置问题方案

## 1. 问题分析
- 从控制台错误信息可以看出，获取当前位置失败，出现了 `Network location provider at 'https://www.0o09leapis.qj29zk/' ERR_BLOCKED_BY_CLIENT` 错误
- 这个错误通常是由于浏览器安全设置、扩展程序阻止了位置请求，或者位置服务提供商的URL被浏览器拦截
- 目前的代码已经有手动设置位置的功能，但用户体验可以进一步优化

## 2. 实现步骤

### 2.1 添加默认位置
- 位置：`Emergency.vue` 中的变量定义部分
- 功能：添加一个默认位置作为备选方案，当浏览器地理定位失败时使用
- 实现：
  ```javascript
  // 响应紧急呼叫
  const currentLocation = ref(null)
  // 添加默认位置 - 长沙岳麓区湖南师范大学中和楼
  const defaultLocation = { longitude: 112.9384, latitude: 28.1857 } // 长沙岳麓区湖南师范大学中和楼
  const locationError = ref(null)
  ```

### 2.2 修改 `getCurrentLocation` 函数
- 位置：`Emergency.vue` 中的 `getCurrentLocation` 函数
- 功能：优化获取当前位置的逻辑，添加默认位置作为备选
- 实现：
  ```javascript
  // 获取当前位置
  const getCurrentLocation = () => {
    if ('geolocation' in navigator) {
      navigator.geolocation.getCurrentPosition(
        (position) => {
          const longitude = position.coords.longitude
          const latitude = position.coords.latitude
          currentLocation.value = { longitude, latitude }
          locationError.value = null
          console.log('成功获取当前位置:', currentLocation.value)
          // 获取到位置后立即获取待响应呼叫列表
          fetchPendingEmergencyList()
        },
        (error) => {
          console.error('获取位置失败:', error.message)
          locationError.value = error.message
          
          // 优化错误处理：显示更详细的错误信息
          let errorMsg = '无法获取位置信息，使用默认位置'
          switch (error.code) {
            case error.PERMISSION_DENIED:
              errorMsg = '定位权限被拒绝，使用默认位置'
              break
            case error.POSITION_UNAVAILABLE:
              errorMsg = '位置信息不可用，使用默认位置'
              break
            case error.TIMEOUT:
              errorMsg = '获取位置超时，使用默认位置'
              break
            default:
              errorMsg = `获取位置失败: ${error.message}，使用默认位置`
          }
          
          ElMessage.warning(errorMsg)
          
          // 使用默认位置 - 长沙岳麓区湖南师范大学中和楼
          currentLocation.value = defaultLocation
          // 获取到位置后立即获取待响应呼叫列表
          fetchPendingEmergencyList()
          
          // 显示手动位置设置界面，让用户可以手动输入位置
          showManualLocation.value = true
        },
        {
          enableHighAccuracy: true,
          timeout: 10000,
          maximumAge: 60000
        }
      )
    } else {
      locationError.value = '浏览器不支持地理定位'
      console.error('浏览器不支持地理定位功能')
      ElMessage.warning('浏览器不支持地理定位功能，使用默认位置')
      
      // 使用默认位置 - 长沙岳麓区湖南师范大学中和楼
      currentLocation.value = defaultLocation
      // 获取到位置后立即获取待响应呼叫列表
      fetchPendingEmergencyList()
      
      // 显示手动位置设置界面，让用户可以手动输入位置
      showManualLocation.value = true
    }
  }
  ```

### 2.3 修改组件挂载逻辑
- 位置：`Emergency.vue` 中的 `onMounted` 函数
- 功能：确保应用程序在组件挂载时能够获取位置或使用默认位置
- 实现：无需修改，已有的 `getCurrentLocation()` 调用会处理好默认位置的使用

## 3. 预期效果
- 当浏览器地理定位成功时，使用真实位置
- 当浏览器地理定位失败时，使用默认位置（长沙岳麓区湖南师范大学中和楼）
- 无论定位成功与否，都能获取待处理紧急呼叫列表
- 始终显示手动位置设置界面，允许用户随时修改位置
- 向用户显示清晰的位置获取状态信息
