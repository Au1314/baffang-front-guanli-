# 充电桩投诉和故障审核功能实现方案

## 1. 实现目标
在已有的投诉和故障审核列表、详情功能基础上，添加审核操作功能，包括：
- 审核对话框组件
- 审核表单（审核结果、审核意见）
- 审核提交逻辑
- 审核状态管理

## 2. 实现范围
- `src/views/ChargingComplaintAudit.vue` - 充电桩投诉审核
- `src/views/ChargingFaultAudit.vue` - 充电桩故障审核

## 3. 技术方案

### 3.1 审核对话框设计
- 添加审核对话框组件，包含：
  - 审核结果选择（通过/拒绝）
  - 审核意见输入框（必填）
  - 提交和取消按钮
  - 表单验证

### 3.2 审核表单逻辑
- 使用Element Plus的Form组件实现表单
- 表单验证：审核结果必填，审核意见必填且长度限制
- 审核结果与意见关联：拒绝时必须填写拒绝原因

### 3.3 审核操作按钮
- 在列表操作栏添加"审核"按钮（仅对审核中状态显示）
- 在详情对话框中添加"审核"按钮（仅对审核中状态显示）

### 3.4 API调用逻辑
- 根据实际API调整参数名称：`action`（1通过，2拒绝），`opinion`（审核意见）
- 使用PUT请求方法
- 审核成功后刷新列表数据
- 显示操作结果提示

## 5. 代码实现细节

### 5.1 审核对话框模板

### 5.2 审核表单数据和验证规则

```javascript
// 审核对话框显示状态
const showAuditDialog = ref(false)
// 审核表单引用
const auditFormRef = ref()
// 当前审核的记录ID
const currentAuditId = ref(0)
// 审核表单数据
const auditForm = reactive({
  action: '',
  opinion: ''
})

// 审核表单验证规则
const auditRules = {
  action: [
    { required: true, message: '请选择审核结果', trigger: 'change' }
  ],
  opinion: [
    { required: true, message: '请输入审核意见', trigger: 'blur' },
    { min: 1, max: 500, message: '审核意见长度在 1 到 500 个字符', trigger: 'blur' }
  ]
}
```

### 5.3 审核操作方法

```javascript
// 打开审核对话框
const handleAudit = (row) => {
  currentAuditId.value = row.id
  auditForm.action = ''
  auditForm.opinion = ''
  showAuditDialog.value = true
}

// 取消审核
const cancelAudit = () => {
  showAuditDialog.value = false
}

// 提交审核
const submitAudit = async () => {
  if (!auditFormRef.value) return
  await auditFormRef.value.validate()
  try {
    // 调用审核API
    await authApi.auditComplaint({
      id: currentAuditId.value,
      action: parseInt(auditForm.action),
      opinion: auditForm.opinion
    })
    ElMessage.success('审核成功')
    showAuditDialog.value = false
    fetchComplaintList() // 刷新列表
  } catch (error) {
    console.error('审核失败:', error)
    ElMessage.error('审核失败')
  }
}
```

### 5.4 列表操作按钮修改

```vue
<el-table-column label="操作" width="200" fixed="right">
  <template #default="scope">
    <el-button type="primary" size="small" @click="handleViewDetail(scope.row)">查看详情</el-button>
    <el-button type="success" size="small" @click="handleAudit(scope.row)" v-if="scope.row.currentStatus === 1">审核</el-button>
  </template>
</el-table-column>
```

## 6. 故障审核功能实现

故障审核功能实现与投诉审核功能类似，只需将API调用改为`auditFault`方法即可。
