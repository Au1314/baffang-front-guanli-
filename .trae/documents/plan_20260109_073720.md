# 添加私人电桩管理到导航菜单方案

## 1. 需求分析
- 已创建了独立的私人电桩管理页面
- 页面路由已配置完成
- 但导航菜单中没有相应的入口
- 需要在侧边栏菜单中添加私人电桩管理选项

## 2. 实现方案

### 2.1 导航菜单位置
导航菜单实现位于 `src/components/layout/MainLayout.vue` 文件中，使用 Element Plus 的 `el-menu` 和 `el-menu-item` 组件。

### 2.2 权限控制
私人电桩管理页面的权限是超级管理员和普通管理员，所以菜单项也需要相同的权限控制。

### 2.3 具体实现
在 `MainLayout.vue` 文件的侧边栏菜单中添加私人电桩管理菜单项，位置建议在平台管理菜单项附近，因为它们的权限相同。

## 3. 具体实现步骤

### 3.1 查找合适的位置
在 `MainLayout.vue` 文件中，找到平台管理菜单项的位置：
```vue
<!-- 平台管理（超级管理员和普通管理员可见） -->
<el-menu-item 
  v-if="adminStore.hasPermission(['超级管理员', '普通管理员'])" 
  index="/platform-manage"
>
  <el-icon><Setting /></el-icon>
  <template #title>平台管理</template>
</el-menu-item>
```

### 3.2 添加私人电桩管理菜单项
在平台管理菜单项下方添加私人电桩管理菜单项：
```vue
<!-- 私人电桩管理（超级管理员和普通管理员可见） -->
<el-menu-item 
  v-if="adminStore.hasPermission(['超级管理员', '普通管理员'])" 
  index="/private-station-manage"
>
  <el-icon><Plug /></el-icon>
  <template #title>私人电桩管理</template>
</el-menu-item>
```

### 3.3 导入所需图标
确保已导入所需的图标组件。在 `MainLayout.vue` 的 script 部分，需要导入 `Plug` 图标：
```javascript
import { 
  // 其他图标
  Plug
} from '@element-plus/icons-vue'
```

## 4. 技术要点
- 使用 Element Plus 的 `el-menu-item` 组件添加菜单项
- 应用相同的权限控制逻辑
- 使用合适的图标表示私人电桩管理
- 确保路由路径与菜单项的 `index` 属性一致

## 5. 预期效果
- 侧边栏菜单中会显示私人电桩管理选项
- 只有超级管理员和普通管理员可以看到该选项
- 点击该选项会跳转到私人电桩管理页面
- 菜单项样式与其他菜单项保持一致

## 6. 测试要点
- 登录系统后，侧边栏是否显示私人电桩管理选项
- 权限控制是否正确，非管理员用户是否看不到该选项
- 点击菜单项是否能正确跳转到私人电桩管理页面
- 菜单项的激活状态是否正确显示

## 7. 风险评估
- 需确保已正确导入所需的图标组件
- 需确保权限控制逻辑与页面路由的权限设置一致
- 需确保菜单项的 `index` 属性与路由路径完全匹配

## 8. 代码结构调整
- 仅需修改 `MainLayout.vue` 文件
- 添加一个新的菜单项和相应的图标导入
- 不影响其他功能和组件
