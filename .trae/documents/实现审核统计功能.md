# 实现审核统计功能方案

## 1. 功能需求
根据API返回的审核统计数据，实现一个审核统计页面，展示以下信息：
- 审核总数、待处理数、处理中数、已通过数、已拒绝数、今日审核数
- 各审核类型的统计数据（私桩认证、车主认证、充电桩投诉、充电桩故障、评论举报、交易申诉）

## 2. 实现步骤

### 2.1 API调用实现
在`src/api/auth.js`中添加获取审核统计信息的方法：
```javascript
// 获取审核统计信息
getAuditStatistics() {
  return request.get('/audit/record/statistics')
}
```

### 2.2 组件创建
创建`src/views/StatisticsAudit.vue`组件，包含以下功能：
- 数据加载和刷新功能
- 审核状态统计展示（使用卡片布局）
- 各审核类型统计展示（使用表格或卡片布局）
- 加载状态和错误处理

### 2.3 路由配置
在`src/router/index.js`中添加审核统计路由：
```javascript
{
  path: '/statistics/audit',
  name: 'StatisticsAudit',
  component: () => import('@/views/StatisticsAudit.vue'),
  meta: {
    requiresAuth: true,
    title: '审核统计',
    hideLayout: false,
    permission: ['超级管理员', '普通管理员', '审核员']
  }
}
```

### 2.4 入口按钮添加
在`src/views/Statistics.vue`的action-bar中添加审核统计入口按钮：
```html
<el-button type="primary" plain @click="$router.push('/statistics/audit')">审核统计</el-button>
```

## 3. 数据转换处理
根据API返回的数据结构，组件将直接使用返回的数据，无需额外转换，因为字段名和展示需求匹配：
- `totalCount` → 审核总数
- `pendingCount` → 待处理数
- `processingCount` → 处理中数
- `approvedCount` → 已通过数
- `rejectedCount` → 已拒绝数
- `todayCount` → 今日审核数
- `typeStatistics` → 各类型审核统计数组

## 4. 技术栈
- Vue 3 + Element Plus
- Axios用于API调用
- Vue Router用于路由管理
- 响应式设计，适配不同屏幕尺寸

## 5. 预期效果
- 审核统计页面展示清晰的审核状态和类型统计
- 支持数据刷新功能
- 包含加载状态和错误处理
- 界面美观，交互友好
