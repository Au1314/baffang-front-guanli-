# 修复决策模块页面空白问题

## 1. 问题分析
从代码分析来看，决策模块页面显示空白的原因是：
- `DecisionList.vue` 组件中的 `formattedByType` 和 `formattedByPriority` 计算属性直接对 `statistics.value.byType` 和 `statistics.value.byPriority` 进行 `map` 操作
- 但如果这些值不是数组（例如，API调用失败返回了错误数据，或者初始值设置不正确），那么 `map` 操作会失败，导致组件崩溃

## 2. 解决方案
修改 `DecisionList.vue` 组件中的 `formattedByType` 和 `formattedByPriority` 计算属性，确保它们在 `statistics.value.byType` 和 `statistics.value.byPriority` 不是数组时也能正常工作。

## 3. 实现步骤

### 3.1 修改 `formattedByType` 计算属性
在 `DecisionList.vue` 组件的 `script` 部分，修改 `formattedByType` 计算属性，添加类型检查：
```javascript
// 格式化后的按类型统计数据
const formattedByType = computed(() => {
  return Array.isArray(statistics.value.byType) ? statistics.value.byType.map(item => ({
    ...item,
    typeName: decisionTypeMap[item.type] || `类型${item.type}`
  })) : []
})
```

### 3.2 修改 `formattedByPriority` 计算属性
同样，修改 `formattedByPriority` 计算属性，添加类型检查：
```javascript
// 格式化后的按优先级统计数据
const formattedByPriority = computed(() => {
  return Array.isArray(statistics.value.byPriority) ? statistics.value.byPriority.map(item => ({
    ...item,
    priorityName: priorityMap[item.priority] || `优先级${item.priority}`
  })) : []
})
```

### 3.3 确保 statistics 初始值正确
检查 `statistics` 初始值的设置，确保 `byType` 和 `byPriority` 初始值为空数组：
```javascript
// 统计数据
const statistics = ref({
  totalCount: 0,
  pendingCount: 0,
  adoptedCount: 0,
  ignoredCount: 0,
  executedCount: 0,
  failedCount: 0,
  todayCount: 0,
  avgConfidence: 0,
  byType: [],
  byPriority: []
})
```

## 4. 预期效果
修复后，即使 API 调用失败，或者返回的数据格式不符合预期，`formattedByType` 和 `formattedByPriority` 计算属性也能正常工作，不会导致组件崩溃，从而避免了页面空白的问题。
