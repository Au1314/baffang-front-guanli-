# 修复待处理紧急呼叫列表显示问题方案

## 1. 问题分析
- 右上角显示数字1，说明 `pendingEmergencyList` 数组长度为1，确实有一个待处理紧急呼叫
- 但列表项没有显示出来，同时详情面板显示"请选择一个紧急呼叫开始处理"
- 从代码分析来看，最可能的原因是 `emergency-list-scroll` 类的 `overflow: hidden` 样式导致列表项被隐藏
- `el-scrollbar` 组件需要在内容超出容器高度时显示滚动条，而 `overflow: hidden` 会隐藏超出的内容

## 2. 实现步骤

### 2.1 修改 CSS 样式
- 位置：`Emergency.vue` 中的 `.emergency-list-scroll` 样式
- 功能：将 `overflow: hidden` 改为 `overflow: auto`，让 `el-scrollbar` 组件正常工作
- 实现：
  ```css
  .emergency-list-scroll {
    flex: 1;
    overflow: auto;
  }
  ```

## 3. 预期效果
- 列表项能够正常显示
- 当列表项数量超出容器高度时，显示滚动条
- 右上角仍显示正确的待处理紧急呼叫数量

## 4. 注意事项
- 保持其他样式不变
- 确保 `el-scrollbar` 组件能够正常工作

## 5. 测试要点
- 验证列表项是否正常显示
- 验证滚动条是否在需要时显示
- 验证右上角的待处理紧急呼叫数量是否正确
