# AI异常检测功能实现方案

## 1. 功能概述
在决策模块下新增AI异常检测页面，用于调用AI异常检测API，展示异常分析结果和建议操作。

## 2. 实现步骤

### 2.1 创建新页面组件
- 创建文件：`src/views/AIAnomalyDetection.vue`
- 参考现有`AIDecisionRequest.vue`的结构设计
- 简化表单，专注于异常检测功能

### 2.2 添加API调用方法
- 在`src/api/auth.js`中添加新的API方法：
  ```javascript
  // AI异常检测
  detectAnomaly(data) {
    return request.post('/ai/decision/anomaly/detect', data, {
      timeout: 180000 // 3分钟超时
    })
  }
  ```

### 2.3 页面设计与实现

#### 2.3.1 表单设计
- 保持简洁，只保留必要的参数
- 包含业务类型、业务ID等可选参数
- 添加自动执行开关

#### 2.3.2 结果展示
- 基本信息展示：决策ID、编号、置信度、自动执行状态、处理时间
- AI分析结果：
  - 异常检测状态（是否存在异常）
  - 置信度和优先级
  - 异常列表（折叠面板展示，包含类型、描述、严重程度）
  - 建议操作（表格展示，包含操作名称、描述、类型、可自动执行状态）
- 建议操作列表：独立表格展示详细操作建议
- 参数详情弹窗：用于查看操作参数

#### 2.3.3 数据处理
- 解析返回的`analysis`字段（Markdown格式的JSON）
- 格式化展示异常信息和建议操作
- 提供复制结果功能

### 2.4 样式设计
- 参考现有页面样式，保持一致性
- 优化异常信息的视觉展示，突出严重程度
- 确保响应式设计，适配不同屏幕尺寸

## 3. 技术要点

### 3.1 数据解析
- 使用正则表达式提取`analysis`字段中的JSON内容
- 安全处理JSON解析，防止解析错误

### 3.2 异常状态展示
- 根据`hasAnomaly`字段显示不同的状态标签
- 根据`confidence`值展示置信度进度条或数值
- 根据`priority`和`severity`字段显示不同颜色的标签

### 3.3 操作参数展示
- 使用弹窗展示详细的操作参数
- 格式化JSON参数，提高可读性

## 4. 文件修改清单

1. **新增文件**：
   - `src/views/AIAnomalyDetection.vue` - AI异常检测页面组件

2. **修改文件**：
   - `src/api/auth.js` - 添加异常检测API调用方法

## 5. 预期效果

- 用户可以通过简洁的表单提交AI异常检测请求
- 系统展示清晰的异常分析结果，包括异常类型、描述、严重程度
- 提供详细的建议操作列表，包含操作类型、参数和可执行状态
- 支持复制完整结果，方便后续处理
- 页面设计美观，交互友好，与现有系统风格一致
