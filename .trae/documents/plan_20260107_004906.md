## 调整数据统计功能实现

### 需求分析

1. 数据统计有新数据时可以推送到数据大屏
2. 数据大屏数据3分钟自动刷新一次
3. 时间筛选器点击后应该有相应响应
4. 数据大屏对全员开放（除普通管理员与超级管理员外只能查看）

### 实现计划

1. **修改数据大屏权限控制**

   * 修改router/index.js中的权限配置，移除permission限制

   * 修改MainLayout.vue中的菜单显示逻辑，让所有用户可见

   * 确保普通用户只能查看，不能编辑

2. **实现数据自动刷新机制**

   * 在DataScreen.vue中添加定时刷新功能（3分钟）

   * 使用setInterval实现定时数据更新

   * 优化刷新逻辑，避免重复请求

3. **实现时间筛选器响应功能**

   * 为时间筛选器添加点击事件

   * 根据选择的时间范围（日/周/月/年）更新图表数据

   * 实现不同时间范围的数据切换

4. **添加数据推送支持**

   * 在DataScreen.vue中添加数据接收逻辑

   * 支持外部数据推送更新

   * 优化数据更新时的图表重绘

5. **完善统计数据展示**

   * 确保显示用户总数、日活、私桩认证量、车主认证量

   * 完善私桩分布数据图表

   * 完善交易数据图表

### 技术实现

* 使用Vue 3 Composition API

* 使用echarts进行数据可视化

* 使用setInterval实现定时刷新

* 响应式设计，适配不同屏幕尺寸

### 预计修改的文件

* `src/views/DataScreen.vue`：实现自动刷新、时间筛选响应、数据推送支持

* `src/router/index.js`：调整数据大屏权限配置

* `src/components/layout/MainLayout.vue`：调整菜单显示逻辑

### 预期效果

* 数据大屏对所有用户开放，普通用户只能查看

* 数据每3分钟自动刷新一次

* 点击时间筛选器可以切换不同时间范围的数据

* 支持外部数据推送更新

* 数据展示符合用户需求
