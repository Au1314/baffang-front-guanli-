## 解决模块加载错误

### 问题分析
修复 `onUnmounted` 导入后，Vite 开发服务器需要重新编译文件。动态模块加载失败通常是 HMR 或缓存问题。

### 解决方案（按顺序尝试）

**方案1：强制刷新浏览器**
- 按 `Ctrl+Shift+R` 或 `Ctrl+F5` 强制刷新，清除缓存

**方案2：重启 Vite 开发服务器**
- 在终端中终止当前的 `npm run dev` 进程
- 重新运行 `npm run dev`

**方案3：检查文件语法**
- 确保所有模板标签正确闭合
- 确保导入语句完整
- 确保所有变量和函数正确定义

建议先尝试方案1，如果不行再尝试方案2。
