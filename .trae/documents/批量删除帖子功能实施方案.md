# 批量删除帖子功能实施方案

## 1. 需求分析
根据用户提供的API信息，需要实现批量删除帖子功能。API使用DELETE方法，请求路径为`/forum/post/batch`，请求体为包含ids数组的JSON对象，响应为成功或失败状态。

## 2. 现有结构分析
- 论坛管理模块（ForumManage.vue）包含帖子管理标签页
- 帖子列表已经实现了单个删除功能
- authApi中已有单个帖子删除方法（deletePost）
- 需要添加批量删除API方法和UI功能

## 3. 实施方案

### 3.1 添加批量删除API方法
- 在authApi中添加batchDeletePost方法
- 实现DELETE请求，路径为/forum/post/batch
- 接收ids数组作为参数

### 3.2 实现UI功能
- 在帖子列表中添加多选框列
- 添加批量删除按钮
- 实现帖子选择功能
- 添加确认对话框
- 实现批量删除逻辑
- 显示操作结果提示

## 4. 具体实现步骤

1. **添加批量删除API方法**
   - 修改 src/api/auth.js，添加batchDeletePost方法

2. **实现帖子列表多选功能**
   - 修改 src/views/ForumManage.vue，在帖子列表中添加多选框列
   - 添加selectedPosts ref用于跟踪选中的帖子
   - 实现select-change事件处理

3. **添加批量删除按钮**
   - 在帖子列表上方添加批量删除按钮
   - 根据选中状态启用/禁用按钮

4. **实现批量删除逻辑**
   - 添加batchDeletePosts方法
   - 显示确认对话框
   - 调用batchDeletePost API
   - 处理响应，显示结果提示
   - 刷新帖子列表

5. **测试功能完整性**
   - 测试多选功能
   - 测试批量删除功能
   - 测试确认对话框
   - 测试结果提示

## 5. 预期效果
- 帖子列表支持多选
- 可通过批量删除按钮一次性删除多个帖子
- 操作前显示确认对话框
- 操作后显示成功或失败提示
- 列表自动刷新

## 6. 技术要点
- 使用Vue 3 Composition API
- 基于Element Plus组件库
- 遵循现有的代码风格和架构
- 确保功能完整性和稳定性

## 7. 代码结构
- authApi.js：添加batchDeletePost方法
- ForumManage.vue：实现UI功能和逻辑

## 8. 注意事项
- 确保API请求格式正确
- 实现良好的用户反馈
- 处理可能的错误情况
