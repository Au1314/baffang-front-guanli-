# 实现车主审核认证统计功能方案

## 1. 功能需求
根据API返回的车主审核认证统计数据，实现一个车主审核认证统计页面，展示以下信息：
- 待审核数量
- 审核中数量
- 已通过数量
- 已拒绝数量
- 需要补充材料数量
- 今日处理数量

## 2. 实现步骤

### 2.1 API调用实现
在`src/api/auth.js`中添加获取车主审核认证统计信息的方法：
```javascript
// 获取车主审核认证统计信息
getVehicleAuditStatistics() {
  return request.get('/audit/vehicle/statistics')
}
```

### 2.2 组件创建
创建`src/views/StatisticsVehicleAudit.vue`组件，包含以下功能：
- 数据加载和刷新功能
- 车主审核认证统计展示（使用卡片布局）
- 加载状态和错误处理

### 2.3 路由配置
在`src/router/index.js`中添加车主审核认证统计路由：
```javascript
{
  path: '/statistics/vehicle-audit',
  name: 'StatisticsVehicleAudit',
  component: () => import('@/views/StatisticsVehicleAudit.vue'),
  meta: {
    requiresAuth: true,
    title: '车主审核认证统计',
    hideLayout: false,
    permission: ['超级管理员', '普通管理员', '审核员']
  }
}
```

### 2.4 入口按钮添加
在`src/views/Statistics.vue`的action-bar中添加车主审核认证统计入口按钮：
```html
<el-button type="primary" plain @click="$router.push('/statistics/vehicle-audit')">车主审核认证统计</el-button>
```

## 3. 数据转换处理
根据API返回的数据结构，组件将直接使用返回的数据，无需额外转换，因为字段名和展示需求匹配：
- `pending` → 待审核
- `processing` → 审核中
- `approved` → 已通过
- `rejected` → 已拒绝
- `needsSupplement` → 需要补充材料
- `todayProcessed` → 今日处理

## 4. 技术栈
- Vue 3 + Element Plus
- Axios用于API调用
- Vue Router用于路由管理
- 响应式设计，适配不同屏幕尺寸

## 5. 预期效果
- 车主审核认证统计页面展示清晰的审核状态统计
- 支持数据刷新功能
- 包含加载状态和错误处理
- 界面美观，交互友好
