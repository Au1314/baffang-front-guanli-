# 修复用户ID验证问题

## 1. 问题分析

根据用户反馈，当输入用户ID 1时，表单验证提示"用户ID必须为正整数"，这是因为：

1. **输入类型转换问题**：`<el-input type="number">` 虽然限制了输入为数字，但Vue的双向绑定可能将输入值转换为字符串类型
2. **验证规则严格性**：当前验证规则使用 `type: 'number'`，要求值必须是JavaScript数值类型，而不是字符串形式的数字

## 2. 解决方案

修改用户ID的验证规则，使其能够正确处理字符串形式的数字，或者确保输入值被正确转换为数值类型。

## 3. 修复步骤

### 3.1 修改NoticeSend.vue组件

#### 3.1.1 更新脚本部分

1. 修改用户ID的验证规则，添加 `transform` 属性将输入值转换为数值类型
2. 或者使用自定义验证函数，确保值为正整数
3. 同时修复关联ID的相同问题

### 3.2 具体修改内容

#### 3.2.1 修改验证规则

```javascript
// 修改前
const rules = ref({
  userId: [
    { required: true, message: '请输入用户ID', trigger: 'blur' },
    { type: 'number', min: 1, message: '用户ID必须为正整数', trigger: 'blur' }
  ],
  // 其他规则...
})

// 修改后
const rules = ref({
  userId: [
    { required: true, message: '请输入用户ID', trigger: 'blur' },
    {
      type: 'number',
      min: 1,
      message: '用户ID必须为正整数',
      trigger: 'blur',
      transform: (value) => Number(value) // 将输入值转换为数值类型
    }
  ],
  // 其他规则...
  relatedId: [
    {
      type: 'number',
      min: 1,
      message: '关联ID必须为正整数',
      trigger: 'blur',
      required: false,
      transform: (value) => Number(value) // 将输入值转换为数值类型
    }
  ],
  // 其他规则...
})
```

## 4. 预期效果

1. **验证通过**：输入用户ID 1时，表单验证能够正确识别为正整数，不再显示错误提示
2. **类型转换**：通过 `transform` 属性，将字符串形式的数字转换为数值类型，确保验证规则能够正确处理
3. **一致性**：同时修复关联ID的相同问题，确保所有数字类型字段的验证都能正确工作
4. **用户体验**：用户能够正常输入数字，无需担心类型转换问题
