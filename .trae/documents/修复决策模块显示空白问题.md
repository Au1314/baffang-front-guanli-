## 问题分析

通过查看路由配置文件，发现了导致决策模块显示空白的根本原因：

1. 在 `src/router/index.js` 中存在**重复的决策模块路由配置**：
   - 第46-73行：完整的决策模块路由配置，包含子路由 `/decision/list` 和 `/decision/request`
   - 第439-448行：重复的决策模块路由配置，但**没有包含任何子路由**

2. 当访问 `/decision/list` 或 `/decision/request` 时，Vue Router 会被重复的路由定义混淆，最终匹配到没有子路由的配置，导致路由无法正确解析，从而显示空白页面。

3. 浏览器控制台的错误信息也验证了这一点，显示请求 `/decision/list` 时失败。

## 修复方案

**删除重复的路由配置**：

1. 删除 `src/router/index.js` 中第439-448行的重复路由配置
2. 只保留第46-73行的完整决策模块路由配置，该配置包含了正确的子路由

## 修复步骤

1. 打开 `src/router/index.js` 文件
2. 删除第439-448行的重复路由配置：
   ```javascript
   {
     path: '/decision',
     name: 'Decision',
     component: () => import('@/views/Decision.vue'),
     meta: {
       requiresAuth: true,
       title: '决策模块',
       hideLayout: false,
       permission: ['超级管理员', '普通管理员']
     }
   },
   ```
3. 保存文件并重新运行项目

## 预期效果

- 决策模块的路由配置恢复正常
- 访问 `/decision/list` 和 `/decision/request` 时能正确匹配到对应的组件
- 决策模块不再显示空白，而是正常显示对应的页面内容
