## 问题分析

从浏览器控制台可以看到，API请求返回403 Forbidden错误，关键问题是**URL路径重复**：

```
POST http://localhost:8080/api/v1/admin/api/v1/admin/ai/decision/audit/suggest/11 403 (Forbidden)
```

可以看到URL中重复了 `/api/v1/admin`，这导致服务器无法识别正确的API路径，从而返回403 Forbidden。

### 原因
1. 在 `src/api/index.js` 中，axios实例的 `baseURL` 已经设置为 `/api/v1/admin`
2. 但在 `src/api/auth.js` 中的 `getAIAuditSuggest` 方法中，又重复添加了完整路径 `/api/v1/admin/ai/decision/audit/suggest/${auditId}`
3. 最终导致请求URL变成：`baseURL + URL = /api/v1/admin + /api/v1/admin/ai/decision/audit/suggest/11`

### 影响范围

查看 `auth.js` 中的其他API方法，发现 `requestAIDecision` 方法也存在同样的问题：

```javascript
// 通用AI决策请求
requestAIDecision(data) {
  return request.post('/api/v1/admin/ai/decision/request', data, {
    timeout: 180000 // 3分钟超时，适应AI分析可能的长时间处理
  })
}
```

## 修复方案

修改 `auth.js` 中的API方法，去掉重复的 `/api/v1/admin` 前缀，只保留相对路径。

## 修复步骤

1. 打开 `src/api/auth.js` 文件
2. 修改 `getAIAuditSuggest` 方法的URL，去掉重复的 `/api/v1/admin` 前缀
3. 修改 `requestAIDecision` 方法的URL，去掉重复的 `/api/v1/admin` 前缀
4. 验证修复效果

## 预期效果

- API请求URL不再重复，格式正确
- 服务器能正确识别API路径
- 不再返回403 Forbidden错误
- AI审核建议功能能正常使用

## 技术细节

- **修改文件**：`src/api/auth.js`
- **修改内容**：API方法中的URL路径
- **影响范围**：仅AI决策相关的两个API方法
