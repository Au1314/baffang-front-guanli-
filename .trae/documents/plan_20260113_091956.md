# 修复紧急响应统计页面字段名不匹配问题

## 问题分析
从截图中可以看到：
- API返回的数据包含`totalCallCount`和`todayCallCount`字段，值分别为17和9
- 但页面上总呼叫量和今日呼叫量没有显示出来
- 检查代码发现，页面使用的字段名是`emergencyStats.totalCount`和`emergencyStats.todayCount`
- 字段名不匹配导致数据无法正确显示

## 解决方案
修改StatisticsEmergency.vue中的字段名，使其与API返回的字段名匹配

## 修复步骤
1. 将第45行的`emergencyStats.totalCount`改为`emergencyStats.totalCallCount`
2. 将第53行的`emergencyStats.todayCount`改为`emergencyStats.todayCallCount`
3. 测试修复后的功能

## 预期效果
- 总呼叫量显示为17
- 今日呼叫量显示为9
- 页面能正确展示所有统计数据

## 修复代码
```javascript
// 修复前
<div class="stats-item-value">{{ emergencyStats.totalCount }}</div>
<div class="stats-item-value">{{ emergencyStats.todayCount }}</div>

// 修复后
<div class="stats-item-value">{{ emergencyStats.totalCallCount }}</div>
<div class="stats-item-value">{{ emergencyStats.todayCallCount }}</div>
```

## 技术细节
- 确保代码中的字段名与API返回的字段名完全匹配
- 检查所有使用到这两个字段的地方
- 保持代码的一致性

## 测试方法
- 重新加载页面
- 检查总呼叫量和今日呼叫量是否正确显示
- 检查其他统计数据是否正常显示
