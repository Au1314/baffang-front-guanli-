# 数据大屏和平台管理功能优化

## 1. DataScreen.vue 修改

**目标**：将自动数据推送改为手动推送

**修改内容**：
- 移除自动数据推送定时器 `setupDataPushListener`
- 保留3分钟自动刷新机制
- 确保数据大屏正常显示所有统计指标

## 2. PlatformManage.vue 修改

**目标**：添加数据统计功能，权限限制为普通管理员及以上

**修改内容**：
- 添加数据统计标签页
- 实现统计数据展示，包括：
  - 用户总数
  - 用户日活
  - 私桩认证量
  - 车主认证量
  - 私桩分布数据
  - 交易数据
- 添加手动推送数据到大屏的按钮
- 设置权限控制，只有普通管理员及以上可以查看该标签页

## 3. 权限设计

**权限等级**：超级管理员＞普通管理员＞客服/紧急响应人员/审核员/论坛管理员 ＞未分配成员

**实现方式**：
- 使用 `isNormalAdmin` 计算属性控制数据统计标签页的显示
- 确保只有普通管理员及以上可以看到该标签页

## 4. 数据推送功能

**实现方式**：
- 在平台管理的数据统计标签页中添加「推送数据到大屏」按钮
- 点击按钮时，将统计数据发送到大屏
- 大屏收到数据后立即更新

## 5. 数据统计展示

**展示方式**：
- 使用卡片式布局展示核心统计指标
- 使用图表展示趋势数据
- 保持与数据大屏一致的数据格式

## 6. 技术实现

**技术栈**：
- Vue 3 Composition API
- Element Plus UI 组件
- Echarts 图表库
- Pinia 状态管理

**关键组件**：
- ElCard：用于数据卡片展示
- ElButton：用于操作按钮
- ECharts：用于数据可视化
- Pinia Store：用于状态管理和权限控制

## 7. 测试计划

**测试内容**：
- 权限控制：确保只有普通管理员及以上可以看到数据统计标签页
- 数据推送：点击推送按钮后，数据大屏能正确更新
- 自动刷新：数据大屏每3分钟自动刷新一次
- 数据展示：所有统计指标能正确显示
