# 实现私桩分布数据统计功能方案

## 1. 功能需求
根据API返回的私桩分布数据统计，实现一个私桩分布统计页面，展示以下信息：
- 状态分布（空闲、异常）
- 类型分布（普通私桩、专业私桩）
- 电流类型分布（交流电）
- 认证状态分布（已认证、认证失败、未认证）
- 开放状态分布（关闭、开启）

## 2. 实现步骤

### 2.1 API调用实现
在`src/api/auth.js`中添加获取私桩分布数据统计的方法：
```javascript
// 获取私桩分布数据统计
getPrivateStationDistribution() {
  return request.get('/stats/station/distribution')
}
```

### 2.2 组件创建
创建`src/views/StatisticsPrivateStation.vue`组件，包含以下功能：
- 数据加载和刷新功能
- 多种分布数据的可视化展示（使用Element Plus图表组件）
- 加载状态和错误处理
- 响应式设计，适配不同屏幕尺寸

### 2.3 路由配置
在`src/router/index.js`中添加私桩分布数据统计路由：
```javascript
{
  path: '/statistics/private-station-distribution',
  name: 'StatisticsPrivateStation',
  component: () => import('@/views/StatisticsPrivateStation.vue'),
  meta: {
    requiresAuth: true,
    title: '私桩分布数据统计',
    hideLayout: false,
    permission: ['超级管理员', '普通管理员']
  }
}
```

### 2.4 入口按钮添加
在`src/views/Statistics.vue`的action-bar中添加私桩分布数据统计入口按钮：
```html
<el-button type="primary" plain @click="$router.push('/statistics/private-station-distribution')">私桩分布数据统计</el-button>
```

## 3. 数据转换处理
根据API返回的数据结构，组件将直接使用返回的数据，无需复杂转换：
- 每个分布数组（如`statusDistribution`）包含`statusName`和`count`字段，可直接用于图表展示
- 对于缺失的分布类型，组件将自动处理，只展示有数据的分布项

## 4. 技术栈
- Vue 3 + Element Plus
- Axios用于API调用
- Vue Router用于路由管理
- Element Plus图表组件用于数据可视化
- 响应式设计，适配不同屏幕尺寸

## 5. 预期效果
- 私桩分布数据统计页面展示清晰的各类分布图表
- 支持数据刷新功能
- 包含加载状态和错误处理
- 界面美观，交互友好，数据可视化直观
