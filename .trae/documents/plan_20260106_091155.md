## 创建独立的数据统计大屏页面

### 需求分析
- 创建一个独立的数据统计大屏页面
- 面向超级管理员和普通管理员开放
- 包含用户数据统计、交易数据分析、充电桩分布数据等功能
- 使用echarts进行数据可视化
- 当前使用虚拟数据，后续对接真实接口

### 实现计划

1. **创建DataScreen.vue组件**
   - 顶部标题区域
   - 核心指标卡片（用户总数、日活、认证量等）
   - 用户数据统计图表区域（折线图、柱状图）
   - 交易数据分析图表（饼图、柱状图）
   - 充电桩分布热力图
   - 数据实时更新区域
   - 时间筛选器（日/周/月/年）

2. **在MainLayout.vue中添加菜单**
   - 添加"数据大屏"菜单项
   - 设置权限控制（超级管理员和普通管理员可见）

3. **在router/index.js中添加路由**
   - 添加数据大屏路由
   - 设置权限配置

4. **在auth.js中添加API接口**
   - 添加用户统计数据接口
   - 添加交易数据接口
   - 添加充电桩分布数据接口

### 技术实现
- 使用Vue 3 Composition API
- 使用echarts进行图表展示
- 使用Element Plus组件
- 响应式布局，适配大屏展示
- 深色主题，更适合数据大屏展示

### 预计修改的文件
- `src/views/DataScreen.vue`（新建）
- `src/components/layout/MainLayout.vue`
- `src/router/index.js`
- `src/api/auth.js`

### 预期效果
- 独立的数据统计大屏页面
- 丰富的图表展示（折线图、柱状图、饼图、热力图）
- 深色主题，适合大屏展示
- 清晰展示用户数据、交易数据、充电桩分布等关键指标
