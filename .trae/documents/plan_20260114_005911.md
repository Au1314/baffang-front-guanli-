## 修复站点审核API请求参数错误

### 问题分析
- **错误原因**：前端调用站点审核API时发送了后端不支持的`remark`字段，导致后端JSON解析失败
- **错误日志**：`JSON parse error: Unrecognized field "remark" (class com.baffang.admin.dto.StationAuthReviewDTO), not marked as ignorable`
- **影响文件**：`src/views/PrivateStationAudit.vue`
- **影响函数**：`submitAudit`

### 修复方案
1. **修改审核请求数据结构**：
   - 移除不支持的`remark`字段
   - 移除不支持的`rejectReason`字段（根据Postman示例，后端不接受该字段）
   - 只保留后端支持的字段：`stationId`、`authStatus`、`opinion`

2. **修复步骤**：
   - 定位到`src/views/PrivateStationAudit.vue`文件中的`submitAudit`函数
   - 修改`auditData`对象，只包含后端支持的字段
   - 确保审核逻辑正确映射认证状态

### 预期效果
- 审核API请求成功，不再返回400 Bad Request
- 站点审核功能正常使用
- 符合后端API要求的请求格式

### 代码修改示例
```javascript
// 修复前
const auditData = {
  stationId: currentAudit.value.id,
  authStatus: authStatus,
  opinion: auditForm.final_opinion,
  rejectReason: auditForm.result === '3' ? auditForm.reject_reason : '',
  remark: auditForm.remark // 包含操作备注
}

// 修复后
const auditData = {
  stationId: currentAudit.value.id,
  authStatus: authStatus,
  opinion: auditForm.final_opinion
}
```
