# 审核功能优化方案

## 1. 实现目标
- 审核按钮在待审核状态（currentStatus === 0）和审核中状态（currentStatus === 1）下显示
- 拒绝时必须填写拒绝原因
- 优化审核表单，添加拒绝原因字段
- 确保API调用正确传递拒绝原因

## 2. 实现范围
- `src/views/ChargingComplaintAudit.vue` - 充电桩投诉审核
- `src/views/ChargingFaultAudit.vue` - 充电桩故障审核

## 3. 技术方案

### 3.1 审核按钮显示条件修改
- 将审核按钮的显示条件从 `currentStatus === 0` 修改为 `currentStatus === 0 || currentStatus === 1`
- 确保在列表页和详情页都进行修改

### 3.2 审核表单优化
- 添加拒绝原因字段
- 设置表单验证规则，拒绝时拒绝原因为必填
- 实现审核结果与拒绝原因的联动

### 3.3 API调用调整
- 确保审核API调用时正确传递拒绝原因
- 拒绝时rejectReason字段为必填
- 通过时rejectReason字段可为空

## 5. 实现细节

### 5.1 审核按钮显示条件
```vue
<el-button type="success" size="small" @click="handleAudit(scope.row)" v-if="scope.row.currentStatus === 0 || scope.row.currentStatus === 1">审核</el-button>
```

### 5.2 审核表单数据
```javascript
const auditForm = reactive({
  action: '',
  opinion: '',
  priority: '',
  rejectReason: '' // 添加拒绝原因字段
})
```

### 5.3 审核对话框模板
```vue
<el-form-item label="拒绝原因" prop="rejectReason" v-if="auditForm.action === '2'">
  <el-input
    v-model="auditForm.rejectReason"
    type="textarea"
    :rows="3"
    placeholder="请输入拒绝原因"
  ></el-input>
</el-form-item>
```

### 5.4 表单验证规则
```javascript
const auditRules = {
  action: [
    { required: true, message: '请选择审核结果', trigger: 'change' }
  ],
  opinion: [
    { required: true, message: '请输入审核意见', trigger: 'blur' },
    { min: 1, max: 500, message: '审核意见长度在 1 到 500 个字符', trigger: 'blur' }
  ],
  rejectReason: [
    { required: true, message: '请输入拒绝原因', trigger: 'blur', validator: (rule, value, callback) => {
      if (auditForm.action === '2' && !value) {
        callback(new Error('拒绝时必须填写拒绝原因'))
      } else {
        callback()
      }
    }}
  ]
}
```

## 6. 预期效果
- 审核按钮在待审核和审核中状态下显示
- 选择拒绝时，拒绝原因字段显示并变为必填
- 拒绝时必须填写拒绝原因才能提交
- 审核API调用时正确传递拒绝原因

- 选择拒绝时是否显示拒绝原因字段
- 拒绝时不填写拒绝原因是否能提交
- 审核API调用时是否正确传递拒绝原因
