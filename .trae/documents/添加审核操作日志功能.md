# 添加审核操作日志功能

## 1. 实现目标
在已有的审核记录列表基础上，添加查看审核操作日志功能，通过专门的 API 获取审核操作日志，替换当前从详情数据中获取的审核日志。

## 2. 实现范围
- `src/api/audit.js` - 添加获取审核操作日志的 API 方法
- `src/views/AuditRecordList.vue` - 更新审核详情页面，使用新的 API 获取审核操作日志

## 3. 技术方案

### 3.1 API 方法添加
- 在 `src/api/audit.js` 中添加 `getAuditRecordLogs` 方法，用于调用 `/audit/record/{id}/logs` API

### 3.2 审核详情页面更新
- 在审核详情页面中添加一个独立的 API 调用，用于获取审核操作日志
- 更新审核日志的展示部分，使用新获取的数据
- 保持现有的审核日志展示样式不变

### 3.3 数据流程
1. 用户点击"查看详情"按钮，打开审核详情对话框
2. 调用 `getAuditRecordDetail` 获取审核详情
3. 调用 `getAuditRecordLogs` 获取审核操作日志
4. 在审核日志卡片中展示获取到的日志数据

## 4. 具体实现步骤

### 4.1 修改 `src/api/audit.js`
1. **添加 `getAuditRecordLogs` 方法**：用于获取审核操作日志

### 4.2 修改 `src/views/AuditRecordList.vue`
1. **添加响应式数据**：添加 `auditLogs` 响应式数据，用于存储审核操作日志
2. **添加加载状态**：添加 `logsLoading` 加载状态，用于显示获取日志时的加载动画
3. **更新 `handleViewDetail` 方法**：在获取审核详情后，调用 `getAuditRecordLogs` 获取审核操作日志
4. **更新审核日志展示**：使用新获取的 `auditLogs` 数据展示审核操作日志

## 5. 实现细节

### 5.1 API 方法实现
```javascript
/**
 * 获取审核操作日志
 * @param {string|number} id - 审核记录 ID
 * @returns {Promise} - 返回审核操作日志数据
 */
export const getAuditRecordLogs = (id) => {
  return service({
    url: `/audit/record/${id}/logs`,
    method: 'get'
  })
}
```

### 5.2 审核详情页面更新
- **添加响应式数据**：
  ```javascript
  const auditLogs = ref([])
  const logsLoading = ref(false)
  ```

- **更新 `handleViewDetail` 方法**：
  ```javascript
  const handleViewDetail = async (row) => {
    auditDetail.value = row
    showDetailDialog.value = true
    
    // 获取审核详情
    detailLoading.value = true
    try {
      const response = await getAuditRecordDetail(row.id)
      auditDetail.value = response
    } catch (error) {
      console.error('获取审核详情失败:', error)
      ElMessage.error('获取审核详情失败')
    } finally {
      detailLoading.value = false
    }
    
    // 获取审核操作日志
    logsLoading.value = true
    try {
      const response = await getAuditRecordLogs(row.id)
      auditLogs.value = response || []
    } catch (error) {
      console.error('获取审核操作日志失败:', error)
      ElMessage.error('获取审核操作日志失败')
      auditLogs.value = []
    } finally {
      logsLoading.value = false
    }
  }
  ```

- **更新审核日志展示**：
  ```vue
  <!-- 审核日志 -->
  <el-card shadow="never" class="detail-section">
    <template #header>
      <span class="section-title">审核日志</span>
    </template>
    <div v-if="auditLogs.length > 0" v-loading="logsLoading">
      <el-timeline>
        <el-timeline-item 
          v-for="log in auditLogs" 
          :key="log.id"
          :timestamp="log.createTime"
        >
          <div class="log-content">
            <div class="log-title">
              <strong>{{ log.adminName }}</strong> {{ log.actionName }}
            </div>
            <div class="log-info">
              从 {{ log.fromStatusName }} → 到 {{ log.toStatusName }}
            </div>
            <div class="log-opinion" v-if="log.opinion">
              审核意见：{{ log.opinion }}
            </div>
          </div>
        </el-timeline-item>
      </el-timeline>
    </div>
    <div v-else-if="!logsLoading" class="empty-logs">
      暂无审核操作日志
    </div>
  </el-card>
  ```
