## 操作栏按钮布局优化方案

### 1. 优化思路

- **保持按钮在同一行**：所有操作按钮都直接显示在同一行，不使用下拉菜单
- **优化按钮样式**：使用 `text` 类型按钮减少视觉重量，突出核心操作
- **调整按钮顺序**：按操作频率和重要性排序
- **调整列宽度**：确保操作列有足够宽度容纳所有按钮
- **使用图标**：为按钮添加图标，提高视觉识别度和操作效率

### 2. 具体实现

**文件**：`src/views/system/UserManage.vue`

#### 2.1 添加图标导入

```javascript
// 在现有导入基础上添加需要的图标
import { Search, Refresh, Delete, Key, View, Check, Close } from '@element-plus/icons-vue'
```

#### 2.2 优化操作栏按钮布局

```vue
<el-table-column label="操作" width="280" align="center">
  <template #default="scope">
    <!-- 查看按钮：使用primary类型，突出显示 -->
    <el-button type="primary" size="small" @click.stop="handleViewDetail(scope.row.id)">
      <el-icon><View /></el-icon>
      查看
    </el-button>
    
    <!-- 禁用/启用按钮：根据状态动态变化 -->
    <el-button
      :type="scope.row.statusName === '正常' ? 'danger' : 'success'"
      size="small"
      @click.stop="scope.row.statusName === '正常' ? handleDisableUser(scope.row) : handleEnableUser(scope.row)"
    >
      <el-icon>{{ scope.row.statusName === '正常' ? <Close /> : <Check /> }}</el-icon>
      {{ scope.row.statusName === '正常' ? '禁用' : '启用' }}
    </el-button>
    
    <!-- 重置密码按钮：使用text类型，减少视觉重量 -->
    <el-button type="warning" size="small" @click.stop="handleResetPassword(scope.row)">
      <el-icon><Key /></el-icon>
      重置密码
    </el-button>
    
    <!-- 删除按钮：使用danger类型，突出显示 -->
    <el-button type="danger" size="small" @click.stop="handleDeleteUser(scope.row)">
      <el-icon><Delete /></el-icon>
      删除
    </el-button>
  </template>
</el-table-column>
```

#### 2.3 优化按钮间距样式

```css
:deep(.operation-buttons) {
  display: flex;
  gap: 8px;
}
```

### 3. 预期效果

- **所有按钮同一行**：4个操作按钮都显示在同一行，符合用户需求
- **视觉层次清晰**：核心操作（查看、禁用/启用）使用主色调，次要操作（重置密码）使用警告色，危险操作（删除）使用危险色
- **图标辅助识别**：每个按钮都有对应的图标，提高操作识别度
- **间距优化**：按钮之间有适当的间距，既不拥挤也不松散
- **响应式设计**：操作列宽度调整为280px，确保能容纳所有按钮

### 4. 技术要点

- 使用Element Plus的不同类型按钮区分操作重要性
- 为每个按钮添加图标，提高视觉识别度
- 调整操作列宽度，确保所有按钮能在同一行显示
- 优化按钮间距，使布局更美观

### 5. 优化前后对比

**优化前**：按钮布局可能存在换行或间距不合理的问题
**优化后**：所有按钮在同一行整齐排列，视觉层次清晰，间距合理
