# 实现手动执行决策功能

## 1. 功能需求

* 在AI审核建议结果页面添加手动执行决策功能

* 调用API `/ai/decision/execute/{decisionId}`，请求方式为POST

* 实现执行决策的确认弹窗

* 显示执行结果反馈

## 2. 技术方案

### 2.1 文件结构

* 修改现有文件：
  * `src/api/auth.js` - 添加API调用方法
  * `src/views/AIAuditSuggest.vue` - 添加手动执行决策功能

### 2.2 功能设计

#### 2.2.1 API集成

* 在authApi中添加新方法：`executeDecision(decisionId)`

* 请求URL：`ai/decision/execute/${decisionId}`（注意去掉开头的斜杠，避免路径重复）

* 请求方式：POST

* 请求参数：decisionId（路径参数）

#### 2.2.2 手动执行决策按钮

* 在AI审核建议结果页面添加"手动执行决策"按钮

* 仅在获取到决策结果后显示

* 点击按钮打开确认弹窗

#### 2.2.3 确认弹窗

* 弹窗标题："确认执行决策"

* 弹窗内容：提示用户确认执行该决策，包含决策ID和决策编号

* 操作按钮：确认、取消

### 2.3 样式设计

* 采用Element Plus组件库

* 保持与现有AI审核建议页面一致的样式

* 使用确认弹窗确保用户操作的准确性

## 3. 实现步骤

### 3.1 第一步：添加API调用方法

在`src/api/auth.js`中添加新的API调用方法：

```javascript
// 手动执行决策
executeDecision(decisionId) {
  return request.post(`ai/decision/execute/${decisionId}`, {}, {
    timeout: 180000 // 3分钟超时
  })
}
```

### 3.2 第二步：修改AIAuditSuggest.vue

1. **添加执行决策的相关变量**

2. **添加手动执行决策的按钮**

3. **实现执行决策的方法**

4. **添加确认弹窗**

### 3.3 第三步：实现执行决策的逻辑

* 点击执行按钮时显示确认弹窗

* 确认后调用API执行决策

* 处理成功或失败的情况

* 显示操作反馈

## 4. 预期效果

* AI审核建议结果页面显示"手动执行决策"按钮

* 点击按钮弹出确认弹窗

* 确认后调用API执行决策

* 执行成功后显示成功提示

* 执行失败后显示失败提示

## 5. 技术要点

* 使用Vue 3 Composition API

* 集成Element Plus组件库

* 处理异步API调用

* 实现确认弹窗

* 提供清晰的操作反馈
