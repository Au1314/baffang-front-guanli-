# 实现修改管理员密码功能

## 功能需求
根据提供的API文档，实现管理员修改密码功能，使用PUT /profile/password端点，请求参数包含oldPassword、newPassword、confirmPassword。

## 实现方案

### 1. 更新API服务
在`src/api/auth.js`中添加新的修改密码方法，使用新的API端点：
```javascript
// 修改密码（新API）
changePassword(data) {
  return request.put('/profile/password', data)
}
```

### 2. 修改Profile.vue组件

#### 2.1 添加修改密码按钮
在操作区域添加"修改密码"按钮，点击打开修改密码对话框。

#### 2.2 新增修改密码对话框
- 添加一个新的el-dialog组件用于修改密码
- 包含密码表单，字段包括：
  - 旧密码（必填）
  - 新密码（必填，符合密码复杂度要求）
  - 确认密码（必填，与新密码一致）

#### 2.3 表单验证规则
- 旧密码：必填
- 新密码：必填，长度8-20位，包含字母和数字
- 确认密码：必填，与新密码一致

#### 2.4 实现修改密码逻辑
- 点击保存按钮时，进行表单验证
- 调用API修改密码
- 根据响应结果显示成功或失败提示
- 成功后关闭对话框并清空表单

### 3. 样式优化
- 保持与现有界面风格一致
- 确保密码输入框显示密码切换功能

## 预期效果
- 管理员可以在个人资料页面点击"修改密码"按钮
- 弹出修改密码对话框，包含旧密码、新密码和确认密码输入框
- 输入符合要求的密码后，点击保存按钮调用API修改密码
- 操作成功或失败后显示相应提示
- 成功后对话框自动关闭，表单清空

## 实现步骤
1. 更新`src/api/auth.js`，添加新的修改密码API方法
2. 修改`src/views/Profile.vue`，添加修改密码按钮
3. 在Profile.vue中添加修改密码对话框和表单
4. 实现表单验证和密码修改逻辑
5. 测试功能是否正常工作

- 使用Element Plus的表单验证
- 密码输入框的显示/隐藏功能
- API调用和错误处理
- 表单数据重置

- 密码修改成功后不需要重新登录
