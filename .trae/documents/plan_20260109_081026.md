# 添加删除私桩功能方案

## 1. 需求分析
- 现有私人电桩管理页面已实现列表展示、详情查看和编辑功能
- 需要添加删除私桩功能
- API已提供：DELETE /api/v1/admin/private-station/{id}
- 支持单个私桩删除

## 2. 实现方案

### 2.1 API层扩展
- 在 `src/api/auth.js` 中添加删除私桩的API函数

### 2.2 页面组件扩展
- 在操作下拉菜单中添加"删除"选项
- 添加删除确认对话框，防止误操作
- 实现删除逻辑，包括加载状态、成功/失败提示

### 2.3 数据模型设计
- 无需新增数据模型，使用现有数据结构

### 3.3 添加删除确认对话框
添加删除确认对话框组件：
```vue
<!-- 删除确认对话框 -->
<el-dialog
  v-model="showDeleteConfirm"
  title="确认删除"
  width="30%"
  :close-on-click-modal="false"
>
  <span>确定要删除该私人电桩吗？此操作不可恢复。</span>
  <template #footer>
    <div class="dialog-footer">
      <el-button @click="handleCancelDelete">取消</el-button>
      <el-button type="danger" @click="handleConfirmDelete" :loading="deleting">
        确定删除

```

### 3.4 实现删除相关数据和方法
添加删除相关的数据和方法：
```javascript
// 删除私桩相关
const showDeleteConfirm = ref(false)
const deleting = ref(false)
const currentDeleteId = ref('')

// 处理操作栏命令
const handleOperation = (command, row) => {
  if (command === 'edit') {
    handleEditPrivateStation(row)
  } else if (command === 'detail') {
    handleViewPrivateStationDetail(row)
  } else if (command === 'delete') {
    currentDeleteId.value = row.id
    showDeleteConfirm.value = true
  }
}

// 取消删除
const handleCancelDelete = () => {
  showDeleteConfirm.value = false
  currentDeleteId.value = ''
}

// 确认删除
const handleConfirmDelete = async () => {
  try {
    deleting.value = true
    await authApi.deletePrivateStation(currentDeleteId.value)
    ElMessage.success('删除成功')
    showDeleteConfirm.value = false
    fetchPrivateStationList() // 刷新列表
  } catch (error) {
    console.error('删除私桩失败:', error)
    ElMessage.error('删除失败')
  } finally {
    deleting.value = false
    currentDeleteId.value = ''
  }
}
```
