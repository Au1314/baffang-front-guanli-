# 修复API路径重复导致的403错误

## 1. 问题分析
- **错误现象**：控制台显示PUT请求返回403 Forbidden，URL为`http://localhost:6101/api/v1/admin/admin/fault/15/audit`
- **问题根源**：
  - axios实例的baseURL已设置为`/api/v1/admin`
  - `auth.js`中`auditComplaint`和`auditFault`方法又添加了`/admin`前缀
  - 导致最终URL出现重复的`admin`路径：`/api/v1/admin/admin/fault/15/audit`
- **影响范围**：投诉审核和故障审核功能

## 2. 修复方案
- 移除`auth.js`中`auditComplaint`和`auditFault`方法URL的`/admin`前缀
- 确保最终URL格式正确：`/api/v1/admin/fault/15/audit`

## 3. 具体实现步骤

### 3.1 修改 `src/api/auth.js`
1. **修复`auditComplaint`方法**：移除URL中的`/admin`前缀
2. **修复`auditFault`方法**：移除URL中的`/admin`前缀

## 4. 修复后预期效果
- API请求URL格式正确，无重复路径
- 403 Forbidden错误消失
- 投诉审核和故障审核功能正常工作

## 5. 技术细节
- 保持API方法的其他部分不变
- 仅修改URL路径部分
- 利用已有的baseURL配置，避免硬编码完整路径

## 6. 测试要点
- 审核故障时API请求是否成功
- 审核投诉时API请求是否成功
- 其他API功能是否受影响
