# 实现平台管理模块基本框架

## 一、需求分析

1. **功能需求**：
   - 设置成员为管理员（仅超级管理员可用）
   - 新增成员账号（也可以主动注册）（创建时若未指定默认为未分配成员）
   - 设置成员为审核员/客服/紧急响应人员
   - 剥夺成员身份
   - 平台参数配置（如默认呼叫范围，积分奖励，日志记录字段等）
   - 查看平台日志

2. **权限需求**：
   - 平台管理功能仅超级管理员和管理员可用
   - 设置成员为管理员功能仅超级管理员可用

3. **技术栈**：
   - Vue 3 + Vite + Element Plus
   - Pinia状态管理
   - Vue Router路由管理
   - Axios网络请求

## 二、解决方案

1. **创建平台管理页面组件**：
   - 创建PlatformManage.vue组件，包含成员管理、参数配置和日志查看三个标签页
   - 使用Element Plus组件，如Card、Tabs、Button、Table等
   - 设计基本的UI结构，具体功能可以暂时不实现

2. **添加API接口**：
   - 在auth.js中添加平台管理相关的API，如获取成员列表、新增成员、修改成员权限等
   - 确保API路径与后端接口匹配

3. **添加路由配置**：
   - 在router/index.js中添加平台管理页面路由
   - 设置路由元信息，确保只有超级管理员和管理员才能访问
   - 设置合适的页面标题

4. **添加菜单配置**：
   - 在MainLayout.vue中添加平台管理菜单
   - 设置菜单权限，确保只有超级管理员和管理员才能看到
   - 设置合适的图标和文字

5. **实现基本的状态管理**：
   - 在adminStore.js中添加平台管理相关的状态和方法
   - 实现成员列表的获取和更新
   - 实现参数配置的获取和更新
   - 实现日志查看的功能

## 四、技术实现

1. **创建PlatformManage.vue组件**：
   ```vue
   <template>
     <div class="platform-manage">
       <h2 class="page-title">平台管理</h2>
       <el-card>
         <el-tabs v-model="activeTab" type="border-card">
           <!-- 成员管理 -->
           <el-tab-pane label="成员管理" name="member">
             <div class="tab-content">
               <!-- 成员管理内容 -->
             </div>
           </el-tab-pane>
           <!-- 参数配置 -->
           <el-tab-pane label="参数配置" name="config">
             <div class="tab-content">
               <!-- 参数配置内容 -->
             </div>
           </el-tab-pane>
           <!-- 日志查看 -->
           <el-tab-pane label="日志查看" name="log">
             <div class="tab-content">
               <!-- 日志查看内容 -->
             </div>
           </el-tab-pane>
         </el-tabs>
       </el-card>
     </div>
   </template>
   
   <script setup>
   import { ref } from 'vue'
   
   const activeTab = ref('member')
   </script>
   ```

2. **添加API接口**：
   ```javascript
   // 获取成员列表
   getMemberList(params) {
     return request.get('/platform/member/list', { params })
   },
   
   // 新增成员
   addMember(data) {
     return request.post('/platform/member/add', data)
   },
   
   // 修改成员权限
   updateMemberPermission(data) {
     return request.put('/platform/member/update-permission', data)
   },
   
   // 获取参数配置
   getConfig() {
     return request.get('/platform/config')
   },
   
   // 更新参数配置
   updateConfig(data) {
     return request.put('/platform/config', data)
   },
   
   // 获取日志列表
   getLogList(params) {
     return request.get('/platform/log/list', { params })
   }
   ```

3. **添加路由配置**：
   ```javascript
   {
     path: '/platform-manage',
     name: 'PlatformManage',
     component: () => import('@/views/PlatformManage.vue'),
     meta: { 
       requiresAuth: true,
       title: '平台管理',
       permission: 'manage_platform'
     }
   }
   ```

4. **添加菜单配置**：
   ```vue
   <el-menu-item 
     v-if="adminStore.hasPermission('manage_platform')" 
     index="/platform-manage"
   >
     <el-icon><Setting /></el-icon>
     <template #title>平台管理</template>
   </el-menu-item>
   ```

5. **实现基本的状态管理**：
   ```javascript
   // 成员列表
   const memberList = ref([])
   
   // 参数配置
   const platformConfig = ref({})
   
   // 日志列表
   const logList = ref([])
   
   // 获取成员列表
   const getMemberList = async (params) => {
     const response = await authApi.getMemberList(params)
     memberList.value = response.data
   }
   
   // 获取参数配置
   const getConfig = async () => {
     const response = await authApi.getConfig()
     platformConfig.value = response.data
   }
   
   // 获取日志列表
   const getLogList = async (params) => {
     const response = await authApi.getLogList(params)
     logList.value = response.data
   }
   ```
