# Web管理端界面设计总结

## 1. 概述

本文档描述充电桩管理平台Web管理端的界面设计规范，旨在为后台管理系统提供统一的设计标准和交互规范。

## 2. 设计原则

### 2.1 任务优先

后台管理以「数据概览→快速操作→详情管理」为主线：

* 控制台提供关键指标和快捷入口，减少管理员查找功能的时间

* 各模块列表页支持快捷筛选和批量操作

* 详情页采用弹窗或抽屉形式，避免页面跳转中断工作流程

### 2.2 视觉一致

* **主色统一**：品牌绿 #00D45A 用于选中状态、主按钮、强调图标

* **圆角统一**：卡片12px、按钮8px、输入框4px、弹窗8px

* **间距统一**：基于8px网格系统，内边距16px/24px

* **阴影统一**：卡片 0 2px 12px rgba(0,0,0,0.08)

### 2.3 层级清晰

```
┌─────────────────────────────────────────┐
│             顶部栏 (60px)                │
│  Logo │ 面包屑         用户信息/操作     │
├──────────┬──────────────────────────────┤
│          │                              │
│  侧边栏   │         内容区               │
│  (200px) │                             │
│          │  ┌────────────────────────┐  │
│  导航菜单  │  │   页面标题 + 操作按钮  │  │
│          │  ├────────────────────────┤  │
│          │  │                       │  │
│          │  │      主内容区域         │  │
│          │  │                       │  │
│          │  └────────────────────────┘  │
│          │                              │
└──────────┴──────────────────────────────┘
```

### 2.4 响应式适配

* 主要内容区使用自适应宽度

* 侧边栏可折叠（200px → 64px）

* 表格支持横向滚动

* 统计图表自适应容器宽度

## 6. 交互与状态规范

### 6.1 加载状态

| 场景   | 表现方式                   |
| ---- | ---------------------- |
| 页面加载 | 全屏 Loading 遮罩 + 品牌绿动画  |
| 列表加载 | 骨架屏占位                  |
| 按钮加载 | 按钮内图标替换 + 文字变为"处理中..." |
| 数据提交 | 按钮禁用 + Loading 图标      |

### 6.2 空状态

| 场景    | 文案            | 图标         |
| ----- | ------------- | ---------- |
| 无数据   | "暂无数据"        | 空数据图标      |
| 加载中   | "正在加载..."     | Loading 动画 |
| 搜索无结果 | "未找到相关结果"     | 搜索图标       |
| 无权限   | "您没有访问该页面的权限" | 锁图标        |

### 6.3 异常状态

| 场景   | 表现               | 操作        |
| ---- | ---------------- | --------- |
| 网络错误 | Toast 提示"网络连接失败" | 显示重试按钮    |
| 服务异常 | Toast 提示"服务暂不可用" | 提示联系管理员   |
| 请求超时 | Toast 提示"请求超时"   | 自动重试或手动刷新 |
| 权限不足 | 弹窗提示或跳转提示页       | 引导返回上一页   |

### 6.4 操作反馈

| 操作类型 | 反馈方式                   |
| ---- | ---------------------- |
| 操作成功 | 绿色 Toast + 成功图标 + 提示文案 |
| 操作失败 | 红色 Toast + 失败图标 + 错误原因 |
| 操作确认 | Modal 对话框确认            |
| 危险操作 | 红色主按钮 + 确认对话框          |

### 6.5 表单验证

| 验证场景  | 反馈方式               |
| ----- | ------------------ |
| 必填项为空 | 输入框边框变红 + 下方红色提示文字 |
| 格式错误  | 输入框边框变红 + 提示正确格式   |
| 验证通过  | 输入框边框变绿（可选）        |

## 7. 响应式设计

### 7.1 断点设置

| 断点 | 宽度范围           | 布局变化            |
| -- | -------------- | --------------- |
| 超小 | < 768px        | 侧边栏折叠为图标，表格横向滚动 |
| 小屏 | 768px - 992px  | 侧边栏可折叠，卡片单列     |
| 中屏 | 992px - 1200px | 侧边栏展开，卡片双列      |
| 大屏 | > 1200px       | 全功能展示，多列卡片      |

### 7.2 适配要求

* 表格在小屏幕下支持横向滚动

* 卡片列表在窄屏下自动单列显示

* 侧边栏在小屏幕下自动折叠

* 弹窗在小屏幕下宽度自适应

* 图表容器支持 ResizeObserver 自动调整尺寸
