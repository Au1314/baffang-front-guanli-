# 实现处理决策功能

## 1. 功能需求

* 在决策模块中实现处理决策的功能

* 调用API `/ai/decision/handle`，请求参数包括decisionId、action和remark

* 实现处理决策的弹窗，用于输入处理意见

* 在决策列表中添加处理按钮

## 2. 技术方案

### 2.1 文件结构

* 修改现有文件：
  * `src/api/auth.js` - 添加API调用方法
  * `src/views/DecisionList.vue` - 添加处理决策功能

### 2.2 功能设计

#### 2.2.1 API集成

* 在authApi中添加新方法：`handleDecision(params)`

* 请求URL：`ai/decision/handle`（注意去掉开头的斜杠，避免路径重复）

* 请求方式：POST

* 请求参数：decisionId, action, remark

#### 2.2.2 处理决策弹窗

* 弹窗标题："处理决策"

* 表单字段：
  * 决策ID（只读）
  * 决策编号（只读）
  * 操作类型（下拉选择：adopt, ignore, partial）
  * 处理备注（文本域）

* 操作按钮：确定、取消

#### 2.2.3 决策列表

* 在表格中添加"处理"按钮

* 仅对未处理的决策显示处理按钮

* 点击处理按钮打开处理决策弹窗

### 2.3 样式设计

* 采用Element Plus组件库

* 保持与现有决策模块页面一致的样式

## 3. 实现步骤

### 3.1 第一步：添加API调用方法

在`src/api/auth.js`中添加新的API调用方法：

```javascript
// 处理决策
handleDecision(params) {
  return request.post('ai/decision/handle', params, {
    timeout: 180000 // 3分钟超时
  })
}
```

### 3.2 第二步：修改DecisionList.vue

1. **添加处理决策弹窗**

2. **添加处理决策的相关变量**

3. **添加处理决策的方法**

4. **在表格中添加处理按钮**

### 3.3 第三步：实现处理决策的逻辑

* 打开弹窗时初始化表单数据

* 表单提交时调用API

* 处理成功后刷新列表和统计数据

* 处理失败时显示错误信息

## 4. 预期效果

* 决策列表中未处理的决策显示"处理"按钮

* 点击"处理"按钮打开处理决策弹窗

* 输入处理意见后提交，成功更新决策状态

* 刷新列表和统计数据，显示最新状态

## 5. 技术要点

* 使用Vue 3 Composition API

* 集成Element Plus组件库

* 处理异步API调用

* 实现弹窗表单验证

* 刷新数据时的性能优化
