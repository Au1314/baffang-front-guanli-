# 解决启用用户失败的问题

## 问题分析
从错误信息来看，启用用户时发送请求到 `/api/v1/admin/user/1/status` 时返回 400 Bad Request，导致启用用户失败。

## 可能的原因
1. **请求参数格式不正确**：API 期望的请求体格式与实际发送的不一致
2. **状态码不正确**：启用用户的状态码可能不是 0
3. **原因字段不能为空字符串**：API 可能要求原因字段在启用时也不能为空
4. **API 接口实现问题**：`setUserStatus` 方法的实现可能存在问题

## 解决方案

### 1. 检查 API 接口实现
- 查看 `setUserStatus` 方法的实现，确保请求格式正确
- 检查 API 文档，确认正确的请求参数格式

### 2. 修改 `setUserStatus` 方法
- 确保请求体格式正确
- 根据 API 要求调整状态码和原因字段

### 3. 测试修复
- 重新测试启用用户功能
- 确保禁用用户功能也正常工作

## 实现步骤
1. 查看 `setUserStatus` 方法的实现
2. 根据 API 要求修改方法实现
3. 保存文件
4. 测试启用用户功能
5. 测试禁用用户功能

## 预期效果
修复后，启用用户时请求能够成功发送，API 返回 200 OK，用户状态更新为"正常"，显示成功提示。
