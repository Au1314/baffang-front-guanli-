# 实现获取管理员个人信息功能

## 1. 修改API文件
在 `src/api/auth.js` 中添加一个新的方法 `getProfile`，用于调用 `/profile` 接口获取管理员个人信息。

## 2. 更新Profile组件
在 `src/views/Profile.vue` 中修改代码，实现以下功能：
- 在组件挂载时调用 `getProfile` 方法获取最新的管理员个人信息
- 替换当前从 store 中获取信息的方式，改为直接调用 API 获取
- 确保数据格式与API返回响应匹配

## 3. 实现步骤
1. 在 `auth.js` 中添加 `getProfile` 方法
2. 在 `Profile.vue` 中导入 `getProfile` 方法
3. 在组件挂载时调用 `getProfile` 方法
4. 将获取到的数据更新到 `profileForm` 中
5. 确保UI显示正确的数据格式

## 4. 预期效果
- 个人资料页面能够显示最新的管理员个人信息
- 数据来源从 store 改为直接调用 `/profile` API
- 页面加载时自动获取最新数据

## 5. 注意事项
- 确保API请求头包含正确的Authorization token
- 处理API请求失败的情况
- 确保数据格式转换正确，特别是日期字段
- 保持与现有代码风格一致
