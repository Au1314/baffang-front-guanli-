# 数据导出与平台数据管理模块 UI 优化 - 验证清单

## 整体风格验证
- [ ] 界面风格与后台其他模块保持一致
- [ ] 所有卡片的圆角、阴影、边框、内边距统一
- [ ] 配色方案统一，使用与其他模块相同的颜色
- [ ] 字体设置统一，包括字体大小、粗细和行高
- [ ] 间距标准统一，模块间距、控件间距合理

## 顶部提示栏验证
- [ ] 提示框样式柔和，背景色和警示图标与整体风格协调
- [ ] 提示文字排版清晰易读
- [ ] 提示栏位置和大小合理

## 卡片标题区验证
- [ ] 所有卡片的标题样式统一，包括图标、文字大小
- [ ] 左侧标识线的样式和颜色统一
- [ ] 标题文字清晰，避免过长导致拥挤
- [ ] 标题区与卡片内容的间距合理

## 功能说明区验证
- [ ] 说明文字的字体大小和颜色与下方控件清晰区分
- [ ] 关键风险提示（如回滚操作不可逆）用红色文字突出显示
- [ ] 说明文字清晰易懂，不与表单元素混在一起
- [ ] 说明区与控件区的间距合理

## 表单控件区验证
- [ ] 日期选择器、下拉框的尺寸、样式和间距统一
- [ ] 所有卡片的控件布局对齐
- [ ] "开始日期 - 至 - 结束日期" 的排版协调，"至" 字居中对齐
- [ ] 回滚操作的文件选择下拉框样式和位置与其他控件统一
- [ ] 表单控件的操作流畅，响应及时

## 操作按钮验证
- [ ] 按钮样式统一，主操作按钮用主色，风险操作（回滚）用警示色
- [ ] 所有卡片的按钮左对齐，保持在同一水平线上
- [ ] 按钮有明显的hover和点击反馈
- [ ] 按钮大小和间距合理

## 整体布局验证
- [ ] 多个卡片之间的间距合理，页面整体排版均衡
- [ ] 页面滚动体验良好
- [ ] 卡片在不同屏幕尺寸下布局稳定
- [ ] 整体视觉平衡，避免局部拥挤或空白过多
- [ ] 响应式布局适配不同屏幕尺寸

## 功能验证
- [ ] 数据导出功能正常，包括审核记录导出、订单&用户数据导出、订单明细导出、用户数据导出
- [ ] 平台数据管理功能正常，包括备份平台数据、回滚平台数据
- [ ] 所有API调用和数据展示正常
- [ ] 导出进度弹窗显示正常

## 交互体验验证
- [ ] 页面加载速度快，响应及时
- [ ] 操作流程清晰，易于理解
- [ ] 错误提示和状态反馈清晰
- [ ] 整体操作体验流畅
