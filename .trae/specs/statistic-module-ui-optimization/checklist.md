# 统计模块页面 UI 优化 - 验证清单

- [x] 检查一级标签样式是否统一，选中态和未选中态是否区分明显
- [x] 检查一级标签的间距、圆角、hover 效果是否优化
- [x] 检查二级标签样式是否统一，选中态和未选中态是否区分明显
- [x] 检查不同状态的二级标签是否用不同颜色区分，整体是否和谐
- [x] 检查二级标签的间距、圆角、hover 效果是否优化
- [x] 检查数据卡片样式是否统一，是否有轻微阴影和圆角
- [x] 检查数据卡片的图标和文字排版是否合理，数据是否醒目
- [x] 检查数据卡片是否有 hover 效果，交互反馈是否良好
- [x] 检查不同模块下卡片的间距、尺寸是否统一
- [x] 检查配色方案是否与其他后台模块保持一致
- [x] 检查字体和字号是否统一，信息层级是否清晰
- [x] 检查间距和边距是否统一，界面整体感是否强
- [x] 检查数据卡片在不同屏幕尺寸下的布局是否合理，不变形
- [x] 检查标签导航在小屏幕下的显示效果是否正常
- [x] 检查数据加载中是否显示适当的加载状态，样式是否美观
- [x] 检查数据为空时是否显示适当的空状态提示，样式是否美观
- [x] 检查加载和空状态的样式是否与整体风格一致
