# 数据大屏更新 - 产品需求文档

## Overview
- **Summary**: 基于现有数据大屏实现，通过连接真实的统计接口，实现数据的实时更新和展示，提供更直观、全面的数据可视化体验。
- **Purpose**: 为管理员提供实时、准确的平台运营数据，帮助其快速了解平台状态，做出数据驱动的决策。
- **Target Users**: 平台管理员、运营人员

## Goals
- 连接真实的统计API接口，替换模拟数据
- 实现数据的定时自动更新
- 优化图表展示和交互体验
- 确保数据的实时性和准确性
- 提供多维度的数据筛选和查看

## Non-Goals (Out of Scope)
- 不增加新的数据源
- 不修改现有API接口结构
- 不实现数据预测功能
- 不添加新的权限控制

## Background & Context
- 现有项目已实现基础的数据大屏界面，使用了echarts进行图表展示
- 项目中已有多个统计相关的API接口，可用于获取真实数据
- 目前数据大屏使用的是模拟数据，需要替换为真实API数据

## Functional Requirements
- **FR-1**: 连接平台统计API接口，获取核心指标数据
- **FR-2**: 连接客服统计API接口，获取客服相关数据
- **FR-3**: 连接紧急响应统计API接口，获取紧急响应数据
- **FR-4**: 连接论坛统计API接口，获取论坛相关数据
- **FR-5**: 连接审核统计API接口，获取审核相关数据
- **FR-6**: 实现数据的定时自动更新
- **FR-7**: 优化时间范围筛选功能，支持日、周、月、年维度
- **FR-8**: 提供数据刷新控制，支持手动刷新

## Non-Functional Requirements
- **NFR-1**: 数据更新延迟不超过30秒
- **NFR-2**: 页面加载时间不超过3秒
- **NFR-3**: 图表渲染流畅，无卡顿
- **NFR-4**: 响应式设计，适配不同屏幕尺寸
- **NFR-5**: 错误处理机制，确保接口调用失败时不影响整体页面

## Constraints
- **Technical**: 基于现有的Vue 3 + Element Plus + ECharts技术栈
- **Business**: 不增加新的API接口，仅使用现有的统计接口
- **Dependencies**: 依赖现有的统计API接口返回数据格式

## Assumptions
- 现有统计API接口返回的数据格式能够满足图表展示需求
- API接口响应时间在可接受范围内
- 平台数据量不会导致图表渲染性能问题

## Acceptance Criteria

### AC-1: 核心指标数据展示
- **Given**: 平台运行正常，API接口可用
- **When**: 访问数据大屏页面
- **Then**: 核心指标区域显示真实的平台数据，包括用户总数、日活用户、月活用户、新增用户、车主认证量、私桩认证量
- **Verification**: `programmatic`

### AC-2: 图表数据展示
- **Given**: 平台运行正常，API接口可用
- **When**: 访问数据大屏页面
- **Then**: 所有图表显示真实的数据，包括用户增长趋势、认证量统计、支付方式占比、交易数据分析、V2V交易占比、私桩共享占比、充电桩分布热力图、区域统计
- **Verification**: `programmatic`

### AC-3: 数据自动更新
- **Given**: 平台运行正常，API接口可用
- **When**: 数据大屏页面打开超过3分钟
- **Then**: 页面数据自动更新，显示最新的统计数据
- **Verification**: `programmatic`

### AC-4: 时间范围筛选
- **Given**: 平台运行正常，API接口可用
- **When**: 切换时间范围（日、周、月、年）
- **Then**: 图表数据根据选择的时间范围更新
- **Verification**: `programmatic`

### AC-5: 手动刷新功能
- **Given**: 平台运行正常，API接口可用
- **When**: 点击手动刷新按钮
- **Then**: 页面数据立即更新，显示最新的统计数据
- **Verification**: `programmatic`

### AC-6: 错误处理
- **Given**: 平台运行正常，部分API接口不可用
- **When**: 访问数据大屏页面
- **Then**: 页面正常加载，不可用接口的数据显示为默认值或提示信息
- **Verification**: `human-judgment`
