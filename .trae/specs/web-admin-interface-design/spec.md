# Web管理端界面设计规范 Spec

## Why

当前Web管理端缺乏统一的视觉设计规范，界面风格与App不一致，需要建立完整的设计体系以提升用户体验和管理效率。本规范旨在统一Web管理端的视觉风格、交互模式和组件规范，与App端的设计语言保持一致性。

## What Changes

- 建立Web管理端视觉设计规范体系，统一色彩、字体、间距、圆角等基础元素
- 制定布局结构规范，明确顶部导航、侧边栏、内容区的层级关系
- 定义主要功能模块的界面结构和交互模式
- 制定状态反馈和异常处理规范
- 保持与App端设计语言的一致性

## Impact

- Affected specs: 现有所有管理端页面需遵循本规范进行优化
- Affected code: src/components/layout/MainLayout.vue, src/views/*, src/style.css

## ADDED Requirements

### Requirement: 视觉设计规范

Web管理端界面应遵循统一的视觉设计规范，包括色彩、字体、间距、圆角等基础元素。

#### 视觉基础规范

| 项目 | App规范 | Web管理端规范 | 说明 |
|------|--------|-------------|------|
| 主色 | #00D45A 品牌绿 | #00D45A 品牌绿 | 保持App一致性，用于选中状态、主按钮、强调元素 |
| 辅助色 | 金黄、青绿、浅蓝等 | 沿用App辅助色体系 | 用于功能区分、快捷入口等 |
| 中性色 | 深灰主文案、#999/#aaa次要文案、#F8F8F8背景 | 沿用App中性色体系 | 文案、占位、背景区分 |
| 顶部导航背景 | 浅绿至白色纵向渐变 | 深色系(#304156)主导航 | 管理端使用深色导航增强专业感 |
| 搜索框 | 圆角胶囊搜索框 | 圆角矩形搜索框 | 沿用圆角风格，浅色描边 |
| 底部导航 | 浅白半透明底+轻阴影 | 侧边栏导航替代 | Web端使用侧边栏代替底部Tab |
| 图标 | uni-icons | Element Plus Icons | 保持线框/填充风格区分 |

### Requirement: 布局结构规范

Web管理端采用经典的后台管理系统布局结构，由顶部栏、侧边栏和内容区三部分组成。

#### 布局层级

```
┌──────────────────────────────────────────────────────────┐
│                      顶部栏 (Header)                      │
│  Logo │ 面包屑导航 │                    用户信息/操作    │
├────────────┬─────────────────────────────────────────────┤
│            │                                             │
│  侧边栏    │              内容区 (Content)                │
│  (Sidebar) │                                            │
│            │  ┌─────────────────────────────────────┐    │
│  导航菜单   │  │        页面标题 + 操作按钮           │    │
│            │  ├─────────────────────────────────────┤    │
│            │  │                                     │    │
│            │  │            主内容区域                │    │
│            │  │                                     │    │
│            │  └─────────────────────────────────────┘    │
│            │                                             │
└────────────┴─────────────────────────────────────────────┘
```

#### 布局规范

- 顶部栏高度：60px，固定定位
- 侧边栏宽度：200px（展开）/ 64px（折叠），可配置
- 内容区padding：20px
- 栅格系统：基于Element Plus的24栏栅格

### Requirement: 主要界面构成

#### 控制台（Dashboard）

管理员登录后的主页面，提供系统概览和快捷操作入口。

**界面结构：**
- 欢迎信息区：显示管理员信息、今日日期、系统状态
- 统计卡片区：关键数据指标卡片（待审核数、在线用户数、今日活跃等）
- 快捷操作区：常用功能入口（快捷跳转）
- 最近动态区：最新审核记录、系统通知等

**视觉规范：**
- 主背景：深蓝渐变(#0a1929 → #1a2e45)
- 卡片：半透明深色背景( rgba(26,46,69,0.8) ) + 模糊效果(backdrop-filter: blur(10px))
- 边框：1px边框使用主色透明度20%
- 阴影：0 4px 16px rgba(0,0,0,0.15)

#### 审核管理模块

**页面列表：**
- 审核管理主页：显示各类型待审核数量统计

### Requirement: 组件规范

#### 卡片组件

- 圆角：12px
- 背景：白色或半透明深色
- 阴影：0 2px 12px rgba(0,0,0,0.08)
- 内边距：16px-24px
- Hover效果：轻微上浮(translateY(-2px)) + 阴影加深

#### 按钮规范

- 主按钮：背景#00D45A，文字白色，圆角8px
- 次按钮：边框#00D45A，文字#00D45A，透明背景
- 危险按钮：背景#f56c6c
- 禁用状态：透明度50%
- 按钮尺寸：small(28px) / default(32px) / large(40px)

#### 表格规范

- 表头：背景#f5f7fa，文字加粗
- 行高：48px
- 斑马纹：奇偶行交替背景
- Hover：当前行高亮背景
- 边框：1px #ebeef5分隔线

#### 表单规范

- 输入框高度：32px
- 圆角：4px
- 边框：1px #dcdfe6
- Focus状态：边框#00D45A
- 标签与输入框间距：8px

#### 弹窗/对话框规范

- 圆角：8px
- 头部：背景白色，底部边框
- 内容区：内边距24px
- 底部：内边距16px，按钮右对齐

### Requirement: 交互与状态规范

#### 加载状态

- 列表加载：骨架屏或Loading遮罩
- 按钮加载：图标替换+禁用
- 页面加载：全屏Loading

#### 空状态

- 统一空状态插图
- 文案提示：「暂无数据」「正在获取...」

#### 异常状态

- 网络错误：重试按钮
- 权限不足：提示+跳转
- 服务异常：联系管理员提示

#### 反馈机制

- 成功：Toast提示(绿色)
- 失败：Toast提示(红色)
- 警告：Toast提示(橙色)
- 信息：Toast提示(蓝色)
- 操作确认：Modal对话框

## MODIFIED Requirements

### Requirement: 现有管理端界面

现有管理端界面需逐步优化以符合本规范，包括但不限于：
- 色彩体系调整
- 组件圆角统一
- 布局结构规范化
- 交互反馈统一化

## REMOVED Requirements

### Requirement: 非规范化设计

**Reason**: 原有设计中存在的非规范化元素（如不统一的圆角、不一致的色彩使用）将逐步废弃，统一使用本规范定义的设计语言。

**Migration**: 新开发页面严格遵循本规范，现有页面逐步迭代优化。
