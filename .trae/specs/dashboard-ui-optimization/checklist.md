# 数据大屏 UI 优化 - 验证清单

- [ ] 检查整体视觉风格是否为深色科技风，背景是否有渐变/质感，是否包含科技元素
- [ ] 检查配色方案是否为蓝绿色系，辅助色搭配是否合理，图表、卡片、文字的配色是否协调
- [ ] 检查字体层级是否清晰，标题、数据、标签的字体大小/粗细是否区分明显
- [ ] 检查数据指标卡片样式是否统一，是否有圆角、阴影、发光效果
- [ ] 检查核心数据是否突出，字号是否大，是否有发光或渐变效果
- [ ] 检查趋势箭头和百分比显示是否直观，颜色是否区分增长/下降
- [ ] 检查卡片之间的间距和尺寸是否统一
- [ ] 检查图表配色风格是否统一，与平台主色调是否一致
- [ ] 检查图表样式是否优化，是否有渐变填充、立体/发光效果
- [ ] 检查图表的坐标轴、图例、标签样式是否清晰，是否拥挤
- [ ] 检查图表是否有 hover 交互效果和平滑过渡动画
- [ ] 检查页面布局是否均衡，模块排版和间距是否合理
- [ ] 检查模块之间的区分度是否强，边界是否清晰
- [ ] 检查标题栏样式是否优化，平台名称是否突出，是否有仪式感
- [ ] 检查刷新按钮是否有 hover/点击效果
- [ ] 检查时间显示样式是否与整体风格统一
- [ ] 检查数据加载中是否显示适当的加载动画，样式是否美观
- [ ] 检查数据为空时是否显示适当的空状态提示，样式是否美观
- [ ] 检查数据大屏在不同屏幕尺寸下的显示效果是否正常
- [ ] 检查动效和交互是否流畅，是否提升用户体验
